# 终焉之地（代号 godot-game）

一款以「十日终焉」为气质原型的 **多人社交博弈 + UGC 关卡平台**。

玩家以失忆的**编号**身份被困在**终焉之地**，在 10 人局的**关卡**中用**余命**互相博弈。
每个人都持有只有自己知道的**密令**，因此同一张牌桌上，10 个人在玩 10 个不同的游戏。
在无数次**轮回**中找回自己的过去、觉醒**回响**，并最终有可能成为**生肖**——
关卡规则的化身，去设计下一个折磨别人的关卡。

- **引擎**：Godot 4.8
- **状态**：设计阶段，尚未进入实装

## 核心设计要点

- **密令**：每局每人一条隐藏目标，把任何平庸玩法变成社交推理。
- **余命**：唯一硬通货，串起短期决策、中期压力与长期目标。
- **回响**：稀有的超能力。**只从失去中诞生**，必须与角色前史共振；触发条件越苛刻越强。
- **无阵营**：普通玩家只有编号，没有"人类阵营"——阵营会杀死猜疑链。
- **生肖**：关卡的主持者与规则的化身，胜利条件是「收成」而不是杀人。
- **UGC 不写代码**：只组合预定义的触发器与效果，安全且可裁决。
- **LLM 不裁判**：胜负永远由确定性规则引擎判定，AI 只负责主持与演出。
