# 终焉之地（代号 godot-game）

一款以「十日终焉」为气质原型的 **多人社交博弈 + UGC 关卡平台**。

玩家以失忆的**编号**身份被困在**终焉之地**，走到大世界里的某栋建筑前进场，
在**关卡**中用**余命**互相博弈。开局人数由关卡设计者定义（4–16 人），
每个人都持有只有自己知道的**密令**——**坐着几个人，就有几个不同的游戏在进行**。
在无数次**轮回**中找回自己的过去，并在共振情景中激活只属于本轮回的**回响**。
同时，**任何玩家都可以自己造一个关卡并主持它**——成为关卡规则的化身，
去设计下一个折磨别人的关卡。造关没有门槛，只要付得起余命。

> **当前阶段：游戏设计。** 本仓库现阶段只讨论玩法设计，不涉及任何技术实现。

## 核心设计要点

- **密令**：每局每人一条隐藏目标，把任何平庸玩法变成社交推理。
- **余命**：唯一硬通货，串起短期决策、中期压力与长期目标。
- **回响**：稀有的超能力。它是**一个大多数人都有过的底层渴望**被兑现成畸形的形状，
  只从失去中诞生，必须与角色前史共振；激活情景越苛刻，回响越强，**激活后是否发动由玩家决定**。
- **无阵营**：普通玩家只有编号，没有"人类阵营"——阵营会杀死猜疑链。
- **主持人**：关卡的主持者与规则的化身，胜利条件是「收成」而不是杀人。
- **造关是通用能力**：没有身份门槛，任何玩家都能造关并主持；
  但**不能以编号身份进自己的关卡**。
- **门槛是一块地**：造关前要先在大世界买地，需大额余命 + 周期性维护费。
  **核心区有限且昂贵、人流大；外围无限且便宜、人流小**——新人永远买得起地，但买不起好地。
- **死亡逻辑尚未设计**：出局后干什么、轮回结束意味着什么、重开有无代价，全部待定。
- **模板的准入判据是"能不能让人露出本性"**：无最优解 / 可观测 / 价值取舍 /
  **随机性不得成为决策的借口**。
- **UGC 只做组合**：创作者组合预定义的规则零件，一切效果都必须能被客观判定。
- **主持人不裁判**：胜负永远由关卡规则本身判定，主持人只负责叙事与演出。
