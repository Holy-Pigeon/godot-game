# 01 · 核心循环与三层目标

> 状态：草案 v0.1 ｜ 关联：[00 高概念](00-overview.md)、[02 余命与记忆](02-economy-lifespan-memory.md)、[03 密令](03-mandate.md)、[04 回响](04-echo.md)、[06 死亡与轮回](06-death-and-recurrence.md)

---

## 1. 设计问题陈述

原始构想是"玩家可以创建关卡，也可以参与别人的关卡"。这是一个**平台**，不是一个**游戏**——
它缺少让玩家明天还想登录的理由。

本文档解决的就是这个问题：**用三层嵌套的目标结构，把每一次点击都接到一个更大的欲望上。**

| 层 | 时长 | 玩家在想什么 | 核心机制 |
|---|---|---|---|
| 短期 | 20–40 分钟 | "这一局我要怎么赢" | **密令** |
| 中期 | 3–8 小时 | "我要打通这一轮回" | **十日 + 余命** |
| 长期 | 数十小时 | "我到底是谁 / 我要成为什么" | **记忆碎片 · 回响 · 权柄** |

---

## 2. 短期循环：一局关卡（20–40 分钟）

### 2.1 单局流程

```
⓪ 选关          在大世界中走到某栋建筑前，读公示牌：类型 / 难度·死亡率 / 人数 / 门票
       ↓        看不到规则修正件、密令池与主持人——选关本身就是一次信息不全的赌博
① 入场          支付门票（余命），进入 N 人房间（人数由关卡设定，不足由 AI 编号补位）
       ↓
② 规则宣读      生肖（或 AI 生肖）宣布本关规则 + 已激活的规则修正件
       ↓
③ 密令发放      每人私下收到 1 条密令。只有自己可见
       ↓
④ 博弈回合      基础玩法模板驱动（下注/发言/投票/拍卖…）
       ↓        规则修正件在触发点介入
       ↓        玩家可发动回响（一旦发动即永久暴露）
       ↓
⑤ 出局处理      出局者立刻转入观测者态，继续下注与传信
       ↓
⑥ 结算          余命瓜分 + 密令达成分成 + 生肖收成计算
       ↓
⑦ 死者刻印      彻底出局者写下刻印，留给未来的人
```

### 2.2 短期目标为什么是"密令"而不是"胜负"

这是整套设计的第一块基石。

如果一局的目标只有"赢"，那么德州就只是德州，投票放逐就只是投票放逐——UGC 再多也是同质的。

**密令让 10 个人在同一张桌子上玩 10 个不同的游戏：**

| 编号 | 公开目标 | 密令 |
|---|---|---|
| 011 | 赢下这局 | 让 7 号在你之前出局 |
| 043 | 赢下这局 | 全程不主动加注，并活到最后 |
| 077 | 赢下这局 | 保护 3 号存活，即使你自己出局也算完成 |
| 108 | 赢下这局 | 使某位玩家的余命归零 |

于是必然产生：**结盟、交易、试探、背叛、伪装**。
公开规则由关卡规则本身裁决（不可争议），密令负责生产叙事（不可预测）。

> 详见 [03 密令系统](03-mandate.md)。

### 2.3 单局张力曲线设计目标

| 阶段 | 占比 | 应有的情绪 |
|---|---|---|
| 规则宣读 | 10% | 评估：这关我能怎么玩 |
| 前期试探 | 25% | 观察：谁在装傻，谁在拉人 |
| 中期结盟 | 30% | 投入：我押谁 |
| 后期崩解 | 25% | 背叛：密令开始互斥，联盟必然破裂 |
| 结算 | 10% | 揭晓：原来他的密令是这个 |

**结算必须公开所有密令**——这是每局最强的一击。玩家会立刻回放整局，理解"原来他当时那句话是为了这个"。

## 3. 中期循环：一次轮回（十日）

### 3.1 昼夜双相

```
      ┌─────────────────┐         ┌─────────────────┐
      │   白天 · 庇护所  │  ────▶  │   夜晚 · 关卡    │
      │  2D 像素可走动   │         │   N 人博弈       │
      │                 │  ◀────  │                 │
      │ 交易 / 结盟      │         │ 押注 / 密令      │
      │ 情报 / 道具      │         │ 回响 / 出局      │
      │ 查看刻印与档案   │         │ 观测者 / 结算    │
      └─────────────────┘         └─────────────────┘
              ↑                            │
              └──────── ×10 日 ────────────┘
                            │
                            ▼
                    第 10 日 · 终焉关卡
                            │
                            ▼
              结算 → 挑选记忆碎片 → 写刻印 → 新轮回
```

**白天相不是过场，是第二个玩法层**：密令在这里被交易、联盟在这里被建立、情报在这里被贩卖。
很多局的胜负，在进关卡之前就已经定了。

### 3.2 "日"的定义（关键决策 D-06）

> **"第几日"= 你这一轮回打到第几关，不是现实的第几天。**

一次轮回就是一次 roguelike run。手快的人一晚上打完，慢的人打一周。
**你死了，立刻开新轮回，零等待。**

这条决策直接消灭了"第一天死了要硬等十天"的流失死局。详见 [06](06-death-and-recurrence.md)。

### 3.3 日层难度曲线

| 层 | 日数 | 定位 | 目标致死率 |
|---|---|---|---|
| **试炼层** | 1–3 日 | 教学 / 筛选 | **< 8%** |
| **倾轧层** | 4–6 日 | 结盟与背叛成形 | ~25% |
| **崩坏层** | 7–9 日 | 高压，密令互斥度拉满 | 45%+ |
| **终焉** | 第 10 日 | 终局关卡 | 设计为"必有代价" |

只分 **4 个匹配层**而不是 10 层，是为了不把人口池切碎。

注意：**第 1 日几乎不会死人**。新手最容易挫败的时刻在数值上被前置消除了。

## 4. 长期循环：三条并行进度轴

短期靠密令，中期靠十日，**长期必须有三条互相挤压的轴**，否则玩家会在第 5 个轮回退坑。

| 轴 | 驱动的欲望 | 载体 | 玩家的口头禅 |
|---|---|---|---|
| **生存轴** | 恐惧 | 余命、轮回次数、磨损 | "我这轮还剩 4 天" |
| **真相轴** | 好奇 | 记忆碎片 → 前史 → 终焉之地的真相 | "我想起来我是谁了" |
| **权柄轴** | 支配欲 | 回响觉醒 → 分化 → 晋升生肖 → 造关 | "下次轮到我定规矩" |

### 4.1 三轴共用一套资源，因此必然互相挤压

这是整个长期设计的心脏：

```
              ┌──────────────┐
              │   记忆碎片    │
              └──┬────────┬──┘
                 │        │
        燃烧掉    │        │  积累起
                 ▼        ▼
          ┌──────────┐  ┌──────────┐
          │ 发动回响  │  │  拼出前史 │
          │ = 活下去  │  │ = 逼近真相│
          └──────────┘  └──────────┘
                 ↑            │
                 └── 前史决定你的回响是什么 ──┘
```

于是每一轮回，每个玩家都要回答同一个问题：

> **我现在烧掉记忆活下去，还是保留记忆去逼近真相？**

- **求生型玩家**：轮回次数多，但永远在原地打转，什么都不记得，每一轮都是"第一次"。
- **求真型玩家**：死得快，但每一轮都比上一轮更接近答案。

这两种玩家在庇护所里会互相鄙视，也会互相需要——**天然的社交对立与交易**。
而且它顺带解释了世界观：为什么有人轮回了几百次还没逃出去？**因为他每次都为了活命烧光了记忆。**

### 4.2 权柄轴的完整路径

```
失忆的编号
   │ 行为被系统观测
   ▼
记忆碎片 → 前史浮现
   │ 创伤类型 × 应对方式
   ▼
执念成型（32 种组合之一）
   │ 决定归属十二权柄中的哪一系
   ▼
遇到与前史共振的绝境 → 回响觉醒
   │ 触发条件越苛刻 → 阶数越高
   ▼
多轮回中回响进化、分化
   │
   ▼
权柄成型，被终焉之地认可 → 晋升生肖
   │
   ▼
主持关卡 / 设计关卡包 / 追求收成
```

**你怎么受苦，决定你怎么折磨别人。** 这个闭环把玩家的游玩史变成了他的能力，也变成了他的创作风格。

> 详见 [04 回响](04-echo.md) 与 [05 十二权柄](05-zodiac-authority.md)。

## 5. 三层循环的咬合关系

| 从 | 到 | 咬合点 |
|---|---|---|
| 短期 → 中期 | 一局 → 轮回 | 每局的余命盈亏决定你能否撑到第 10 日 |
| 中期 → 长期 | 轮回 → 三轴 | 轮回结算时**挑选**带走的记忆碎片（主动取舍） |
| 长期 → 短期 | 三轴 → 一局 | 觉醒的回响是你下一局的底牌；前史决定你的密令倾向 |
| 长期 → 平台 | 权柄轴 → UGC | 晋升生肖后可造关，你的关卡带着你的执念气质 |

**没有单向的循环**。每一层都往上供给，也从上层取回反馈。

## 6. 首次会话（新玩家的前 60 分钟）

留存的成败在这一小时里决定。设计目标：

| 时间 | 玩家经历 | 我们要传达的 |
|---|---|---|
| 0–5 min | 无名醒来，被告知你是"编号 XXX"，没有过去 | 神秘感 + 身份代入 |
| 5–10 min | 庇护所短暂探索，遇到一个 AI 编号搭话 | 世界观 + 操作教学 |
| 10–35 min | **第 1 日关卡**（低致死率），拿到第一条密令 | **核心乐趣：密令带来的双重目标** |
| 35–40 min | 结算，全场密令公开，回放"原来他是为了这个" | **啊哈时刻** |
| 40–50 min | 第 2 日关卡，开始有人被淘汰 | 压力上升 |
| 50–60 min | 拿到第一枚记忆碎片，看到自己前史的第一个模糊片段 | **长期钩子** |

**硬性要求**：新玩家必须在 40 分钟内经历一次"结算揭晓密令"的震撼，
并在 60 分钟内看到一枚指向"你是谁"的记忆碎片。达不到就是首次会话设计失败。

---

## 7. 会话粒度与时长预算

| 单位 | 目标时长 | 可中断性 |
|---|---|---|
| 一局关卡 | 20–40 分钟 | **不可中断**（掉线转 AI 托管 + 余命惩罚） |
| 白天相 | 5–15 分钟 | 可随时离开 |
| 一次轮回 | 3–8 小时（可跨多次登录） | 完全可中断，进度持久化 |
| 一次登录 | 45–90 分钟（1 日 + 白天，或 2 日） | — |

**设计约束**：绝不能出现"必须连续在线 2 小时"的内容。轮回进度必须能随时挂起。

---

## 8. 循环健康度指标（上线后监控）

| 指标 | 目标 | 说明 |
|---|---|---|
| 单局完成率 | > 85% | 中途退出率过高 = 局内张力失败 |
| 密令达成率 | 35–55% | 太高则无张力，太低则挫败 |
| 结算揭晓后的重看率 | > 30% | 衡量"啊哈时刻"是否成立 |
| 轮回完成率（打到第 10 日） | 15–25% | 太高说明太简单 |
| 死亡后 5 分钟内重开率 | > 60% | 衡量"零冷却重开"是否真的留住了人 |
| 首个记忆碎片获取率（新玩家） | > 80% | 长期钩子的挂钩成功率 |
| 第 7 日回访率 | > 25% | 长期轴是否起效 |

## 9. 未决问题

1. **白天相的时长**：庇护所做成"可无限停留的社交空间"还是"限时准备阶段"？前者利于社交沉淀，后者利于节奏紧凑。倾向：前 3 日限时（教学），之后开放。
2. **密令是否每局重发**：还是一条密令可跨越多个日、直到达成或失败？跨日密令叙事更强，但判定复杂度与串通风险上升。
3. **单局 20–40 分钟是否过长**：对移动端与碎片时间极不友好。是否需要一个 10 分钟的"短关卡"模板池？
4. **轮回失败后的进度惩罚**：目前只有"记忆继承上限 + 意识涣散"。是否需要更硬的惩罚来维持恐惧感？还是恐惧应完全由局内提供？
5. **三轴的进度是否需要显式 UI**：显式化利于目标感，但会破坏"失忆者"的沉浸。倾向：真相轴显式，权柄轴半隐（只给方向不给答案），生存轴完全显式。
