# 01 · 核心循环

> 状态：核心规格 v0.3 ｜ 真源：玩家循环与时间单位

## 已锁定规则

- 一局关卡时长目标为 20–40 分钟；关卡人数由关卡包在 4–16 人范围内设定。
- 一次轮回由连续 10 关构成；“日”只表示个人轮回进度。
- 关卡之间是庇护所：交易、情报、准备与关系延续发生在这里。
- 回响在特定情景下激活，激活后可在**当前轮回**的合法时机发动；新轮回开始即清空。
- 出局与轮回结算的具体处理未定，不得在其他文档假设其行为。

## 一局关卡

```text
入场并支付门票
  → 宣读规则、修正件与压制配置
  → 私下发放密令
  → 进行模板规定的博弈回合
       ├─ 修正件在其规则时机自动介入
       └─ 情景满足时，回响激活；玩家决定是否发动
  → 结算余命、密令、公开信息与关卡结果
  → 出局处理〔待定〕 / 返回庇护所
```

### 局内目标

| 层次 | 玩家关心的问题 | 主要机制 |
|---|---|---|
| 生存 | 我会不会在本轮回结束前归零？ | 余命、押注、关卡结果 |
| 私利 | 我怎样完成自己的目标？ | 密令、隐瞒、交易、背叛 |
| 翻盘 | 我现在要不要亮底牌？ | 回响主动发动、压制、暴露 |

密令而非统一胜负条件是局内张力来源；公开合作可以存在，但永远无法确定对方的真正收益。

## 一次轮回：十日

| 阶段 | 关卡 | 目的 |
|---|---:|---|
| 试探层 | 1–3 日 | 学规则、形成初步关系与情报 |
| 倾轧层 | 4–6 日 | 密令冲突上升，交易与结盟成形 |
| 崩坏层 | 7–9 日 | 押注、压制与互斥密令加压 |
| 终焉 | 第 10 日 | 终局关卡；具体结算后果待定 |

庇护所不承担第二套玩法；它只承接关卡外的交易、关系、情报和下一关准备。

## 三条长期轴

| 轴 | 资源与产物 | 本轮回内的表现 |
|---|---|---|
| 生存 | 余命、轮回次数 | 是否撑过十日 |
| 真相 | 记忆碎片、前史 | 逐步知道自己是谁 |
| 权柄 | 执念与回响形状 | 在共振情景下重新激活回响 |

三轴共享记忆碎片：烧记忆发动回响，会同时牺牲燃料、真相与前史拼图。

```text
行为被观测 → 前史碎片 → 执念 / 回响形状
                     ↓
当前轮回的共振情景 → 激活 → 玩家主动发动或放弃 → 下一轮回重置
```

权柄只代表回响的最高阶，不代表造关权限；造关始终对所有玩家开放。

## 首次会话目标

第一小时至少让新玩家经历一次：拿到密令、因密令怀疑他人、做出一次有代价的余命选择、看见或经历一次回响激活。首次濒死可播放“觉醒”演出，但演出后仍由玩家决定是否发动。

## 指标与未决项

上线后监控入场完成率、密令达成率、余命归零率、回响激活/发动率与轮回完成率。死亡、轮回结算、大终焉和具体数值见 [06](06-death-and-recurrence.md)、[09](09-open-questions.md)。
