# 00 · 高概念与术语

> 状态：核心规格 v0.3 ｜ 真源：产品定位与全局术语
>
> 规则细节分别见：[01 核心循环](01-core-loop.md)、[04 回响](04-echo.md)、[07 关卡](07-level-design.md)。

## 一句话高概念

《终焉之地》是一款 4–16 人的多人社交博弈 + UGC 关卡平台：失忆的编号在十日轮回中押上余命、完成私密密令，并在与前史共振的情景下激活只属于当前轮回的回响。

## 已锁定的产品规则

| 主题 | 规则 |
|---|---|
| 对局 | 关卡由创作者设定人数；每名编号持有一条仅自己可见的密令 |
| 货币 | 余命是唯一硬通货，用于入场、押注、交易、买地与维护地块 |
| 关卡经济 | 每关收取固定门票并声明回收等级；等级值 = 门票 + 规则回收余命 + 规则致死数 × 10，回收越高，赢家奖励越丰富 |
| 完美通关 | 每关必须有一条与关卡真实目标同源的隐藏正收益路径；玩家从反馈中推理，正确执行后获得概率判定 |
| 回响 | 情景**激活**回响，不自动发动；玩家主动使用；激活只持续当前轮回，下轮回重置为普通编号 |
| 成长 | 记忆、前史与回响形状可以构成长线；不传递可直接使用的力量 |
| 阵营 | 普通编号没有阵营，避免出现“人类共同最优解” |
| UGC | 所有人都能造关、主持自己的关卡；门槛是地块与余命，不是身份或阶数 |
| 公平 | 创建者不得以编号身份进入自己的关卡 |
| 裁决 | 规则决定胜负；主持人只在预先声明的裁量清单内叙事或裁量 |
| AI | AI 编号用于补位；AI 回响方案仍待定 |
| 死亡 | 出局后的行动、轮回结算与重开代价均未定案，见 [06](06-death-and-recurrence.md) |

## 三个设计支柱

1. **秘密制造猜疑**：同一张桌上，每个人的目标不同。
2. **规则可以被玩**：密令、修正件与回响都只改变可判定的规则结构。
3. **长线不制造常驻强者**：前史塑造风格；每个新轮回仍从普通编号开始。

## 术语

本节是**平台级术语的唯一定义处**。其他文档使用这些词时不再重复定义，只补充规则细节。

T-11 模板专属的词（灾痕、承担值、协商轮、失守、公开承诺认可）见 [12 · 最后提案](12-t11-last-proposal.md#本关术语)；它们只在该模板内成立，不是平台词汇。

### 身份与时间

| 术语 | 定义 |
|---|---|
| 编号 | 普通玩家身份；没有阵营 |
| 关卡 | 一局规则博弈，20–40 分钟；人数由关卡包设定 |
| 轮回 | 一次完整流程，连续 10 个关卡，即“十日” |
| 日 | 轮回内的关卡进度，不是现实时间 |
| 庇护所 | 两关之间的场所，承接交易、情报、关系与下一关准备 |
| 主持人 | 关卡的叙事与裁量执行者，不裁判胜负 |

### 资源

| 术语 | 定义 |
|---|---|
| 余命 | 唯一硬通货；归零意味着本轮回结束，后续处理待定 |
| 记忆碎片 | 碎片的总称。真相进度、回响燃料、前史拼图三者共用同一份资源，共用发生在花掉的时候 |
| 前史碎片 | 归属于某条回响前史的碎片；决定该回响的找回度 |
| 真相轴碎片 | 归属于真相轴的碎片；推进“我是谁”，不属于任何单条回响 |
| 找回度 | 某条回响的前史已持有碎片数 ÷ 该前史碎片总数；按回响独立计算 |
| 渴望值 | 按创伤分池累积的量，只由真实损失产生，不能购买或靠送死刷取 |

### 前史与回响

| 术语 | 定义 |
|---|---|
| 前史 | 编号失忆前的一段经历，写成普通人能共情的伤口；以具名碎片逐步找回 |
| 回响 | 前史伤口与当前情景共振后，暂时开放给玩家的一次规则例外权 |
| 回响形状 | 由前史与执念决定的长期能力方向；跨轮回保留，不等于本轮回可用的回响 |
| 执念格 | 创伤 W1–W8 × 应对 R1–R4 的坐标；W 给伤口，R 给应对方式 |
| **激活** | 条件全部成立，回响变为**可用**。不自动生效 |
| **发动** | 玩家在合法时机主动确认使用已激活的回响并支付燃料 |
| 阶 | 回响强度分档：L0 既视感 / L1 微响 / L2 回响 / L3 共鸣 / L4 权柄 |
| 觉醒 / 辨认 / 掌握 | 三次有效共振后逐层揭示触发路径的三个阶段；跨轮回保留的是这份理解进度 |
| 语义锚点 | 跨模板通用的抽象效果，形如“动词·对象·阶”；由模板负责实现 |
| 情境谓词 | 模板声明的客观状态；回响激活条件只能引用词表内的谓词 |
| 压制 | 关卡对回响的限制：封锁动词族、提高发动成本或设置绝缘区 |

### 关卡与经济

| 术语 | 定义 |
|---|---|
| 密令 | 局内隐藏目标；每名编号一条，默认只对本人可见 |
| 关卡包 | 一个可上架的关卡配置：模板 + 修正件 + 密令池 + 压制 + 主持人配置 + 经济参数 |
| 规则修正件 | 关卡包中的预制规则组件，不能由作者自由编写条文 |
| 地块 | 造关前置资产；核心区有限昂贵、外围无限便宜 |
| 回收等级 | `固定门票 + 规则回收余命 + 规则致死数 × 10`；决定风险档与奖励丰富度 |
| 系统净回收 | `固定门票 + 规则回收余命 − 系统发放余命`；用于观察经济通胀 |
| 完美通关 | 每关必须存在的隐藏正收益路径，全体玩家从系统所得超过全体门票与损失之和 |
| 潜规则 | 完美通关的完整条件与检测逻辑；只存在于模板内部规格与 GM 工具，不向玩家公布 |
| 完美判定 | 玩家执行正确方向后获得的概率判定；执行越完整概率越高 |
| 裁量清单 | 关卡包预先声明的、主持人可执行的动作范围 |
| 收成 | 主持人与关卡作者的收益 |

### 记录与推断

| 术语 | 定义 |
|---|---|
| 规则事件流 | 可复算整局的判定事实流；结算、激活判定只读它 |
| 行为语料流 | 公开发言、私聊与语音转写；只供局后推断，不进入任何判定 |
| 执念倾向增量 | 局后小模型产出的形状移动量，带证据引用；对玩家不可见 |

### 三组容易混淆的词

- **激活 ≠ 发动。** 激活是系统判定的结果，发动是玩家的选择。不发动没有任何成本。
- **“共鸣”有两个意思。** 一是激活条件里的共鸣类条款（当前情景重演前史结构），二是 L3 阶的名称。前者写条件，后者写强度，按上下文区分。
- **记忆碎片是总称。** 前史碎片与真相轴碎片是它的两种归属，玩家不能选归属，但发动时可以选烧哪一处。

## 明确不做

- 数值成长、装备碾压或跨轮回携带可用回响。
- 人类阵营 / 主持人阵营对抗。
- 由主持人主观判定胜负。
- 创作者撰写无法客观判定的自由规则。
- 将死亡后机制假定为已经设计完成。
