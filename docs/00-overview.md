# 00 · 高概念与设计支柱

> 状态：草案 v0.2 ｜ 关联：[索引](README.md)、[01 核心循环](01-core-loop.md)、[04 回响](04-echo.md)、[05 无阵营与主持人](05-authority-and-ascension.md)
>
> **v0.2 变更**：① 死亡如何处理**整体待定**（见 [06](06-death-and-recurrence.md)），
> 本文档中依赖它的地方一律标 〔待定〕；② **造关与主持是所有玩家的通用能力**，
> 不再是权柄轴的终点（见 [05 §5](05-authority-and-ascension.md)）。

---

## 1. 一句话高概念

> **一群失忆的人被困在终焉之地，被迫在彼此设计的规则里互相博弈；
> 你能带走的只有记忆，而记忆同时也是你唯一的力量燃料。**

## 2. 三句话产品定位

1. 这是一个 **多人局的社交博弈游戏**（单局人数由关卡设计者定义），玩法核心是**信息差与人性抉择**，不是操作。
2. 关卡由**玩家自己组合规则**产出（UGC），平台提供打磨过的基础玩法与规则零件。
3. 长期驱动力来自**找回你自己是谁**——真相轴与超能力（回响）是同一套资源。

---

## 3. 我们要避开的三个坑

这一节比任何设计都重要。整套框架就是为了绕开它们。

### 坑 1：UGC 会退化成"棋牌室"

玩家自建德州、狼人、21 点……最后平台变成一堆规则微调的桌游合集，毫无气质。

> **对策**：[密令系统](03-mandate.md)。同一张牌桌上 N 个人有 N 个互斥的胜利条件，
> 任何平庸玩法都会自动长出叙事、结盟、背叛与猜疑。

### 坑 2：开局人数门槛 = 冷启动死局

关卡人数由作者定义，多数有意思的模板要 8 人以上。凑不齐，门就永远打不开，新人第一次登录就流失。

> **对策**：[AI 编号补位](08-host-and-ugc.md)。由外部模型扮演终焉之地的居民，有性格、有密令、会撒谎。
> 这在世界观里完全成立，**不是妥协，是设定**。

### 坑 3：淘汰即离场

死亡游戏最爽的是"死了还要看别人死"，但被淘汰的玩家干坐着就会退出。

> **对策：〔待定〕。** 这个坑是真的，但填它的方案还没定，见 [06](06-death-and-recurrence.md)。
> **在方案定下来之前，任何声称"死亡不是结束"的设计都不成立。**

---

## 4. 三条设计支柱

所有系统都必须能回答"我在支撑哪一条支柱"。不能回答的系统一律砍掉。

| 支柱 | 含义 | 系统落点 |
|---|---|---|
| **规则是可以被玩弄的** | 规则是玩具，不是围栏 | 规则修正件、回响的"规则例外权"、诡辩类回响 |
| **每个人都有不能说的秘密** | 同一场局里，每个人赢的定义不同 | **密令系统**、前史、回响的隐藏性 |
| **死亡不是结束，是轮回** 〔待定〕 | 长期目标的载体。**支柱本身保留，落点全部待定**，见 [06](06-death-and-recurrence.md) | 余命经济、十日轮回、记忆碎片 |

---

## 5. 玩家幻想（Player Fantasy）

我们卖给玩家的三种感觉，按优先级排序：

1. **"我看穿了他。"** —— 在信息不全的情况下做出正确判断的智力快感。
2. **"我想起来了。"** —— 记忆碎片拼合、前史浮现，以及首次激活回响时的叙事高潮。
3. **"现在轮到我定规矩了。"** —— 设计关卡、主持它、看着别人在你的规则里挣扎。
   **这件事不需要解锁**：任何玩家随时都可以造关并成为自己关卡的主持人，成本只有余命。

**我们不卖**：操作技巧、数值成长、装备收集。这些一律不做，做了会稀释前三种。

---

## 6. 目标受众

| 层 | 画像 | 他们为什么留下 |
|---|---|---|
| 核心 | 狼人杀 / 剧本杀 / Among Us / 无限流小说读者 | 社交博弈 + 世界观气质 |
| 次核心 | Roguelike 与叙事解谜玩家 | 轮回结构 + 真相轴 |
| 创作者 | 桌游设计爱好者、TRPG KP、模组作者 | **造关与主持从第一天起就对他们开放**，不必先擅长博弈 |

创作者层是这个平台的内容供给命脉，所有 UGC 设计优先服务他们。
**这也是造关不设身份门槛的根本原因**：门槛会把这一层直接挡在外面（见 [05 §5.1](05-authority-and-ascension.md)）。

## 8. 术语表（全项目统一，不得自创同义词）

> **已从术语表移除**：观测者、刻印、磨损、回溯。它们全部属于尚未设计的死亡逻辑，
> 在 [06](06-death-and-recurrence.md) 定案之前不是本项目的术语，**不要在任何文档里使用**。

### 世界与身份

| 术语 | 定义 |
|---|---|
| **终焉之地** | 游戏世界。玩家被困于此，被迫参与关卡 |
| **编号** | 普通玩家的身份。**没有阵营**，只有编号（如"043"） |
| **主持人** | 关卡的主持者与执行者，规则的化身。**不参与生死博弈**，胜利条件是"收成"。裁量范围由本关的**裁量清单**限定。**任何玩家创建关卡即成为该关主持人，无门槛**；但不得以编号身份参与自己的关卡。世界观称谓待定 |
| **AI 编号** | LLM 扮演的补位 NPC。有性格、有密令、会撒谎 |
| **前史** | 你进入终焉之地之前的人生。开局失忆，靠记忆碎片一片片找回 |

### 玩法单位

| 术语 | 定义 |
|---|---|
| **关卡** | 一局对局。**人数由关卡设计者在模板区间内设定**，20–40 分钟。入口是大世界中的一栋建筑 |
| **轮回** | 一次完整 run = 连续 10 个关卡 = "十日" |
| **日** | **关卡进度，不是现实时间**。"第 7 日"= 本轮回的第 7 关 |
| **庇护所** | 关卡之间的白天相。2D 像素可走动场景：交易、结盟、情报、准备 |
| **地块** | 大世界里的一块地，**造关的前置条件**。买地需大额余命，持有需周期性维护费 |
| **核心区 / 外围** | 地块的两个分区。核心区**总量有限**、地价极高、人流大；外围**无限供应**、便宜、人流小 |
| **大终焉** | 每周/每月一次的全服同步终局事件，承载赛季高潮与主线 |

### 资源

| 术语 | 定义 |
|---|---|
| **余命** | **唯一硬通货**，单位"日"。押注、交易、道具、买地与地块维护费全用它。归零 = 本轮回结束（后续处理〔待定〕） |
| **记忆碎片** | 第二资源，**三重身份**：真相轴进度 / 回响的燃料 / 前史的拼图 |

### 核心机制

| 术语 | 定义 |
|---|---|
| **密令** | 局内隐藏目标，只有自己可见。N 人 = N 个互斥胜利条件 |
| **回响** | 玩家超能力。**由与前史创伤共振的特定情景激活，激活后由玩家主动选择是否发动**。稀有，人人有机会 |
| **既视感 / 微响 / 回响 / 共鸣 / 权柄** | 回响的 0–4 阶。按"能触及规则的哪一层"分级 |
| **执念** | 创伤类型 × 应对方式，决定你的回响长成什么样 |
| **执念格** | 创伤 W1–W8 × 应对 R1–R4 = 32 格。**回响的全部分类**，不再往上归类 |
| **裁量清单** | 关卡上架时声明的、本关主持人被允许做的事。清单之外的裁量一律无效 |
| **既视感 / 微响 / 回响 / 共鸣 / 权柄** 的四阶 | 「权柄」**只是回响的最高阶**，不是主持人身份，见 [05 §5.3](05-authority-and-ascension.md) |

### 平台与内容

| 术语 | 定义 |
|---|---|
| **基础玩法模板** | 官方打磨的玩法骨架，胜负判定清晰无争议（暗账、投票放逐、契约谈判……）。**准入判据是"能不能让人露出本性"**，见 [07 §2.2](07-level-design.md) |
| **规则修正件** | UGC 的原子零件 = 触发器 + 条件 + 效果。按**效果层级 L1–L4** 组织 |
| **关卡包** | 基础玩法模板 + 规则修正件 + 主持人人格 + 密令池 + 压制配置 |
| **压制** | 关卡对回响的封锁配置（封锁某类 / 代价翻倍 / 绝缘区）。是难度维度，但**不在入口公示**，只在进场后宣读 |
| **公示牌** | 关卡建筑门口的四项信息：类型 / 难度·死亡率 / 人数 / 门票。除此之外一概不给 |
| **收成** | 主持人的胜利指标：余命流转量、背叛次数、评分、通过率健康度（原「观看时长」一项随死亡逻辑〔待定〕）|

## 9. 明确不做的事

| 不做 | 原因 |
|---|---|
| 人类阵营 / 双阵营对抗 | 会制造虚假团队感，**杀死猜疑链**，见 [05](05-authority-and-ascension.md) |
| 数值成长（攻击力、等级、装备） | 稀释智力快感，且让老玩家碾压新人 |
| 回响传递"力量"跨轮回 | **不传递任何力量**：激活状态与未用次数在新轮回全部清空；可能保留的只是信息与关系记忆 |
| 让主持人决定胜负 | 那样"说服主持人"就成了最优解，见 [08](08-host-and-ugc.md) |
| 让创作者自由撰写规则条文 | 无法被客观判定的规则必然引发争议，见 [07](07-level-design.md) |
| 全服现实时间十日赛季 | 第一天死了要硬等十天。"日是个人进度轴"见 [01 §3.2](01-core-loop.md) |
| **给造关设身份门槛** | 门槛会掐断内容供给，且筛的是"擅长博弈"而不是"擅长设计"，见 [05 §5.1](05-authority-and-ascension.md)。**经济门槛（买地）不在此列**——它筛的是"愿不愿押上东西"，对新人老手是同一句话 |
| **让外围的地也变稀缺** | 一旦外围也抢不到，"造关是通用能力"就名存实亡，见 [07 §4.2](07-level-design.md) |
| **第二种货币** | 余命是唯一硬通货。多货币要求玩家先学汇率表，会稀释压迫感，见 [02 §1.1](02-economy-lifespan-memory.md) |
| 3D 场景化 | 90% 的体验在信息呈现，3D 只会稀释它 |

## 10. 未决问题

1. **世界观授权边界**：本作气质取自"十日终焉"，但术语、角色、剧情必须完全原创。是否需要在立项阶段做一次对照排查？
2. **商业模式**：目前所有设计都刻意避开付费强度（回响不可购买）。变现是走外观 / 赛季通行证 / 创作者分成抽佣，还是买断？这会反向影响余命经济。
3. **目标语言与市场**：中文为第一语言时世界观最顺，但 UGC 平台的规模效应依赖用户量。是否一开始就做双语关卡包结构？
4. **真相轴的终点**：终焉之地的"真相"必须有一个可抵达的答案吗？还是设计成永远后退的地平线？这决定了叙事内容的产能模型。
5. **死亡怎么处理**：整体待定，六个子问题见 [06](06-death-and-recurrence.md)。
   这是当前**唯一一块完全空白的核心设计**，它卡着支柱三、卡着 [02](02-economy-lifespan-memory.md) 的一半收支途径、
   也卡着 [05](05-authority-and-ascension.md) 收成指标里的一项权重。
