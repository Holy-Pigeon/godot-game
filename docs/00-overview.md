# 00 · 高概念与术语

> 状态：核心规格 v0.3 ｜ 真源：产品定位与全局术语
>
> 规则细节分别见：[01 核心循环](01-core-loop.md)、[04 回响](04-echo.md)、[07 关卡](07-level-design.md)。

## 一句话高概念

《终焉之地》是一款 4–16 人的多人社交博弈 + UGC 关卡平台：失忆的编号在十日轮回中押上余命、完成私密密令，并在与前史共振的情景下激活只属于当前轮回的回响。

## 已锁定的产品规则

| 主题 | 规则 |
|---|---|
| 对局 | 关卡由创作者设定人数；每名编号持有一条仅自己可见的密令 |
| 货币 | 余命是唯一硬通货，用于入场、押注、交易、买地与维护地块 |
| 回响 | 情景**激活**回响，不自动发动；玩家主动使用；激活只持续当前轮回，下轮回重置为普通编号 |
| 成长 | 记忆、前史与回响形状可以构成长线；不传递可直接使用的力量 |
| 阵营 | 普通编号没有阵营，避免出现“人类共同最优解” |
| UGC | 所有人都能造关、主持自己的关卡；门槛是地块与余命，不是身份或阶数 |
| 公平 | 创建者不得以编号身份进入自己的关卡 |
| 裁决 | 规则决定胜负；主持人只在预先声明的裁量清单内叙事或裁量 |
| AI | AI 编号用于补位；AI 回响方案仍待定 |
| 死亡 | 出局后的行动、轮回结算与重开代价均未定案，见 [06](06-death-and-recurrence.md) |

## 三个设计支柱

1. **秘密制造猜疑**：同一张桌上，每个人的目标不同。
2. **规则可以被玩**：密令、修正件与回响都只改变可判定的规则结构。
3. **长线不制造常驻强者**：前史塑造风格；每个新轮回仍从普通编号开始。

## 术语

| 术语 | 定义 |
|---|---|
| 编号 | 普通玩家身份；没有阵营 |
| 关卡 | 一局规则博弈，20–40 分钟；人数由关卡包设定 |
| 轮回 | 一次完整 run，连续 10 个关卡，即“十日” |
| 日 | 轮回内的关卡进度，不是现实时间 |
| 余命 | 唯一硬通货；归零意味着本轮回结束，后续处理待定 |
| 记忆碎片 | 真相进度、回响燃料、前史拼图三者共用的资源 |
| 密令 | 局内隐藏目标；每名编号一条，默认只对本人可见 |
| 回响 | 前史与当下情景共振后激活的规则例外权；是否发动由玩家决定 |
| 回响形状 | 由前史与执念决定的长期能力方向；不等于本轮回可用的回响 |
| 执念格 | 创伤 W1–W8 × 应对 R1–R4，回响的分类坐标 |
| 主持人 | 关卡的叙事与裁量执行者，不裁判胜负 |
| 地块 | 造关前置资产；核心区有限昂贵、外围无限便宜 |
| 规则修正件 | 关卡包中的预制规则组件，不能由作者自由编写条文 |
| 情境谓词 | 模板声明的客观状态；回响以此判断能否激活 |

## 明确不做

- 数值成长、装备碾压或跨轮回携带可用回响。
- 人类阵营 / 主持人阵营对抗。
- 由主持人主观判定胜负。
- 创作者撰写无法客观判定的自由规则。
- 将死亡后机制假定为已经设计完成。
