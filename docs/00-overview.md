# 00 · 高概念与设计支柱

> 状态：草案 v0.1 ｜ 关联：[索引](README.md)、[01 核心循环](01-core-loop.md)、[04 回响](04-echo.md)、[05 权柄轴与晋升](05-authority-and-ascension.md)

---

## 1. 一句话高概念

> **一群失忆的人被困在终焉之地，被迫在彼此设计的规则里互相博弈；
> 你能带走的只有记忆，而记忆同时也是你唯一的力量燃料。**

## 2. 三句话产品定位

1. 这是一个 **多人局的社交博弈游戏**（单局人数由关卡设计者定义），玩法核心是**信息差与人性抉择**，不是操作。
2. 关卡由**玩家自己组合规则**产出（UGC），平台提供打磨过的基础玩法与规则零件。
3. 长期驱动力来自**找回你自己是谁**——真相轴与超能力（回响）是同一套资源。

---

## 3. 我们要避开的三个坑

这一节比任何设计都重要。整套框架就是为了绕开它们。

### 坑 1：UGC 会退化成"棋牌室"

玩家自建德州、狼人、21 点……最后平台变成一堆规则微调的桌游合集，毫无气质。

> **对策**：[密令系统](03-mandate.md)。同一张牌桌上 N 个人有 N 个互斥的胜利条件，
> 任何平庸玩法都会自动长出叙事、结盟、背叛与猜疑。

### 坑 2：开局人数门槛 = 冷启动死局

关卡人数由作者定义，多数有意思的模板要 8 人以上。凑不齐，门就永远打不开，新人第一次登录就流失。

> **对策**：[AI 编号补位](08-host-and-ugc.md)。由外部模型扮演终焉之地的居民，有性格、有密令、会撒谎。
> 这在世界观里完全成立，**不是妥协，是设定**。

### 坑 3：淘汰即离场

死亡游戏最爽的是"死了还要看别人死"，但被淘汰的玩家干坐着就会退出。

> **对策**：[观测者态与三层缓冲](06-death-and-recurrence.md)。出局者变成亡魂，
> 能看到部分隐藏信息、能下注、能传递一条真假难辨的信息。**死亡解锁新的博弈层**。

---

## 4. 三条设计支柱

所有系统都必须能回答"我在支撑哪一条支柱"。不能回答的系统一律砍掉。

| 支柱 | 含义 | 系统落点 |
|---|---|---|
| **规则是可以被玩弄的** | 规则是玩具，不是围栏 | 规则修正件、回响的"规则例外权"、诡辩类回响 |
| **每个人都有不能说的秘密** | 同一场局里，每个人赢的定义不同 | **密令系统**、前史、回响的隐藏性 |
| **死亡不是结束，是轮回** | 长期目标的载体 | 余命经济、十日轮回、记忆碎片、磨损 |

---

## 5. 玩家幻想（Player Fantasy）

我们卖给玩家的三种感觉，按优先级排序：

1. **"我看穿了他。"** —— 在信息不全的情况下做出正确判断的智力快感。
2. **"我想起来了。"** —— 记忆碎片拼合、前史浮现、回响觉醒的叙事高潮。
3. **"现在轮到我定规矩了。"** —— 晋升主持人、设计关卡、看着别人在你的规则里挣扎。

**我们不卖**：操作技巧、数值成长、装备收集。这些一律不做，做了会稀释前三种。

---

## 6. 目标受众

| 层 | 画像 | 他们为什么留下 |
|---|---|---|
| 核心 | 狼人杀 / 剧本杀 / Among Us / 无限流小说读者 | 社交博弈 + 世界观气质 |
| 次核心 | Roguelike 与叙事解谜玩家 | 轮回结构 + 真相轴 |
| 创作者 | 桌游设计爱好者、TRPG KP、模组作者 | **UGC 与晋升主持人**是他们的终生目标 |

创作者层是这个平台的内容供给命脉，所有 UGC 设计优先服务他们。

## 8. 术语表（全项目统一，不得自创同义词）

### 世界与身份

| 术语 | 定义 |
|---|---|
| **终焉之地** | 游戏世界。玩家被困于此，被迫参与关卡 |
| **编号** | 普通玩家的身份。**没有阵营**，只有编号（如"043"） |
| **主持人** | 关卡的主持者与执行者，规则的化身。**不参与生死博弈**，胜利条件是"收成"。裁量范围由本关的**裁量清单**限定。世界观称谓待定 |
| **AI 编号** | LLM 扮演的补位 NPC。有性格、有密令、会撒谎 |
| **前史** | 你进入终焉之地之前的人生。开局失忆，靠记忆碎片一片片找回 |

### 玩法单位

| 术语 | 定义 |
|---|---|
| **关卡** | 一局对局。**人数由关卡设计者在模板区间内设定**，20–40 分钟。入口是大世界中的一栋建筑 |
| **轮回** | 一次完整 run = 连续 10 个关卡 = "十日" |
| **日** | **关卡进度，不是现实时间**。"第 7 日"= 本轮回的第 7 关 |
| **庇护所** | 关卡之间的白天相。2D 像素可走动场景：交易、结盟、情报、准备 |
| **大终焉** | 每周/每月一次的全服同步终局事件，承载赛季高潮与主线 |

### 资源

| 术语 | 定义 |
|---|---|
| **余命** | **唯一硬通货**，单位"日"。押注、交易、道具、复活全用它。归零 = 本轮回死亡 |
| **记忆碎片** | 第二资源，**三重身份**：真相轴进度 / 回响的燃料 / 前史的拼图 |
| **磨损** | 轮回次数的叙事化。轮回越多，看到的世界越不同（**不是惩罚**） |
| **回溯** | 昂贵的复活道具。回到本轮回前一日，永久丢失部分记忆，并留下**公开可见**的污点 |

### 核心机制

| 术语 | 定义 |
|---|---|
| **密令** | 局内隐藏目标，只有自己可见。N 人 = N 个互斥胜利条件 |
| **回响** | 玩家超能力。**由绝境触发，必须与前史创伤共振**。稀有，人人有机会 |
| **既视感 / 微响 / 回响 / 共鸣 / 权柄** | 回响的 0–4 阶。按"能触及规则的哪一层"分级 |
| **执念** | 创伤类型 × 应对方式，决定你的回响归属哪一系 |
| **执念格** | 创伤 W1–W8 × 应对 R1–R4 = 32 格。**回响的全部分类**，不再往上归类 |
| **裁量清单** | 关卡上架时声明的、本关主持人被允许做的事。清单之外的裁量一律无效 |
| **刻印** | 死者**手工**留下的痕迹（墙上的字、录音、统计聚合）。**不是超能力**，别和回响混淆 |
| **观测者** | 本局出局后的亡魂态。可看隐藏信息、下注、传一条真假信息 |

### 平台与内容

| 术语 | 定义 |
|---|---|
| **基础玩法模板** | 官方打磨的玩法骨架，胜负判定清晰无争议（暗账、投票放逐、契约谈判……）。**准入判据是"能不能让人露出本性"**，见 [07 §2.2](07-level-design.md) |
| **规则修正件** | UGC 的原子零件 = 触发器 + 条件 + 效果。按**效果层级 L1–L4** 组织 |
| **关卡包** | 基础玩法模板 + 规则修正件 + 主持人人格 + 密令池 + 压制配置 |
| **压制** | 关卡对回响的封锁配置（封锁某类 / 代价翻倍 / 绝缘区）。是难度维度，但**不在入口公示**，只在进场后宣读 |
| **公示牌** | 关卡建筑门口的四项信息：类型 / 难度·死亡率 / 人数 / 门票。除此之外一概不给 |
| **收成** | 主持人的胜利指标：余命流转量、背叛次数、观看时长、评分、通过率健康度 |

## 9. 明确不做的事

| 不做 | 原因 |
|---|---|
| 人类阵营 / 双阵营对抗 | 会制造虚假团队感，**杀死猜疑链**，见 [05](05-authority-and-ascension.md) |
| 数值成长（攻击力、等级、装备） | 稀释智力快感，且让老玩家碾压新人 |
| 回响传递"力量"跨轮回 | 只能传递**信息与关系记忆**，否则 PvP 平衡崩坏 |
| 让主持人决定胜负 | 那样"说服主持人"就成了最优解，见 [08](08-host-and-ugc.md) |
| 让创作者自由撰写规则条文 | 无法被客观判定的规则必然引发争议，见 [07](07-level-design.md) |
| 全服现实时间十日赛季 | 第一天死了要硬等十天，见 [06](06-death-and-recurrence.md) |
| 3D 场景化 | 90% 的体验在信息呈现，3D 只会稀释它 |

## 10. 未决问题

1. **世界观授权边界**：本作气质取自"十日终焉"，但术语、角色、剧情必须完全原创。是否需要在立项阶段做一次对照排查？
2. **商业模式**：目前所有设计都刻意避开付费强度（回响不可购买）。变现是走外观 / 赛季通行证 / 创作者分成抽佣，还是买断？这会反向影响余命经济。
3. **目标语言与市场**：中文为第一语言时世界观最顺，但 UGC 平台的规模效应依赖用户量。是否一开始就做双语关卡包结构？
4. **真相轴的终点**：终焉之地的"真相"必须有一个可抵达的答案吗？还是设计成永远后退的地平线？这决定了叙事内容的产能模型。
