## 1. 设计目标

### 1.1 为什么只用一种硬通货

终焉之地只有一种硬通货：**余命**，单位是「日」。

多货币系统（金币 / 钻石 / 声望点 / 关卡币）的通病是：玩家需要先学习一张汇率表，才能理解自己的处境。而本作的核心体验是**压迫感与取舍**，任何需要查表才能算清的东西都会削弱压迫感。

单一货币带来的收益：

| 层级 | 玩家的问题 | 余命如何回答 |
|---|---|---|
| **短期（一局之内）** | 这一手跟还是不跟？ | 押上去的是你剩下的寿命，不是筹码 |
| **中期（一次轮回）** | 我还能撑几关？ | 余命直接告诉你"你还能存在多少日" |
| **长期（跨轮回）** | 我在为什么努力？ | 余命是购买情报、道具、回溯、AI 编号的唯一手段 |

玩家在任何时刻只需要看一个数字，就知道自己离死亡有多远。**这个数字下降时，玩家的心跳应该跟着变化——这是整套经济系统唯一的成功标准。**

### 1.2 双资源结构

余命不是孤立的。它与第二种资源**记忆碎片**构成一对张力：

| | 余命 | 记忆碎片 |
|---|---|---|
| **本质** | 存在的时间 | 存在的意义 |
| **管的是** | 你能不能活下去 | 你是谁、你为何在此 |
| **稀缺性来源** | 博弈流转，零和 | 只增不循环，且会被烧掉 |
| **对应目标轴** | 生存轴 | 真相轴 + 权柄轴 |
| **玩家心理** | 恐惧 | 好奇 / 支配欲 |

**余命买不到记忆碎片，记忆碎片也不能直接换余命。** 两者之间没有汇率——这是刻意的。一旦可以互换，玩家会把它们折算成同一个数字，第 4 节的核心两难就会消失。

## 2. 余命

### 2.1 定义

- **单位**：日。显示为整数 + 小数一位（例：`23.5 日`）。
- **归属**：与编号绑定，跨轮回**不继承**（新轮回重新发放初始余命）。这是与记忆碎片最重要的差别。
- **术语消歧**：本作中「日」有两个含义，必须在 UI 上用不同视觉区分——
  - **进度日**：你这一轮回打到第几关（第 1 日 ~ 第 10 日），是关卡进度，不是现实时间。
  - **余命日**：你还剩多少余命。
  - 两者的连接点是**存在税**（见 2.3）：每推进一个进度日，自动扣除固定余命。这让"活着本身就在消耗寿命"成为可感知的机制。

### 2.2 获取途径

| 途径 | 说明 | 量级 | 备注 |
|---|---|---|---|
| **关卡胜出瓜分** | 主要来源。存活与名次决定基础分配 | 大 | 见第 5 节结算模型 |
| **密令完成分成** | 密令达成度参与分池，与名次分离 | 中–大 | 允许"输了牌局但赚了余命" |
| **庇护所交易** | 白天相出售道具、情报、刻印线索 | 中 | 交易抽税，见 6.2 |
| **观测者下注** | 出局后对存活者下注 | 小–中 | 死亡后的持续产出渠道 |
| **造关者收成抽成** | 你设计的关卡每开一局，按收成比例抽取 | 小但持续 | UGC 生态的经济引擎 |
| **刻印被采用回流** | 你留下的刻印被后来者实际采用后回流 | 小 | 让"死得有价值"成立 |
| **大终焉奖励** | 全服节庆事件的名次与参与奖励 | 大 | 周期性投放，需严格控量 |

**刻印回流的判定**：系统记录刻印被"采用"（玩家读取后在有效窗口内按其指向行动）而非"被查看"。害死人的刻印同样产生回流——**误导也是一种影响力**，这是伪造刻印这一行为的经济基础。

### 2.3 消耗途径

| 途径 | 说明 | 量级 | 设计意图 |
|---|---|---|---|
| **存在税** | 每推进一个进度日自动扣除 | 固定小额 | 让时间本身有成本，禁止龟缩 |
| **关卡押注** | 入场必须押注，不可为零 | 大 | 核心零和流转 |
| **道具购买** | 庇护所白天相 | 中 | 余命沉淀 |
| **情报购买** | 他人出售的关卡信息、密令线索 | 中 | 玩家间流转，平台抽税 |
| **雇佣 AI 编号** | 人数不足时自费召入 AI 编号，或主动多召 | 中 | 与 AI 补位保底联动 |
| **回溯** | 拉回本轮回的前一日 | **极大** | 复活的代价必须痛 |
| **生肖行使权柄** | 主持关卡时每次裁量都付费 | 中 | 权力不免费，防滥权 |
| **伪造刻印投放** | 主动投放误导性刻印 | 小 | 谎言需要成本 |

### 2.4 归零后果

余命 ≤ 0 时：

1. **立即判定本轮回死亡**，不进入负值。
2. 若发生在关卡内 → 转为**观测者**（本局亡魂态），可继续下注、传递有限信息、留下刻印。
3. 本局结束后 → 进入**轮回结算**：挑选记忆碎片、书写刻印、结算刻印回流账户。
4. **零冷却重开新轮回。** 不存在任何形式的等待时间。
5. 连续快速死亡会触发**意识涣散**，降低记忆碎片继承率（见 6.3）。

**已死亡编号的余命账户不清零**：刻印回流与造关者抽成会继续打入。玩家下次登录时能看到"我死了，但我还在赚"——这是留存设计，不是数值设计。

## 3. 记忆碎片

### 3.1 三重身份

记忆碎片是本作最重要的设计对象，因为它同时是三样东西：

| 身份 | 作用 | 关联系统 |
|---|---|---|
| **真相轴进度** | 拼出终焉之地的真相、大终焉的由来 | 叙事主线 |
| **回响的燃料** | 发动回响必须烧掉记忆碎片 | [回响系统](./04-echo.md) |
| **前史的拼图** | 拼出你自己的创伤类型与应对方式，进而决定执念归系 | 回响觉醒前置 |

三重身份共用一个数量，意味着**每一次消耗都是三重损失**。玩家烧掉一条记忆碎片保命时，同时失去了：一点真相、一点未来的燃料、一块关于自己是谁的拼图。

### 3.2 获取途径

| 途径 | 数量 | 说明 |
|---|---|---|
| **轮回结算** | 基础若干条 + 表现加成 | 主要来源，且是"候选池"而非直接入账（见 3.4） |
| **关卡奖励** | 特定关卡的隐藏达成 | 由关卡包作者配置，属于关卡设计维度 |
| **庇护所探索** | 可走动场景中的搜索、NPC 对话、场景互动 | 白天相的核心动机之一 |
| **密令特殊达成** | 信息型密令的高完成度 | 见[密令系统](./03-mandate.md) |
| **大终焉主线** | 真相轴主线推进 | 官方叙事内容 |

**记忆碎片不可交易、不可赠予、不可掉落。** 它是纯个人资源。理由：它承载"你的过去"，可交易会立刻摧毁整个前史叙事的自洽性，也会打开代练与工作室的口子。

### 3.3 消耗途径

| 途径 | 消耗量 | 说明 |
|---|---|---|
| **发动回响·微响（1 阶）** | 1 条 | 只影响自己的信息层 |
| **发动回响·回响（2 阶）** | 3 条 | 影响一次判定结果 |
| **发动回响·共鸣（3 阶）** | 5 条起 | 修改本关一条规则 |
| **发动回响·权柄（4 阶）** | 叙事级，单独定义 | 生肖级 |
| **回溯** | **永久丢失一部分已获得的记忆碎片** | 与余命双重代价，且档案上留下公开污点 |

**烧掉的记忆碎片不可找回**，且若被烧掉的碎片属于你的前史拼图关键片段，可能导致已成型的执念**回退或分化**——这是最高阶回响使用者必须承担的诅咒：**越强的人越不知道自己是谁。**

### 3.4 继承规则

轮回结算时：

1. 本轮回获得的记忆碎片先进入**候选池**（全部可见，附带残缺描述）。
2. 玩家从候选池中**主动挑选**有限条带走，其余永久丢弃。**挑错了是玩家自己的责任**，系统不给最优解提示。
3. 带走的碎片中，系统会**随机扭曲一小部分**（比例见第 7 节）。被扭曲的碎片不标记、不可辨识。
4. 已带走的碎片在下一轮回继续有效，可与新碎片拼合。

**设计意图**：主动挑选让玩家为自己的"记忆"负责，产生所有权感；随机扭曲保证没有人能拥有完美攻略，也让"我记错了吗"成为可玩的心理状态，并为叙事上的不可靠叙述者留出空间。

## 4. 核心两难

> **烧记忆活下去，还是留记忆追真相？**

这是本作希望玩家每一轮回都遇到至少一次的抉择时刻。它不需要额外系统支撑——它是双资源结构的自然产物。

### 4.1 两种玩家画像

| | **求生者** | **求真者** |
|---|---|---|
| **行为** | 濒死必烧记忆，靠回响脱身 | 宁可死也不发动回响 |
| **优势** | 轮回次数多，余命厚，庇护所里是富人 | 前史拼图完整，接近真相轴深处 |
| **劣势** | 永远拼不出前史，执念难以成型，回响停留在低阶 | 余命拮据，磨损累积快 |
| **在终焉之地的形象** | "活了三百次，还是不知道自己是谁的人" | "什么都知道，但活不过第六日的人" |

### 4.2 他们为什么必须互相需要

- 求真者需要余命：买情报、买道具、付存在税、雇 AI 编号。**求生者是他的资助人。**
- 求生者需要真相：他不知道自己的执念归属哪一系，不知道自己的回响触发条件，永远卡在微响阶。**求真者是他的解读者。**
- 于是庇护所白天相会自然产生一种交易："**你告诉我我是谁，我付你余命。**"

### 4.3 他们为什么互相鄙视

- 求生者眼中，求真者是"沉迷故事、连第七日都活不过的书呆子"。
- 求真者眼中，求生者是"把自己烧成空壳的行尸走肉"。

这种对立**不需要做成阵营**（普通玩家不设阵营是已锁定的方向），它应该体现在庇护所的对话、称号、刻印内容与玩家自发形成的圈层里。系统只需提供**公开可见的统计标签**（如"已发动回响 47 次""前史完成度 12%"），让玩家自己完成互相识别与互相鄙视。

## 5. 押注与结算模型

### 5.1 流转公式草案

**入场阶段**

```
个人押注 = 日层基准押注 × 关卡倍率 × 玩家自选加注系数
押注池 = Σ(全部参与编号的个人押注)
```

- 押注不可为零；玩家可在允许区间内自选加注系数（承担更高风险换更高回报）。
- AI 编号也按同规则押注，其押注由雇主承担或由系统投放（见 6.1 通胀风险）。

**抽成阶段**

```
生肖收成抽成 = 押注池 × 收成抽成率
平台回收销毁 = 押注池 × 回收率      ← 直接从经济中移除，不发给任何人
可分配池     = 押注池 - 生肖收成抽成 - 平台回收销毁
```

**分配阶段**

```
名次分配池 = 可分配池 × 名次权重
密令分配池 = 可分配池 × 密令权重      (名次权重 + 密令权重 = 1)

个人所得 = 名次分配池 × 该编号名次系数
         + 密令分配池 × (该编号密令完成度 / Σ全场密令完成度)
```

**这个双池结构是本作经济的关键。** 它使得"牌桌上输得最惨的人可能是本局赚得最多的人"成为常态——因为他的密令是自毁型或守护型。这直接支撑了[密令系统](./03-mandate.md)想要的社交推理体验：**你无法通过筹码多少判断谁在赢。**

### 5.2 生肖收成与抽成

生肖的抽成率**不是固定值**，而是由**收成**评分决定：

```
实际收成抽成率 = 基准抽成率 × 收成系数
收成系数 = f(余命流转总量, 背叛发生次数, 观测者观看时长, 玩家评分, 通过率健康度)
```

- **通过率健康度**是一个中间高、两端低的钟形函数。全员通过或全员屠杀，收成系数都会掉到谷底。
- 这从经济上保证了生肖**不希望所有人都死，也不希望所有人都活**，无需任何额外规则约束。
- 生肖行使权柄要付余命（见 2.3），因此低收成关卡对生肖是**净亏损**，滥权与摆烂会自动被市场淘汰。

### 5.3 可调参数表

| 参数名 | 建议初值 | 作用 | 风险 |
|---|---|---|---|
| `entry_stake_base[tier]` | 试炼层 2 日 / 倾轧层 5 日 / 崩坏层 12 日 / 终焉 25 日 | 各日层基准押注 | 过高会让新编号第一次死亡即弃游 |
| `stake_multiplier_range` | 0.5 – 2.0 | 玩家自选加注系数区间 | 过宽会让高手无风险碾压 |
| `zodiac_harvest_rate_base` | 8% | 生肖基准抽成率 | 过高则玩家感觉被抽血，过低则无人造关 |
| `harvest_coefficient_range` | 0.2 – 1.8 | 收成系数上下限 | 上限过高会诱导生肖制造极端局 |
| `platform_burn_rate` | 5% | 平台回收销毁比例 | 唯一的硬性通缩阀门，调整需极谨慎 |
| `rank_pool_weight` | 0.6 | 名次分配池占比 | 过高则密令失去经济意义 |
| `mandate_pool_weight` | 0.4 | 密令分配池占比 | 过高则玩家无视关卡本身玩法 |
| `existence_tax_per_day` | 1.0 日 | 存在税 | 过高会惩罚慢节奏玩家 |
| `rewind_cost_lifespan` | 当前余命上限的 60% | 回溯的余命代价 | 过低会摧毁死亡的重量 |
| `rewind_cost_memory` | 已持有记忆碎片的 25%，永久 | 回溯的记忆代价 | 过低会让求真者滥用 |
| `memory_carry_limit` | 3 条（基础） | 结算可带走的记忆碎片上限 | 过高会让前史过快完成，稀有度崩塌 |
| `memory_distort_rate` | 15% | 带走碎片被随机扭曲的比例 | 过高会让玩家不信任系统而非不信任记忆 |
| `echo_fuel[tier]` | 1 / 3 / 5+ 条 | 各阶回响的记忆消耗 | 见 3.3 |

> 以上全部为**待实测调整**的起始值，任何一项都不应在无数据的情况下写死。

## 6. 反通胀与反刷分

### 6.1 通胀来源盘点

余命经济在关卡内是**零和**的（押注池内部流转），因此通胀只可能来自零和之外的投放口：

| 投放口 | 风险等级 | 控制手段 |
|---|---|---|
| 新编号初始余命 | 高 | 与小号问题耦合，见 6.4 |
| 大终焉奖励 | 高 | 周期性大额投放，必须与全服余命总量挂钩动态调整 |
| AI 编号的系统押注 | **最高** | 若 AI 编号的押注由系统凭空生成，则每一局都在印钱 |
| 刻印回流 | 中 | 从平台回收池支付，而非凭空生成 |
| 庇护所任务 / 探索奖励 | 中 | 设日上限 |

**AI 编号押注的处理原则**：AI 编号的押注必须来自**平台回收池**（`platform_burn_rate` 累积的部分），而不是凭空生成。当回收池不足时，降低 AI 编号的押注额度或减少 AI 补位数量。这让通缩阀门与补位机制自动形成负反馈。

### 6.2 通缩阀门清单

1. **存在税**：全服每日稳定销毁，与在线时长正相关。
2. **平台回收销毁**：每局押注池抽取，是主阀门。
3. **交易税**：庇护所玩家间交易抽税并销毁。
4. **回溯**：大额一次性销毁，同时是余命的终极去处。
5. **道具与情报沉淀**：一次性消耗品，购买即销毁对应余命。
6. **生肖权柄代价**：主持关卡的裁量成本销毁。

### 6.3 意识涣散（反送死刷分）

**问题**：玩家可能故意快速送死来刷轮回次数、刷记忆碎片候选池、或刷执念相关的触发进度。

**机制**：连续快速死亡时，记忆碎片继承率递减。

| 短时间内连续死亡次数 | 继承率 | 附加 |
|---|---|---|
| 1 | 100% | — |
| 2 | 70% | — |
| 3 | 40% | 磨损值额外累积 |
| 4+ | 10% | 强制进入庇护所冷却剧情（叙事化的软冷却，非弹窗禁玩） |

**判定不看死亡次数，看行动质量。** 认真挣扎后失败的玩家不应被惩罚：如果编号在本局有有效抵抗（参与决策、有效押注、密令推进），则不计入连续快速死亡计数。这与回响的渴望值判定规则一致——**放弃的人不会有渴望，也不会有继承。**

### 6.4 反小号送余命

余命的跨账号转移是最容易被工作室利用的口子。缓解方案：

1. **不存在直接转账。** 余命只能通过博弈流转（押注池分配）或庇护所市场交易（有商品对价 + 抽税）流动。
2. **新编号保护期**：初始余命在完成 N 个轮回前**标记为不可流出**——它可以被押注、被输掉，但输掉的部分不进入他人所得，而是进入平台回收池。这使得"开小号故意输给大号"无收益。
3. **异常配对检测**：同一批编号高频出现在同一关卡、且余命持续单向流动时，标记并降低其配对优先级（不直接封禁，先降权）。
4. **AI 编号稀释**：开黑房间会被强制混入更高比例的 AI 编号，降低可控性。
5. **庇护所市场限价**：商品价格区间受系统限制，防止用天价道具洗余命。

## 8. 未决问题

1. **余命是否应当跨轮回部分继承？**
   当前方案是完全不继承（每轮回重发 30 日），这最大化了"轮回即重置"的宿命感，但也意味着庇护所里囤积余命的长期意义被削弱——玩家可能会在轮回末期把余命全部挥霍掉，产生"月底清零"式的畸形行为。备选：允许少量余命以"遗产"形式跨轮回结转，比例受磨损值影响。**需主创拍板。**

2. **记忆碎片与余命是否需要一个单向兑换口？**
   当前设计是完全不可兑换。但这会导致一类死锁：一个求真者余命耗尽、无法进入关卡、也就无法获得新的记忆碎片，陷入停滞。是否需要一个**单向、高汇率、有次数限制**的"以记忆换余命"的绝望通道（叙事上：出卖自己的过去以换取苟活）？这在味道上极佳，但会打开第 4 节两难的一个后门。

3. **大终焉的奖励投放如何与全服余命总量挂钩？**
   周期性大额投放是最危险的通胀源。需要确定是采用固定池（全服瓜分同一个池子，人越多人均越少）还是动态池（按当期回收池规模决定）。前者简单可控但人数暴涨时体验崩坏，后者体验平滑但需要持续盯住全服的余命总量。

4. **AI 编号的余命应否真实存在？**
   若 AI 编号持有真实余命并参与流转，经济模型统一但存在被玩家系统性收割的风险（识别 AI 行为模式 → 稳定套利）。若 AI 编号使用影子账本（其输赢仅影响真人玩家的分配比例，不真正持有余命），则模型复杂但安全。**这个决定会直接影响整套结算规则的写法。**

5. **意识涣散的"行动质量"如何量化且不可伪造？**
   当前描述是"参与决策、有效押注、密令推进"，但这三项都可以被脚本化地伪造（无脑最小加注、随机投票）。需要确定量化口径，或改为由生肖 / AI 主持人给出主观评分——后者更符合世界观，但引入了裁量不一致的风险。
