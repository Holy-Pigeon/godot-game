# 05 · 权柄轴与晋升

> 状态：草案 v0.2 ｜ 关联：[索引](README.md)、[01 核心循环](01-core-loop.md)、[03 密令](03-mandate.md)、[04 回响](04-echo.md)、[07 关卡设计](07-level-design.md)、[08 主持人与创作者生态](08-host-and-ugc.md)
>
> **普通玩家没有阵营，只有编号。主持人不是对面那一队，是规则的化身。**

本文档承担两件事：**为什么普通玩家不分阵营**，以及**权柄轴——玩家如何一步步变成定规则的人**。

> **v0.2 的重大变更**：原「十二权柄与生肖」的整套符号系统（十二生肖 × 十二种权柄）**已废弃**。
> 它同时承担着回响归类、UGC 分类命名空间、长期目标载体、主持者身份四份职责，
> 而其中只有后两份是必需的。删掉那层符号之后：
>
> - 回响不再"归系"，只标注[执念格 W×R](04-echo.md)；
> - 规则修正件不再归属某系，改按**效果层级 L1–L4** 组织；
> - 压制不再"封锁某系"，改为**按语义动词族封锁**；
> - 「生肖」这个角色名统一为「**主持人**」，其世界观称谓待定（见 §8）。

## 1. 为什么不做「主持人 vs 玩家」双阵营

### 1.1 阵营标签会当场杀死猜疑链

只要给普通玩家贴上"人类阵营"的标签，玩家的潜意识就会得出一个结论：**我们是一队的**。

而本作的核心张力恰恰相反：

- 每个编号在关卡内都持有互斥的**密令**，一局有几个人就有几套胜利条件；
- 恐怖来自"我旁边这个人可能为了活下去把我推出去"，不来自"有个怪物在追我们"。

一旦成立"人类阵营"，开局第一句话会变成"我们人类要团结"，随后是集体投票、集体对抗主持人。密令、背叛、情报买卖全部失效，游戏退化为多打一的团队副本。

**结论：普通玩家永远只有"编号"这一个身份标签，孤立、匿名、互不信任。**

### 1.2 人口池不能再切一刀

关卡人数由作者设定，主流社交博弈模板的下限普遍在 8 人以上。若再分两个阵营，等于把匹配池切成两份，并且几乎所有玩家都会想扮演"更酷的那一边"，导致某一侧长期排不上队。冷启动阶段这是致命的。

### 1.3 1vN 非对称是另一款游戏

若主持人下场参与生死博弈，本作会变成一款非对称对抗游戏。其代价是：

- 平衡成本极高，且 UGC 关卡规则可变，**非对称平衡在可变规则上不可能收敛**；
- 玩法重心从"规则博弈与社交推理"漂移到"追逃与操作"；
- 与 2D 像素的表现规格不匹配。

### 1.4 恐怖来自规则的非人格性

终焉之地的压迫感来自**规则不恨你，规则只是执行**。主持人是规则的执行面孔，而不是有胜负心的对手。让主持人去"赢玩家"，恐怖感会退化成敌意，反而变弱。

| 项 | 结论 |
|---|---|
| 普通玩家阵营 | **不存在**。只有编号 |
| 主持人是否参与生死博弈 | **否** |
| 主持人是否可被玩家担任 | 是，通过晋升（见 §5） |
| 玩家之间是否有共同胜利条件 | **否**，仅有临时的、可背叛的私下约定 |

## 2. 主持人是什么

### 2.1 定义

> **主持人 = 关卡的主持者与执行者，是规则的化身。**

主持人在关卡中在场、有人格、可发言、可在**关卡声明的裁量范围内**行使裁量权。
他把一段冷冰冰的规则程序，变成一个会看着你、会诱惑你、会宣判你的存在。

### 2.2 硬约束（不可违反）

| 约束 | 说明 |
|---|---|
| 不持有密令 | 主持人没有局内隐藏目标，不与编号争胜负 |
| 不参与余命对赌 | 主持人不押注、不瓜分编号的余命 |
| 不可直接指定淘汰 | 除非该效果被公开写入本关规则且开局前可见 |
| **裁量不得越界** | 裁量范围由**关卡上架时声明的裁量清单**限定，超出清单一律不生效 |
| 一切裁量公开留痕 | 见 §4.2 |

主持人的胜负由**收成**衡量（§3），而收成与"杀了几个人"无关。

### 2.3 裁量清单取代了"权柄系"

旧设计用"你是哪一系"来限定主持人能做什么（"谎言系可以撒谎，忠诚系只能谈契约"）。
新设计把这件事**下放给关卡本身**：

> **关卡在上架时声明一份裁量清单**——本关的主持人可以做哪些事、在哪些时机做。
> 清单之外的一切裁量无效，且越界行为本身会被记入裁决记录。

好处有三：

1. **不需要一套神话分类**才能表达"这个主持人擅长什么"；
2. **裁量范围与关卡的玩法直接绑定**——搜证关的主持人能藏证据，谈判关的主持人能解释条款，各自成立；
3. **作者的表达空间更大**：他不再被"我这关属于哪一系"框住。

### 2.4 主持人对创作者的意义

关卡的作者即该场关卡的主持人。创作者在世界观里终于有了身份：
**你不是"某个建了房间的玩家"，你是这一关的规则本身。** 这一条是 UGC 生态的叙事地基。

## 3. 主持人的胜利条件：收成（Harvest）

### 3.1 绝不能是"杀玩家"

若主持人的目标是淘汰编号，会立刻发生两件事：

1. 主持人与编号形成实质对抗，§1 的所有论证被架空，猜疑链退化为团队对抗；
2. 关卡设计者会把关卡做成屠宰场，玩家体验崩坏。

因此：

> **主持人的胜利指标是"这场关卡产出了多少戏剧性"，而不是"死了几个人"。**

### 3.2 收成指标草案

| 指标 | 说明 | 建议权重 | 上限 |
|---|---|---|---|
| **余命流转总量** | 本关内易主的余命总额（非净损失） | 25% | 单场封顶 |
| **背叛事件数** | 已成立的结盟/契约被打破的次数 | 20% | 按人数归一 |
| **观测者观看时长** | 观测者停留时长与下注参与度 | 20% | — |
| **玩家评分** | 局后匿名评分（刺激度、公平感两项） | 20% | 低于阈值直接清零收成 |
| **通过率健康度** | 见 §3.3 | 15% | 偏离即扣分 |

收成结算为余命，按比例发放给该场关卡的主持人（若为 AI 代行，则归关卡作者）。

### 3.3 通过率健康区间

| 日层 | 目标通过率 | 偏离处理 |
|---|---|---|
| 试炼层（1–3 日） | 92%+ | 低于 85% 收成清零 |
| 倾轧层（4–6 日） | 70%–80% | 每偏离 5 个百分点扣 20% 收成 |
| 崩坏层（7–9 日） | 50%–60% | 同上 |
| 终焉（第 10 日） | 单独调参 | 由主线设计决定 |

**太简单和太屠杀都扣分。** 全员通关意味着没有张力，全员死亡意味着没有博弈。

### 3.4 为什么这套指标自平衡

- 屠杀型关卡：玩家出局早 → 余命流转少、背叛来不及发生、评分低、通过率超标 → **四项同时扣分**，收成极低。
- 放水型关卡：无人押注、无人背叛、观测者不看 → 同样低收成。
- **最高收成必然出现在"所有人都差点死掉、并且互相背叛过"的关卡**——这恰好就是我们想要的体验。

于是主持人的最优策略天然变成：**挑拨、诱惑、给出恶魔契约、让局面精彩，但不要把人杀光。**
这与终焉之地管理者的行为逻辑完全一致，无需额外约束。

### 3.5 反滥用

| 风险 | 对策 |
|---|---|
| 主持人与好友串通刷余命流转 | 同一批账号重复同场的收成衰减；关卡需达到最低陌生人比例 |
| 刷观测者时长 | 观测者时长需伴随下注或互动行为才计入 |
| 恶意差评打击对手 | 评分需达到最低样本量；离群评分剔除 |

## 4. 权力枷锁

**能上能下，长期目标才有张力。** 一个终身制、无成本的主持人席位会立刻腐化。

### 4.1 任期与消耗

| 项 | 规则 |
|---|---|
| 行使裁量的成本 | 每次行使裁量权支付余命，触及的层级越高越贵 |
| 主持成本 | 开一场关卡需垫付一笔余命作为奖池担保 |
| 任期 | 按赛季计，任期内需达到最低收成线，否则不续任 |
| 闲置 | 连续未主持关卡达阈值，席位转入待补状态 |

**权力不是免费的**，这一条同时把主持人纳入了余命经济，与编号共用同一套货币。

### 4.2 公开裁决记录

主持人的每一次裁量都写入本关的**裁决记录**：时间、条款、裁量内容、理由摘要。

- 局内全场可见；
- 局后进入关卡档案，任何人可复盘；
- 记录不可编辑、不可删除。伪造类修正件只能在**局内**插入伪造事件，且局后档案会标注该关启用过伪造类修正件。

这一条是玩家信任 UGC 生态的地基：**你可以被玩弄，但你事后一定能看清你是怎么被玩弄的。**

### 4.3 申诉与审判

| 阶段 | 机制 |
|---|---|
| 申诉 | 局后 24 小时内，参与该关的编号可发起申诉，需达到最低联署人数 |
| 举证 | 系统自动附上裁决记录与关卡回放 |
| 审判 | 由**其他主持人**组成的同侪评议席 + 系统规则校验共同裁定 |
| 裁定结果 | 驳回 / 警告 / 收成追回 / 权柄冻结 / **褫夺权柄** |

审判本身是可观看的内容，并且是主线叙事的天然舞台。

### 4.4 褫夺

被褫夺权柄的主持人**跌回编号**，保留其回响（降回三阶·共鸣或以下）、其记忆碎片、
以及一条永久的公开档案记录；失去席位、主持资格与收成分成。

**跌落的前主持人是极好的叙事素材**，也是其他玩家的目标与谈资。

## 5. 晋升路径

### 5.1 四段路径

```
编号
 └─ 回响觉醒（一阶·微响）
     └─ 多轮回中回响在同一执念方向上进化、分化（二阶·回响 → 三阶·共鸣）
         └─ 权柄成型，被终焉之地"认可"
             └─ 晋升主持人（四阶·权柄）
```

关键设计：**你将来会做出什么样的关卡，取决于你在无数轮回里反复经历的是什么痛苦**
（创伤 × 应对 → [执念格](04-echo.md) → 回响 → 创作风格）。

> **你怎么受苦，决定你将来怎么折磨别人。**

一个因"被集体串供指认"而觉醒了记录类回响的编号，晋升后设计的关卡必然围绕
"记录、指认、规则改写"展开。**创作风格由角色经历决定**，UGC 内容因此天然具有多样性与个人色彩。

### 5.2 席位数量：正席 + 影子席

> **注意：旧方案的"12 席"锚定在十二系上，那套符号系统已废弃，席位数量因此失去了锚点。**
> 下表的正席数量是**待定值**，见 §8 未决问题 1。

| 方案 | 优点 | 缺点 |
|---|---|---|
| 极少正席（个位数） | 极致稀缺，事件感强，全服共同话题 | 席位僵死，新人永无机会 |
| 正席不限 | 人人有机会 | 主持人贬值，失去神性 |
| **少量正席 + 若干影子席（建议）** | 兼顾稀缺与开放 | 需额外说明两者差异 |

**建议采用第三种：**

- **正席（数量待定，建议个位数）**：全服稀缺。可参与审判评议席、在主线剧情中具名。
  以赛季为周期，收成排名靠前者继任。
- **影子席（不限）**：达到晋升门槛的玩家均可获得。可主持关卡、可造关，
  但**不参与审判、不具名、收成分成低于正席**。

理由：正席提供"全服个位数"的传说级目标，影子席保证"人人有机会"的长期动力，
两者共用同一套晋升门槛，区别只在于能不能坐上那把椅子。

### 5.3 晋升门槛与审核

同时满足以下条件方可申请影子席：

| 维度 | 门槛草案 |
|---|---|
| 回响阶数 | 达到三阶·共鸣 |
| **执念纯度** | 单一执念方向占比 ≥ 70%，避免"什么都沾一点" |
| 轮回经历 | 完成至少 N 次轮回，且至少一次抵达第 10 日 |
| 前史完整度 | 记忆碎片拼合度达到阈值——**你必须先知道自己是谁** |
| 品行档案 | 无有效的严重申诉记录；回溯次数不超过阈值 |

审核方式：

1. **系统校验**：上述硬指标自动核对；
2. **试炼关**：申请者主持一场受监控的关卡（可用 AI 编号补位凑人），按收成指标评分；
3. **评议**：正席主持人 + 系统共同裁定，结果与理由公开。

正席继任额外要求：赛季收成排名靠前，且通过一场**公开的**试炼关（可被全服观战）——
这本身就是赛季高潮内容。

## 6. 主持人缺席时的 AI 代行

关卡的主持人不在线时，由**创作者接入的外部模型**扮演其人格代行主持。
详细设计见 [08](08-host-and-ugc.md)，本文档只规定权限边界。

| 项 | 规定 |
|---|---|
| 胜负、余命、密令判定 | **一律由关卡规则裁决，主持人无权干预** |
| AI 可做 | 开场叙事、氛围演出、临场发言、诱惑与挑拨、模糊条款的裁量提案 |
| 裁量提案 | 必须落在**本关裁量清单**内，超出范围的一律不生效 |
| 越权 | 直接驳回，并记入裁决记录，全场可见 |
| 超时 | 降级为预设模板台词，不阻塞对局 |

**AI 不决定胜负，只决定叙事。** 因此提示词注入无法用于作弊，延迟也只影响演出节奏。

## 7. 铺开顺序

| 阶段 | 主持人与权柄的范围 |
|---|---|
| **验证期 / 成型期** | **完全不做主持人**。只有编号 + 密令 + 关卡规则。先验证核心乐趣 |
| **主持期** | 引入主持人作为**人格演出层**，先做 3 套人格模板（建议分别覆盖信息、规则、赌注三条主线） |
| **元游戏期** | 扩充人格模板；上线收成指标与裁决记录 |
| **开放期** | **开放玩家晋升**（影子席），上线权力枷锁全套、申诉与审判、正席赛季继任 |

先只做 3 套人格模板的理由：三套已能覆盖三类完全不同的关卡体验，
足以验证"主持人的人格演出是否真的提升体验"；扩充属于内容量投入，应在机制验证之后。

## 8. 未决问题

1. **正席数量定几个？** 旧方案的 12 席锚定在已废弃的十二系上，现在没有任何自然锚点。
   太少则新人永远够不到，太多则失去神性。**需主创给一个数**，并说明它锚定在什么上
   （赛季？关卡池分区？纯粹拍板的一个数？）。
2. **主持人的世界观称谓是什么？** "主持人"是功能描述，不是终焉之地里的叫法。
   旧设定用"生肖"提供了这层神话感，删掉之后这个位置是空的。
   需要一个既不落回十二生肖、又有压迫感的称谓。
3. **正席 + 影子席的双层结构是否采用？** 若采用，需确定正席的赛季继任是否允许卫冕及卫冕上限。
4. **收成的五项权重与通过率健康区间的具体数值**需要真实对局数据校准，
   在此之前只能是拍脑袋值。是否接受先用一组可随时调整的初值？
5. **主持人是否允许在自己主持的关卡中与编号发生余命往来**（例如收取"贿赂"）？
   允许会极大丰富博弈层，但直接冲击"主持人不参与生死博弈"的硬约束。
6. **AI 代行时的收成归属**：全额归关卡作者，还是打折发放以鼓励作者亲自到场？
7. **"执念纯度 ≥ 70%"怎么算？** 执念格是 8×4 的矩阵，"同一执念方向"指同一行（同一创伤）、
   同一列（同一应对），还是同一格？三种口径的严苛程度差很远。
