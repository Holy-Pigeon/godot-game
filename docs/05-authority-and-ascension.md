# 05 · 无阵营与主持人

> 状态：核心规格 v0.3 ｜ 真源：主持人身份、权限与造关资格

## 已锁定规则

| 主题 | 规定 |
|---|---|
| 阵营 | 不做“主持人 vs 玩家”或“人类阵营”；恐怖与压力来自规则和彼此猜疑 |
| 主持人 | 关卡的叙事与裁量执行者，不是胜负裁判，也不持有密令 |
| 造关资格 | 所有人都有；无晋升、席位、回响阶数或资历门槛 |
| 经济门槛 | 买地、维护地块、垫付奖池与行使裁量均消耗余命 |
| 作弊边界 | 创建者不得作为编号进入自己的关卡 |
| 权柄 | 回响四阶名称，不是主持人身份或造关权限 |

## 主持人权限

主持人只能执行关卡包预先声明的**裁量清单**，且所有裁量写入不可修改的公开裁决记录。规则、余命、密令和胜负仍由关卡系统结算。

| 可做 | 不可做 |
|---|---|
| 宣读规则、执行人格化叙事、在清单范围内裁量 | 决定胜负、指定淘汰、持有密令、绕过规则改数值 |

主持缺席可由创作者接入的外部模型代行；代行仍受同一清单与记录约束。

## 收成与约束

主持/作者收益是“收成”，衡量余命流转、背叛事件、玩家评分、通过率健康度，以及一项依赖死亡设计的出局者参与指标。收成不是杀人数；过易和屠宰都应降低收益。

| 风险 | 处理 |
|---|---|
| 越权裁量 | 裁决记录、自动校验、局后申诉 |
| 低质量关卡 | 降低推荐、退出正式池；针对关卡，不针对造关资格 |
| 违规或刷量 | 收成冻结/追回、关卡下架、限时禁止主持、公开档案 |

申诉以回放、事件日志和裁决记录为证据；具体同侪审理机制仍待定。

## 创作风格

前史与回响形状只影响玩家可能创作出的关卡气质，不影响其能否造关。造关流程与质量漏斗见 [07](07-level-design.md)、[08](08-host-and-ugc.md)。
