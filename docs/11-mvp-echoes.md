# 11 · MVP 回响规格

> 状态：MVP 规格 v0.5 ｜ 真源：首个可制作的回响包
>
> 验证目标：在 T-11「背光审判」中，验证“首次偶然觉醒 → 跨轮回逐步看懂触发路径 → 玩家主动发动 → 本轮回重置”是否能制造清晰、可选择的翻盘体验。

## 范围与验收

| 项 | MVP 规定 |
|---|---|
| 模板 | 仅 T-11 背光审判 |
| 回响 | E-01 至 E-04 四条，L1 两条、L2 两条 |
| 激活 | 情境满足只激活；不自动发动；激活持续至本轮回结束 |
| 发动 | 玩家主动确认；每条每关最多一次；未发动无成本 |
| 重置 | 下一轮回必定回到普通编号；只保留形状、理解进度与历史档案 |
| 发现节奏 | 第一次只呈现前史意象；第二次揭示关键条件；第三次公开完整触发路径 |
| 验收 | 首次激活有意外感但可复盘；第三次后玩家能说清完整路径，并能解释“不用的机会成本”和“发动的实际代价” |

## 背光审判需要记录的触发事实

`指证矛盾(x, 针对我)`、`余命净变化(我, 本幕)`、`曾公开表态(我, 上一轮)`、`回应数(我, 上一轮)`、`余命分位(我)`、`因我受损(x)`、`曾保护(x, 我)`、`被公开指认(我)`、`幕终裁决轮`。

缺少对应事实记录时不能激活相应回响；发动入口不出现，也不会产生无效消耗。

## 四条回响

| # | 渴望 / 执念格 | 语义锚点 | 激活条件 | 背光审判中的发动效果 |
|---|---|---|---|---|
| E-01【真话】 | 知道；W4 欺瞒 × R3 逃避 | `揭示·指定编号的一次隐藏行动·L1` | `指证矛盾(x,针对我)` 且我本幕余命净变化为负 | 看见该编号本轮夜幕行动及目标 |
| E-02【余音】 | 被听见；W8 湮没 × R4 支配 | `重播·我的一次公开发言·L1` | 上一轮我公开表态且无人回应，且我处于余命后 1/3 | 重播该发言并标记为已确认发生 |
| E-03【替】 | 还清；W6 罪咎 × R2 补偿 | `转嫁·指定编号的一次判定后果到我·L2` | `因我受损(x)` 且 `曾保护(x,我)` | 幕终裁决时替指定编号承受一次淘汰；由我行使离场前的余命赠予权 |
| E-04【不是我】 | 清白；W1 背叛 × R1 复仇 | `转嫁·一次针对我的判定后果到指定编号·L2` | 我被公开指认，且当前为幕终裁决轮 | 将本轮一项损失转移给指定编号 |

共同成本：E-01/E-02 消耗 1 条记忆、可隐蔽；E-03/E-04 消耗 3 条记忆、全场可见并永久登记。

## 前史写作规则

- 前史写普通人能共情的伤口，不写奇观履历。
- 名称写渴望，不写机制术语。
- 每条共鸣条件都必须能还原为“前史中的什么结构正在重演”。
- 四条应覆盖不同信息方向与代价方向：读入、推出、揽责、甩责；不应在同一局面里成为彼此替代解。

## 验证流程

1. 用 GM 设置前史、形状、阶数、完整触发路径与当前理解进度。
2. 第一次满足条件时，只播放觉醒与前史意象；不显示条件清单，也不自动执行效果。
3. 进入新轮回，确认回响重置为不可用，但理解进度保留；第二次共振后只揭示关键条件。
4. 再进入新轮回并制造第三次共振，检查完整触发路径、合法时机与代价均可查看。
5. 在合法时机选择放弃一次，确认无扣费、无暴露、无次数消耗。
6. 主动发动一次，检查效果映射、记忆扣除、暴露与每关频次。

## 暂不纳入 MVP

- L3/L4 回响、跨模板完整映射、回响分化。
- AI 编号的回响形状。
- 渴望跨轮回公式、记忆继承、死亡后处理。
