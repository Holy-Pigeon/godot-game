# 11 · MVP「最后提案」与回响规格

> 状态：MVP 规格 v1.1 ｜ 真源：首个可制作范围与回响包
>
> 验证目标：在 T-11「最后提案」中，用秘密密令推动主动承担、灾痕转移、认可交易与公开否决，并验证“首次偶然觉醒 → 跨轮回逐步看懂触发路径 → 玩家主动发动 → 本轮回重置”能否制造清晰、可选择的翻盘体验。

## 范围与验收

| 项 | MVP 规定 |
|---|---|
| 模板 | 仅 T-11 最后提案；6 人、6 轮、三幕 |
| 经济 | 玩家支付固定门票 2 日后带入真实余命；基础回收等级 60+；无否决时预期系统净回收 32 日 |
| 奖励 | 最终累计承担值前两名基础奖励 14 / 8 日，每次否决各 +1；密令奖为 1 / 2 / 3 日 |
| 回响 | E-01 至 E-04 四条，L1 两条、L2 两条 |
| 记录 | 双流记录：规则事件流可复算，行为语料流含公开发言、私聊与语音转写，共用统一序号轴，见 [13](13-record-and-inference.md) |
| 推断 | 局后一次性小模型意图分析，产出带证据引用的执念倾向增量；对玩家不可见，不进入任何局内判定 |
| 激活 | 三重合取：找回度 ≥ 阈值、渴望值 ≥ 阈值、情境成立；只激活不自动发动；激活持续至本轮回结束 |
| 碎片与渴望 | 具名离散碎片自动归位、按创伤分池的渴望值、无游离燃料库存、烧掉本条回响自己的前史会当场失活，见 [14](14-fragments-and-yearning.md) |
| 发动 | 玩家主动确认；每条每关最多一次；未发动无成本 |
| 重置 | 下一轮回必定回到普通编号；只保留形状、理解进度与历史档案 |
| 发现节奏 | 第一次只呈现前史意象；第二次揭示关键条件；第三次公开完整触发路径 |
| 验收 | 首次激活有意外感但可复盘；第三次后玩家能说清完整路径，并能解释“不用的机会成本”和“发动的实际代价” |
| 完美通关 | 潜规则是明面“认可灾痕方案”的更深解法；完整条件和概率不向玩家显示，回响可以帮助但不是硬性钥匙 |

## T-11 的完整规则

T-11 不使用“夺／护／藏／窥”，没有分配者、查身份或集体处刑。每个关卡轮次放出 4 枚灾痕，所有存活玩家依次选择承担、申请接手别人持有的灾痕，或者不选；单人最多持有 2 枚。

顺序行动后开放自由交流，全体对当前方案投认可/反对票；4 枚全部有主且至少 `n−1` 人认可才结算。第一协商轮若只是灾痕未领完且反对票不超过 1 张，可无代价进入第二轮；2 张反对票仍算正式否决。从第二协商轮开始，未领完也视为否决。每次正式否决都会使单枚灾痕损失 +1，并让最终承担奖第一、第二名各 +1。基础灾痕损失按三幕依次为 1 / 2 / 3 日。

初始化、逐阶段流程、分配限制、密令奖励、结算顺序、归零与经济核算的唯一规则真源见 [12 · T-11 最后提案](12-t11-last-proposal.md)。本文件只锁定 MVP 范围和四条回响，不复制另一份可能漂移的规则。

## 最后提案需要记录的触发事实

`公开承诺认可(x)`、`最终投票(x)`、`因反对导致否决(x)`、`余命分位(我)`、`曾替我承担(x)`、`转移申请(我, x)`、`转移回应(x, 我)`、`收到转移申请数(我, 上一轮)`、`当前持有灾痕数(我)`、`当前幕`。

缺少对应事实记录时不能激活相应回响；发动入口不出现，也不会产生无效消耗。

## 四条回响

| # | 渴望 / 执念格 | 语义锚点 | 激活条件 | 最后提案中的发动效果 |
|---|---|---|---|---|
| E-01【真话】 | 知道；W4 欺瞒 × R3 逃避 | `揭示·一次已锁定的选择·L1` | x 曾在某协商轮公开承诺认可、最终投反对，且该协商轮被否决 | 在投票信息窗口查看一名指定玩家本协商轮已锁定的认可/反对票；只有我可见，目标不能更改，发动者随后可以重新确认自己的票 |
| E-02【余音】 | 被听见；W8 湮没 × R4 支配 | `重播·我的一次公开表态·L1` | 上一轮我申请接手灾痕被拒，且整轮无人向我申请转移，且我处于余命后 1/3 | 把我上一轮被拒的那次接手请求重新钉在本轮公共区，直到投票锁定；当前持有者可随时同意，且该同意不消耗其行动，但绝不自动生效 |
| E-03【替】 | 还清；W6 罪咎 × R2 补偿 | `转嫁·一次针对我的判定后果·L2` | x 曾主动申请并最终替我结算过一枚灾痕 | 在分配回响窗口把 x 当前持有的一枚灾痕移给我；仍受每人最多 2 枚限制 |
| E-04【不是我】 | 清白；W1 背叛 × R1 复仇 | `转嫁·我的一次判定后果到指定编号·L2` | 我持有至少 1 枚；我申请接手 x 的灾痕但被 x 拒绝；x 当前只持有 1 枚 | 在分配回响窗口把我的一枚灾痕移给 x；该枚本协商轮不能再次转移 |

共同成本：E-01/E-02 消耗 1 条记忆、可隐蔽；E-03/E-04 消耗 3 条记忆、全场可见并永久登记。

上表「激活条件」只写共鸣与情境条款；四条同样受找回度与渴望值两道门约束，对应创伤依次为 W4 / W8 / W6 / W1，见 [14](14-fragments-and-yearning.md)。

「语义锚点」列写的是 [04](04-echo.md) 冻结的**抽象锚点**，「发动效果」列写的是它们在 T-11 里的落地。同一条回响换到别的模板时，锚点不变、落地改写。激活条件同样只引用平台谓词词表，由模板绑定到本关事件；词表、绑定表与兼容矩阵的工程形态见 [15](15-t11-technical-design.md)。

## 前史写作规则

- 前史写普通人能共情的伤口，不写奇观履历。
- 名称写渴望，不写机制术语。
- 每条共鸣条件都必须能还原为“前史中的什么结构正在重演”。
- 四条应覆盖不同信息方向与代价方向：读入、推出、揽责、甩责；不应在同一局面里成为彼此替代解。

## T-11 专项验收

- 玩家复盘时主要谈论承担、转移、方案是否值得认可，而不是“谁像坏人”。
- 至少一半玩家在一局中主动申请过一次灾痕转移；至少出现一次承诺认可后投反对。
- 无否决时系统预期净回收接近 32 日；否决后每次增加约 2 日净回收，同时奖池增加 2 日。
- 玩家能指出自己的密令如何改变了原本最省余命的选择。
- 没有分配者或固定领袖；首位行动权轮换后仍能形成不同利益关系。
- 即使移除四条回响，基础关卡仍能独立跑通；加入回响后只改变关键选择，不替玩家作决定。

## 验证流程

1. 用 GM 设置前史、形状、阶数、完整触发路径与当前理解进度。
2. 第一次满足条件时，只播放觉醒与前史意象；不显示条件清单，也不自动执行效果。
3. 进入新轮回，确认回响重置为不可用，但理解进度保留；第二次共振后只揭示关键条件。
4. 再进入新轮回并制造第三次共振，检查完整触发路径、合法时机与代价均可查看。
5. 在合法时机选择放弃一次，确认无扣费、无暴露、无次数消耗。
6. 主动发动一次，检查效果映射、记忆扣除、暴露与每关频次。

## 暂不纳入 MVP

- L3/L4 回响、跨模板完整映射、回响分化。
- AI 编号的回响形状。
- 渴望跨轮回公式、记忆继承、死亡后处理。
