# 07 · 关卡设计系统

> 状态：核心规格 v0.3 ｜ 真源：模板、关卡包、地块与上架约束

## 核心原则

1. 作者组合预制规则零件，不能书写自由规则条文。
2. 模板必须让人露出本性：无单一最优解、行为可观测、有真实取舍，随机不替玩家做决定。
3. 规则修正件自动按规则时机执行；回响只由情景激活，之后仍由玩家选择发动。
4. 模板必须同时提供回响的输出接口（语义锚点）与输入接口（情境谓词）。

## 模板库与 MVP

首批方向：投票放逐、暗账、契约谈判、密室搜证、拍卖、轮盘。首个验证模板为 **T-11 暗账**。

### T-11 暗账

六轮、三个账期，倍率依次 ×1 / ×2 / ×3。每轮按以下顺序：

| 阶段 | 规则 |
|---|---|
| 记账（暗） | 每人选择目标和动作：夺（从目标划走余命）、担（替目标承受损失）、匿（免疫夺/窥但扣余命）、窥（看目标动作但不看目标） |
| 对账（公） | 只公开结果，不公开执行者；公示粒度按人数档缩放 |
| 表态（公） | 指认、担保或沉默；错误指认自罚，错误担保连坐，连续沉默留痕 |
| 账期结算 | 第 2/4/6 轮后平账；账面最少者销账，临走可将剩余余命记为坏账给任意人；出局后处理待定 |

账期间开放 60 秒私聊，不强制履约。暗动作与公开表态形成可交易、可撒谎的碎片化共知；这也是 MVP 回响所需谓词的来源。

## 创作词汇表

| 组件 | 规定 |
|---|---|
| 触发时机 | 只可从官方封闭清单选择，如回合开始、投票、弃权、余命变动、结算 |
| 效果层级 | L1 信息、L2 判定、L3 规则、L4 他人/权柄；动词必须白名单化 |
| 可见性 | 公开、延迟公开、定向、隐秘；隐秘修正件需额外审核 |
| 情境谓词 | 模板公开声明的客观状态；供回响激活条件引用 |

每个模板必须实现所有 L1/L2 语义锚点；L3 可按 [04](04-echo.md) 的降级规则处理。单关可以缺少某个谓词，但同一日层的关卡池必须整体覆盖玩家回响池。

## 地块与关卡包

### 地块

造关先买地：核心区总量有限、昂贵、人流大；外围无限、便宜、人流小。地块收周期维护费，欠费回收的细节待定。地块是纯经济门槛，不能成为身份门槛。

### 关卡包

```text
基础模板 + 修正件 + 密令池 + 压制配置 + 主持人人格/裁量清单 + 人数/门票/奖池
```

门口只公示：类型、难度/死亡率、人数、门票。压制配置进场后宣读；它也是玩家可交易的情报。

## 压制与质量

压制可封锁回响动词族、提高发动代价或设置绝缘区。被压制的发动尝试仍然可见，以保留风险与情报价值。

上架检查至少验证：规则可跑通、无死锁、密令可达成、语义锚点/谓词接口齐全、人数与时长健康、无明显最优解。正式池持续根据公平、张力、完成率、退出率、试跑数据与举报调整推荐或下架。

具体数值、模板人数档、地价和压制信息衰减见 [09](09-open-questions.md)。
