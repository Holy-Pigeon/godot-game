# 07 · 关卡设计系统

> 状态：核心规格 v0.5 ｜ 真源：平台级关卡原则、模板、关卡包与上架约束
>
> 具体模板不得把完整规则写在本文；T-11 见 [12 · 最后提案](12-t11-last-proposal.md)。

## 核心原则

1. **每关都要有人能赚余命。** 系统必须提供至少一条正常可执行的正收益路径；玩家互相转账不能冒充关卡奖励。
2. **回收越高，赢家奖励越丰富。** 关卡回收等级提高时，奖励总量、获奖名额或奖励稀有度至少一项必须提高，不能只提高死亡和扣费。
3. **门票固定且提前公示。** 同一关卡包内所有玩家支付相同门票；不得按玩家当前余命临时加价，也不得进场后追加隐藏门票。
4. **局内玩法不必围绕余命。** 规则可以直接使用玩家剩余余命，也可以是纯解密、操作、谈判或叙事玩法；经济闭环由固定门票、规则回收/死亡和结算奖励承担。
5. **生命按统一尺度计入回收等级。** 规则直接导致一名玩家死亡按 10 余命等值，与固定门票和规则回收余命相加；这只决定风险与奖励档，不决定死亡后处理。
6. **每关必须有完美通关路径。** 至少存在一条规则合法、可验证且非日常达成的路径，使全体玩家从系统获得的总余命超过全体门票与规则损失；这条路径可以依赖回响，也可以完全由基础规则完成。
7. **潜规则必须是明面目标的更深解法。** 完美通关不能是无关的隐藏成就或任意物品清单；它必须回答“这关真正想让玩家理解什么”，由明面规则中的异常、反馈和可重复现象提供推理线索。
8. **猜中潜规则只打开完美判定。** 玩家执行正确方向后获得可调概率的完美通关机会；更完整、更困难的执行应提高概率，最高可以达到必定通过。失败也要留下可复盘反馈，不能像无提示随机落空。
9. **潜规则不直接写给玩家。** 玩家只看到明面规则、行为反馈和世界内线索；完整条件、概率表与检测逻辑只存在于模板内部规格和 GM 工具。
10. **完美通关不能成为简单刷钱路线。** 路径应要求稀有协作、困难状态或高风险选择；若过于简单导致关卡累计系统净收益跌至 `-100` 或更低，设计者进入处罚流程。
11. **作者组合预制规则零件，不能书写自由规则条文。** 核心流程来自官方模板，作者只配置修正件、密令池、压制与经济参数。
12. **模板必须让人露出本性。** 不得存在单一最优解；行为必须可观察或可推断；取舍应发生在利益、关系或价值之间，随机不能替玩家做决定。
13. **回响只开放选择，不替玩家选择。** 规则修正件按声明时机自动执行；回响由情景激活，是否发动始终由玩家决定。
14. **模板必须提供双向接口。** 输出端实现回响语义锚点，输入端声明可客观判定的情境事实。

## 回收、奖励与准入

关卡包必须在入场信息中声明：固定门票、预期回收等级区间、主要回收来源、可能死亡数、奖励名额与奖励内容。统一公式和个人净收益口径见 [02 · 余命与记忆](02-economy-lifespan-memory.md#关卡回收等级)。

上架审核至少检查：

- 是否存在可复现的个人正收益路径。
- 是否存在全体系统净收益大于 0 的完美通关路径；它是否源于明面目标、具有可推理线索且足够困难。
- 完美判定概率是否随正确行为单调提高，失败反馈是否足以支持跨轮回复盘。
- 奖励丰富度是否随预期回收等级单调上升。
- 是否把玩家间交易错误计作系统奖励或回收。
- 规则致死是否确由关卡直接造成，而不是把玩家入场前的低余命重复计价。
- 实际回收等级、死亡率和净回收是否落在公示区间。

关卡按关卡包版本累计系统净收益。累计值达到 `-100` 或更低时，立即停止该版本的创作者收成、移出推荐并禁止新房间创建，直到设计者修改规则并重新通过经济试跑。处罚针对造成亏损的关卡版本，不直接扣除设计者个人已有余命；重复出现简单亏损路径会进一步影响作者上架资格。

## 模板库与 MVP

首批方向：灾难分摊、契约谈判、密室搜证、拍卖、轮盘与纯解密。首个验证模板为 **T-11 最后提案**；其完整流程、密令与数值只记录在 [独立规格](12-t11-last-proposal.md) 中。

## 创作词汇表

| 组件 | 规定 |
|---|---|
| 触发时机 | 只可从官方封闭清单选择，如回合开始、投票、弃权、余命变动、结算 |
| 效果层级 | L1 信息、L2 判定、L3 规则、L4 他人/权柄；动词必须白名单化 |
| 可见性 | 公开、延迟公开、定向、隐秘；隐秘修正件需额外审核 |
| 情境事实 | 模板公开声明的客观状态；供回响激活条件引用 |
| 经济参数 | 固定门票、规则回收、死亡等值、奖励池与抽成上限；不得绕过模板安全区间 |

每个模板必须实现所有 L1/L2 语义锚点；L3 可按 [04](04-echo.md) 的降级规则处理。单关可以缺少某项情境事实，但同一日层的关卡池必须整体覆盖玩家回响池。

## 地块与关卡包

### 地块

造关先买地：核心区总量有限、昂贵、人流大；外围无限、便宜、人流小。地块收周期维护费，欠费回收的细节待定。地块是纯经济门槛，不能成为身份门槛。

### 关卡包

```text
基础模板 + 修正件 + 密令池 + 压制配置 + 主持人人格/裁量清单
         + 人数 + 固定门票 + 回收等级区间 + 奖励配置
```

门口至少公示：类型、人数、固定门票、预期回收等级、死亡率区间、奖励名额与奖励内容。压制配置进场后宣读；它也是玩家可交易的情报。

## 压制与质量

压制可封锁回响动词族、提高发动代价或设置绝缘区。被压制的发动尝试仍然可见，以保留风险与情报价值。

上架检查还必须验证规则可跑通、无死锁、密令可达成、语义锚点/情境事实接口齐全、人数与时长健康、无明显最优解。正式池持续根据公平、张力、完成率、退出率、经济数据与举报调整推荐或下架。

具体地价、维护费、抽成、奖励曲线与压制信息衰减见 [09](09-open-questions.md)。
