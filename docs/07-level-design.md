# 07 · 关卡设计系统

## 0. 本文档的地位

**关卡**是《终焉之地》所有玩法的容器。编号在关卡里押上余命、执行密令、被迫背叛、觉醒回响。
因此**关卡的表达能力决定了这款游戏内容的上限**。

本文档回答三个设计问题：

1. 一个关卡由哪些部分组成？
2. 关卡设计者手里有哪些创作词汇？
3. 什么样的关卡是好关卡，什么样的是坏关卡？

---

## 1. 核心设计哲学

### 1.1 第一原则：不要让玩家"写游戏"，让他们"改规则"

绝大多数 UGC 平台的失败姿势是"给玩家一张白纸"。
结果是 99% 的投稿不可玩，1% 的精品被淹没，平台变成废墟仓库。

我们采取相反的姿势：

> **玩家拿到的不是白纸，而是一张已经很好玩的牌桌，以及一盒可以往桌上扔的规则。**

一个关卡包由五部分构成：

```
关卡包 = 基础玩法模板
       + 规则修正件 × N
       + 主持人人格
       + 密令池
       + 压制配置
```

| 组成 | 承担什么 |
|---|---|
| **基础玩法模板** | 官方设计并长期打磨，保证**可玩性下限**。作者不能改动它的核心流程 |
| **规则修正件** | 作者真正的创作空间，靠组合产生**内容深度上限** |
| **密令池** | 决定这一关的**人性走向**——同一张暗账牌桌，配"保护某人"的密令池和配"必须让某人归零"的密令池，是两款完全不同的游戏 |
| **压制配置** | 决定回响者在这一关有多大呼吸空间 |
| **主持人人格** | 决定叙事气质，由生肖权柄限定 |

作者的创作动作因此从"发明玩法"降维成 **"配置 + 组合 + 调味"**。
这既降低了创作门槛，又抬高了创作质量的地板。

### 1.2 第二原则：作者不编写规则，只挑选规则

作者能做的是**从官方词汇表里挑选并组合**，不能凭空定义新的触发时机或新的效果。

这条限制的三个设计理由：

| 理由 | 说明 |
|---|---|
| **创作门槛** | 一个不会编程的剧本杀作者，应该能在半小时内做出他的第一个关卡 |
| **可裁决性** | 玩家输的时候必须知道自己为什么输。只有当所有规则都来自一套公共词汇，"为什么"才解释得清楚 |
| **体验一致性** | 玩家在 A 关卡学到的规则直觉，在 B 关卡依然成立。词汇表复用是玩家跨关卡学习曲线的基础 |

作者可以自由书写的，是**文本**：关卡简介、开场旁白、规则文案、密令措辞。
这部分恰恰是叙事气质的主要来源，创作自由并没有被真正剥夺——**被剥夺的只有制造混乱的自由**。

### 1.3 第三原则：回响与规则修正件是同一件东西的两个来源

这是整套设计最重要的**对称性**，必须在第一天就锁死。

[回响](04-echo.md)（玩家的超能力）与规则修正件（关卡作者的创作）在设计上是同构的：
**两者都是"在某个时机，对局面施加一个规则性的改变"。**

| | 规则修正件 | 回响 |
|---|---|---|
| 来源 | 关卡作者 | 玩家（由执念与前史生成） |
| 触发 | 关卡规则自动触发 | 玩家主动发动，需满足触发条件 |
| 归属 | 十二权柄之一 | 十二权柄之一 |
| 效果词汇 | **同一份清单** | **同一份清单** |
| 强度分级 | 四层（信息 / 判定 / 规则 / 权柄） | 四阶（微响 / 回响 / 共鸣 / 权柄） |

这个对称性带来三个设计红利：

1. **回响的强度分级有了客观定义**——不是"感觉很强"，而是"它能碰到哪一层"。
2. **新增一个效果词汇，同时惠及关卡创作与回响设计**，内容产能翻倍。
3. **压制**（关卡对回响的封锁）在设计上只是"这一关不接受来自玩家的那一类改变"，概念极其干净。

## 2. 基础玩法模板库

### 2.1 模板是什么

一个基础玩法模板是一套**官方打磨的完整玩法**，包含固定的流程阶段、固定的合法行动、固定的胜负判定，
以及一组**挂载点**——即修正件可以介入的时机。

作者选定模板后，只能通过修正件、密令池、压制与押注参数改变它。核心玩法不可编辑。

### 2.2 模板的准入判据

不是任何多人玩法都能进模板库。**一个模板存在的唯一理由，是它能让人露出本性。**

| 判据 | 含义 | 不合格的样子 |
|---|---|---|
| **1 · 无最优解** | 每个决策点都不存在"正确答案" | 有最优解 → 全场选一样的 → 采样结果全是噪声 |
| **2 · 可观测** | 决策要么公开，要么能被旁人推断 | 只有自己知道的选择，读不出任何东西 |
| **3 · 价值取舍** | 取舍发生在两种价值观之间，不是两个数值之间 | "押 3 日还是 5 日"读出的是算术，不是人 |
| **4 · 随机性不得成为借口** | 结果可以随机，**决策不能有随机性当挡箭牌** | 见下 |

第 4 条是这次砍模板的主刀：

> 牌桌上"我弃牌是因为牌烂"是一句无法反驳的借口——**性格信号被牌力吸收了**。
> 而俄罗斯轮盘里"我把枪口转向你"没有任何借口可讲。
>
> **结果随机没关系，选择必须裸露。**

按这四条，首批模板从十个收敛到六个。被砍掉的（德州扑克变体、盲拍卖、信息竞价、排位淘汰赛）
共同的毛病是**决策的主体是估值与概率，不是人**；它们各自的味道会以规则修正件的形式回到留下的模板里。

### 2.3 首批六个模板

| # | 模板 | 人数区间 | 单局时长 | 核心张力 | 主要采样 | 适配权柄系 | 阶段 |
|---|---|---|---|---|---|---|---|
| **T-11** | **暗账** ★首发 | 4–16 | 20–30 分钟 | 暗中记账 / 公开对账 / 三次处刑 | **R1–R4 全维度** | 子·鼠、丑·牛、卯·兔、亥·猪 | **验证期** |
| T-02 | **投票放逐** | 8–16 | 20–30 分钟 | 舆论、串供、公开处刑 | 从众 vs 独立 | 辰·龙、戌·狗、申·猴 | **验证期** |
| T-10 | **契约谈判** | 6–12 | 25–40 分钟 | 承诺、违约、担保 | 言行一致性 | 戌·狗、申·猴、丑·牛 | 成型期 |
| T-05 | **密室搜证** | 8–12 | 30–45 分钟 | 信息不对称 + 伪证 | 独占 vs 共享、诚实 vs 伪造 | 巳·蛇、子·鼠、酉·鸡 | 成型期 |
| T-06 | **俄罗斯轮盘** | 4–10 | 10–15 分钟 | 纯粹的生死递进压力 | 把代价推给谁 | 寅·虎、未·羊、卯·兔 | 主持期 |
| T-07 | **协作拼图** | 8–16 | 25–35 分钟 | 表面协作 / 暗中破坏 | 伪装的耐性 | 丑·牛、午·马、巳·蛇 | 主持期 |

### 2.4 逐个说明

**T-11 暗账（首发 · MVP 样板）**
为"性格采样"专门设计的模板，也是密令假设的对照床——**它在没有密令时是刻意平庸的**，
因此可以直接跑"有密令 / 无密令"两版，差异全部归因于密令（[09](09-open-questions.md) R-01 的缓解手段）。
它同时吸收了原 T-04 囚徒困境网格的报复链结构。核心循环见 §2.5。

**T-02 投票放逐**
最经典的"我和人博弈"。发言、串供、公开处刑的载体，
也是回响 3 阶「共鸣」最容易打出名场面的舞台。
它的采样维度偏窄（从众 vs 独立、指认 vs 沉默），因此定位为暗账的互补品而非替代品。

**T-10 契约谈判**
纯社交模板，几乎没有随机性。契约一旦缔结就被强制执行（违约自动扣余命），
因此"敢不敢签"是唯一的博弈。它对**言行一致性**的采样精度全库最高，是戌·狗系生肖的主场。

**T-05 密室搜证**
唯一强依赖可走动场景的模板，与大世界共用同一套空间语言。
信息以"物件"形式散布，可被藏匿、伪造、垄断——**采样的是"你拿到独家信息后怎么处置"**。

**T-06 俄罗斯轮盘**
最短、最残酷，适合作为第 7–9 日的高致死率关卡。
它是"随机性不得成为借口"这条判据的正面样板：**枪的结果是随机的，把枪口转向谁不是。**

**T-07 协作拼图**
表面全员共赢，密令池中埋着破坏者。它检验"密令能否把合作玩法变成猜疑玩法"，
采样的是**伪装的耐性**——一个人能装多久的好人。

> 原 T-09 排位淘汰赛承担的「大终焉」骨架职能，改由**多房间并联 + 跨房结算**实现，
> 而不是把单局人数上限抬到 16 以上。

### 2.5 T-11 暗账 · 核心循环

余命的单位是"日"，这一关就是一本账。**6 轮，分 3 个账期，倍率 ×1 / ×2 / ×3。**

#### 每轮三拍

**① 记账（暗）** —— 每人私下选一个目标 + 一个动作：

| 动作 | 效果 | 采样 |
|---|---|---|
| **夺** | 从目标账上划走 1 日（×账期倍率）到自己账上 | R1 复仇 |
| **担** | 替目标承担本轮的一次损失。目标本轮没被夺 → 白费一轮 | R2 补偿 |
| **匿** | 本轮免疫夺与窥，但自动扣 1 日（藏起来也要花钱），且不能有任何收益 | R3 逃避 |
| **窥** | 看到目标本轮选了什么动作，但不知道他的目标是谁 | R4 支配 |

四个动作**互相之间没有最优解**：夺是零和进攻但树敌，担是利他但可能打空，
匿是安全但持续失血，窥给信息但不解决任何问题。

**动作互相咬合，制造"只有两个人知道的秘密"**——这是本模板的社交燃料：

| 撞上 | 结果 |
|---|---|
| 夺 × 匿 | 扑空。**被夺者知道"有人来夺我"，但不知是谁** |
| 夺 × 担 | 担成功。**夺的人与担的人互相知道对方是谁**——两人在暗中照了个面 |
| 担 × 无人夺 | 白费。**被担者知道"有人保了我"，不知是谁**——一道恩情谜题 |
| 两人夺同一目标 | 争夺，双方受损，**且互相暴露** |

> 不是全公开，也不是全隐藏，而是**碎片化的私密共知**。
> 它必然被拿去交易、试探与撒谎——玩家之间会长出"我知道你知道我知道"的结构。

**② 对账（公）** —— 只公布**结果**，不公布**执行者**。
公示粒度随人数缩放：密室档只给总量，主流档给"谁被夺了"，舆论档给分布。

**③ 表态（公）** —— 每人必须公开表态，三选一：

| 表态 | 规则 | 采样 |
|---|---|---|
| **指认 X** | 属实 → X 下轮不得选匿；不实 → **你自己扣 1 日** | 攻击性 |
| **担保 X** | X 在之后两轮内夺了任何人 → **你连坐扣 2 日**；X 干净 → 你得 1 日 | 为他人承担风险 |
| **沉默** | 无代价，但被记录。连续沉默 3 轮 → 全场可见"此人始终沉默" | 回避 |

#### 账期结算：平账与留账

每个账期结束（第 2 / 4 / 6 轮后）：

1. **平账**：账面最少者**销账**（出局，转观测者态）。一局三次公开处刑。
2. **留账**：被销账者在离场前，可将自己剩余的全部余命作为**一笔坏账记到任意一人头上**，或选择不记。
   **全场公开，不可逆。**

> 留账是本模板最重的一个决策点：**带走害你的人（R1）／带走最强的人（战略）／谁也不带（R2 或 R3）。**
> 它同时是全场最大的名场面、最强的性格采样点，以及最纯粹的"人之将死"。

#### 账期间隙：私聊窗（60 秒）

任意两人可私下缔约，**口头，系统不强制执行**（强制执行是 T-10 的职能）。
承诺与后续行为是否兑现，直接喂给 [04 §8.3](04-echo.md) 的**一致性**采样维度。
`窥` 拿到的情报在这里才真正变现——**它是私聊窗里最硬的货**。

#### 为什么这个结构成立

| 设计目标 | 由哪一处承担 |
|---|---|
| 决策密度 | 每轮 3 个决策 × 6 轮 ≈ 18 个决策点，全部是价值取舍 |
| 张力曲线 | 账期倍率 ×1→×3，后期每一次决策都重三倍 |
| 不可逆事件 | 三次平账处刑 + 三次留账 |
| 采样精度 | **暗动作（你做的）× 公开表态（你说的）两个独立维度交叉** |
| 骨架平庸 | 零概率、零操作、规则一句话讲完 → 合格的密令对照组 |
| 回响挂载 | 窥/匿 是 L1 信息层的原生动词；夺的结算与连坐是 L2；规则层由 L3 介入 |

> **言行不一本身就是最强的性格信号**——申·猴诡辩与巳·蛇谎言正是从暗动作与公开表态的这道缝里长出来的。
> 单维度的模板读不出这个，这也是暗账相对投票放逐的核心优势。

## 3. 创作者的词汇表

关卡设计者的全部创作，都发生在两张清单之间：**在什么时机（触发时机）**，**发生什么（效果）**。

### 3.1 触发时机

这是关卡设计者可以"挂钩"的全部瞬间。它是一份**封闭清单**——扩充属于官方内容更新。

**流程节点**

| 时机 | 设计用途 |
|---|---|
| 关卡开始 | 开场规则、初始分配、气氛铺垫 |
| 关卡结束 | 终局清算、隐藏规则揭晓 |
| 回合开始 | 周期性压力（每回合抽血、每回合公示） |
| 回合结束 | 周期性结算、连锁反应的落点 |
| 阶段进入 / 阶段离开 | 与模板流程绑定的阶段性规则 |
| 倒计时归零 | 时间压力的落点 |

**玩家行为**

| 时机 | 设计用途 |
|---|---|
| 玩家行动前 | 提前干预、剥夺选择、预警 |
| 玩家行动后 | 行为的即时代价 |
| 发言时 | 把"说话"本身变成有代价的动作 |
| 押注时 | 与余命经济直接挂钩的规则 |
| 弃权时 | **最被低估的时机**——把消极选项变成危险选项 |

**局面变化**

| 时机 | 设计用途 |
|---|---|
| 投票结算 | 舆论型关卡的核心挂载点 |
| 出局判定 | 死亡的连锁反应（连坐、遗产、复仇） |
| 余命变动 | 经济波动的连锁反应 |
| 信息揭示 | 秘密被公开时的二次代价 |
| 契约缔结 / 契约违约 | 承诺类玩法的骨架 |

**回响与密令**

| 时机 | 设计用途 |
|---|---|
| 密令达成 | 完成密令的副作用（暴露、反噬、连锁） |
| 密令失败 | 失败的叙事与代价，也是**渴望值的重要产出点** |
| 回响发动 | 对超能力者的针对性规则 |
| 回响被压制 | 让"你试图发动却失败了"这件事产生后果 |

> **弃权时** 与 **密令失败** 这两个时机值得单独强调：
> 它们把玩家最消极、最挫败的瞬间，转化成了新的博弈材料。

### 3.2 效果：四层分级

效果按**能触及的层级**分为四层。这个分级同时定义了回响的阶数上限——
**这是设计上的对称性，不是巧合**。

#### L1 · 影响信息（对应回响 1 阶「微响」）

| 效果 | 设计含义 |
|---|---|
| 揭示信息 | 把某项隐藏信息对指定范围公开 |
| 隐藏信息 | 使某项本应公开的信息不进入记录 |
| 伪造记录 | 向公开记录写入一条不实条目（必须留有可被识破的途径） |
| 重播发言 | 让某句已说出的话再次对全场呈现，无法抵赖 |
| 私密传讯 | 在两名编号之间建立一次性的单向信息通道 |
| 标记 | 给某编号附加一个可见或不可见的标签 |

#### L2 · 影响判定（对应回响 2 阶「回响」）

| 效果 | 设计含义 |
|---|---|
| 扣减余命 / 增加余命 | 最直接的代价与奖励 |
| 强制行动 | 剥夺选择权，令某编号执行指定行动 |
| 禁止行动 | 移除某编号的某类合法行动 |
| 改判 | 覆盖一次已经产生的判定结果 |
| 转嫁 | 把某编号承受的代价按比例转移给他人 |
| 豁免 | 使一次出局判定或代价判定失效 |
| 延迟结算 | 把一次结算推迟到指定时机，制造悬置的恐惧 |

#### L3 · 影响规则（对应回响 3 阶「共鸣」）

| 效果 | 设计含义 |
|---|---|
| 修改规则参数 | 改变回合数、上限、阈值等模板可调数值 |
| 启用 / 禁用行动类型 | 全局开关某一类合法行动 |
| 注入密令 | 向指定编号追加一条新密令 |
| 撤销密令 | 使某条密令失效 |
| 变更胜负条件 | 替换本关的结算判据 |
| 变更压制 | 临时提升或解除对回响的压制 |
| 插入阶段 | 在流程中插入一个额外阶段 |

#### L4 · 影响他人（仅生肖可用，对应回响 4 阶「权柄」）

| 效果 | 设计含义 |
|---|---|
| 对他人施加规则 | 令某编号在后续若干关卡内携带一条个人规则 |
| 裁量 | 对模糊条款作出具有约束力的解释，**必须留下公开的裁决记录** |
| 褫夺 | 暂时剥夺某编号的回响使用资格 |
| 收成调节 | 调整本关收成的计算权重，受审计 |

### 3.2.1 这张效果清单同时是「语义接口」

§3.2 的四层效果表不只是作者的词汇表，**它同时是模板必须实现的接口清单**。

原因见 [04 §7.5](04-echo.md)：回响不携带具体效果，只携带**语义锚点**（动词 + 作用对象 + 层级）。
一条回响能不能在你的模板里生效，取决于你的模板有没有实现那个动词。

| 层级 | 模板的义务 |
|---|---|
| **L1 影响信息** | **必须全部实现**，否则不得上架 |
| **L2 影响判定** | **必须全部实现**，否则不得上架 |
| **L3 影响规则** | 可以部分实现。未实现的动词，相关回响自动降级为同系 L2 近似效果 |
| **L4 影响他人** | 仅生肖可用，模板不必实现 |

> **这条约束是给模板定的，不是给关卡作者定的。** 作者选了模板就自动满足，
> 他永远不需要知道全服有哪些回响存在。

实现一个动词的含义是：**把它翻译成这张牌桌上的一个具体动作**。
例如 `豁免 · 一次针对我的出局判定`——
在投票放逐里是"被票出去但仍在场"，在暗账里是"账面垫底但没被销账"，在俄罗斯轮盘里是"实弹但没倒下"。
表现各不相同，玩家的体验是同一句话：**"我该死，但我没死。"**

**新模板的验收标准之一，就是把 L1/L2 的每一个动词都跑通一遍。**

### 3.3 可见性：规则对谁公开

| 可见性 | 体验 | 典型用途 |
|---|---|---|
| **公开** | 关卡开始时全场可见 | 主规则，公平竞技 |
| **延迟公开** | 首次触发后转为公开 | 陷阱型规则，触发即示众 |
| **定向** | 仅特定编号可见 | 与密令配合的私人规则 |
| **隐秘** | 全程不公开，仅事后可查 | **慎用**，需通过审核 |

**设计约束**：单个关卡的 `隐秘` 规则**不得超过 2 条**，且不得直接致死或扣除余命。

理由很硬：**不可知的致死规则会摧毁玩家对公平的信任**，而公平感知是社交博弈游戏的生命线。
玩家可以接受"我被骗了"，但不能接受"我根本没机会知道"。
（这条限制是否还应更严，见 §6 未决问题。）

### 3.4 深度来自组合，不来自表达能力

关卡最多挂 8 条修正件，看起来很少。但修正件之间会**互相咬合**——
一条修正件的效果，可以成为另一条的触发条件。

> **修正件 A**：`弃权时` → 扣减余命 1 日
> **修正件 B**：`余命变动` 且变动为负 → 揭示该编号的一条密令线索
>
> A 与 B 单独看都很朴素。合在一起，**"弃权"变成了"公开泄露自己的秘密"**——
> 弃权从一个消极选项，变成了社会性死亡的开关。
>
> 作者没有发明任何新规则，却造出了一条全新的心理压力线。

这就是我们要的：**深度来自组合，不来自表达能力。**

## 4. 一个关卡由哪些部分组成

从创作者视角，做一个关卡要依次决定六件事。

### 4.1 这是一个什么样的关卡（关卡信息）

关卡名、一句话简介、开场规则说明、内容分级，以及最重要的两项：

- **所属日层**：试炼层 / 倾轧层 / 崩坏层 / 终焉。它决定了这关的预期致死率与匹配对象。
- **预期时长**：与实际偏差过大会破坏玩家的轮回节奏安排。

### 4.2 用哪张牌桌（基础玩法模板）

从十个模板中选一个，**设定这一关要几个人**（不得超出模板本身的人数区间），
并决定**是否允许 AI 编号补位**。禁止补位的关卡更"纯粹"，但开局会慢得多。

**平台支持的人数区间是 4–16 人。** 具体模板可以更窄，但不得超出这个范围。
下限 4 是为了让关卡在冷启动与深夜时段仍然开得起来；上限 16 是发言秩序的天花板，
再多就只能靠"限制发言人数"这类硬约束维持，已经不是同一种体验了。

人数是作者的核心表达手段之一，不是一个填空项。**同一张牌桌在三个规模档下是三种游戏：**

| 档 | 人数 | 局面性质 | 作者要注意 |
|---|---|---|---|
| **密室档** | 4–6 | 每个人都被盯着，谎言几乎藏不住，一次背叛全场都知道是谁 | 密令互斥度要低，否则局面瞬间锁死；**"指认"失去舆论意义**，因为没有舆论 |
| **主流档** | 7–11 | 结盟、背叛、情报差都有生长空间。**默认选择** | 冲突度按 [03](03-mandate.md) 的 C ∈ [0.35, 0.55] 正常配 |
| **舆论档** | 12–16 | 个体被淹没，玩法从"我和你"漂移到"我和舆论" | 需要更强的发言/回合约束；密令要允许"同类多人持有"，否则冲突图配不出来 |

**人数越多，单个密令的可达成性越低，冲突图越难收敛**——见 [03 密令系统](03-mandate.md) 的冲突度计算。

> **要求：模板必须自带随人数缩放的规则档位**，而不是让作者手填一堆参数。
> 至少包括：每回合可行动次数、公示信息的粒度（人少时更模糊，人多时更精确）、
> 以及密令池的冲突度目标值。**作者选了人数，就等于选了一整套体验，这是设计意图，不是副作用。**

### 4.3 往桌上扔什么规则（规则修正件）

从词汇表中挑选并组合，每条修正件需要给出面向玩家的**规则文案**。

> **硬约束：单个关卡最多 8 条修正件。**
> 超过这个数量，玩家在开局前读不完也理解不了，关卡会从"博弈"退化成"混乱"。
> 规则数量不是深度，规则之间的咬合才是。

### 4.4 这一关要逼人做什么（密令池）

决定密令的内容、分发方式（全员 / 部分 / 加权随机），以及冲突策略——
是允许互斥、禁止完全互斥，还是**强制至少存在一对互斥**。

> **硬约束：密令的达成与否必须能被客观判定。**
> 不允许"让某人感到恐惧"这种无法判定的目标；
> 应改写为"使某人在本关内弃权至少两次"。

密令池是关卡人格的真正来源，远比修正件重要。详见 [03 密令系统](03-mandate.md)。

### 4.5 回响能不能用（压制配置）

见 §5。这一项**不向门外公示**，进场后由主持人在规则宣读阶段说明。
它是关卡最有价值的一条"隐藏难度"，也是玩家之间口耳相传的情报。

### 4.6 谁来主持、赌注多大

- **生肖归属**：这一关属于十二权柄的哪一系。它同时限定了可用的修正件范围与叙事气质。
- **主持方式**：作者亲自主持 / 指定生肖 / AI 生肖代行（见 [08](08-host-and-ugc.md)）。
- **押注参数**：入场押注、**单局余命损失上限**（防止一局清空一个编号）、赔付曲线、造关者抽成比例。

### 4.7 玩家在门口看到的是什么（信息可见性）

关卡不在菜单里，也不在匹配列表里。**关卡是 2D 大世界中的一栋建筑。**
玩家走到门前、靠近交互，才能读到这一关的公示牌。

公示牌上**只有四项**：

| 公示项 | 内容 | 玩家拿它判断 |
|---|---|---|
| **类型** | 基础玩法模板（暗账 / 放逐 / 缔约 / 搜证……） | 我熟不熟这张牌桌 |
| **难度 · 死亡率** | 所属日层 + 历史致死率 | 我这条命撑不撑得住 |
| **人数** | 本关的开局人数（作者设定） | 局面有多大，我能不能藏得住 |
| **门票** | 入场需要支付的余命 | 我付不付得起，值不值 |

**门口看不到的**：挂了哪些规则修正件、密令池的内容与冲突策略、谁来主持、压制的细则。
这些要么进场后由主持人宣读（[01 §2.1](01-core-loop.md) 的第 ② 步），要么永远只有作者知道。

这不只是"少显示几个字段"，它有三层设计意图：

1. **选关本身就是一次信息不全的赌博**，与整个游戏的信息结构完全一致。
   如果门口把规则全列出来，玩家会站在门外用攻略把这一关解完，进场只剩执行。
2. **门票 × 死亡率 × 人数是天然的分层器**。不需要额外的等级门禁——
   一栋 30 日门票、死亡率 60% 的楼，自己就会劝退新人。
3. **建筑是长期驻留的地标**。同一栋楼的公示牌会在玩家之间口耳相传，
   关卡因此获得了"名字"和"传说"，而不是列表里的一行字。

> **已拍板（D-11）**：压制**不进公示牌**，连总体标签都不给。
> 玩家可以自行交流、贩卖、伪造这条情报，但系统不公开它。理由与缓冲见 §5.3。

## 5. 压制：不公开的第四个难度维度

### 5.1 问题

回响是玩家私有的规则例外权。关卡作者在设计时**无法预知**进场的编号带着什么回响。
一个精心设计的投票放逐关卡，可能被一名辰·龙系 3 阶回响者一句话摧毁。

### 5.2 两种错误的解法

- **全局削弱回响** → 玩家几十小时的追求变成废纸，权柄轴崩塌。
- **让作者逐条禁用具体回响** → 作者不可能穷举，且会演变成军备竞赛。

### 5.3 正确的解法：把压制变成一条要靠人打听的情报

压制不是"防止关卡被破坏的补丁"，而是**与人数、时长、致死率并列的第四个难度维度**。

但它**不公示**。门口的公示牌只有四项（§4.7），压制不在其中。
玩家想知道这栋楼封不封回响，只有三条路：**进去一次、问一个进去过的人、或者花余命买。**

| 压制模式 | 体验 | 适用场景 |
|---|---|---|
| **无压制** | 超能力者的修罗场。回响满天飞，局面极度不可预测 | 高日数关卡、赛季活动、回响者专场 |
| **部分封锁** | 只封某几系。例如封锁巳·蛇后，"**没人能伪造信息**"本身就成了一条重要情报 | 主流配置，作者的主要调味手段 |
| **代价加重** | 回响可用，但烧掉的记忆翻倍，逼迫回响者做"值不值"的抉择 | 中高难度关卡的默认选项 |
| **绝缘区** | 回响完全失效，所有人回到赤手空拳 | 试炼层教学关；以及**最恐怖的高日数关卡** |

#### 为什么不公示

公示压制看起来对回响者更"公平"，但它会同时毁掉两样东西：

1. **它会把关卡变成一道有标准答案的题。** 门口写着"封锁巳·蛇"，玩家进场前就知道没人能伪造信息，
   于是整局的信息结构在开局前就被确定了。而**不写**，"这里到底能不能骗人"本身就成了一个要在局内试探的问题——
   有人试着发动、被拦下、全场哗然，这一瞬间产生的信息量远大于门口的一行标签。
2. **它会掐死一条完整的情报生意。** 压制是**可复述、可验证、会过时**的知识：
   进去过的人知道，没进去过的人愿意付余命买，而作者随时可以改配置让旧情报失效。
   这正是余命经济里最健康的那类商品——不是道具，是**别人的经验**。

> **玩家之间自由交流压制信息，是被鼓励的，不是漏洞。**
> 系统不公开，玩家自己会把它挖出来、传出去、卖出去，甚至故意传错。
> 这比一个官方标签有趣得多。

#### 必须补上的三道缓冲

不公示的代价是"付了门票才发现能力失效"。这个挫败必须被吸收掉，而不是硬扛：

| 缓冲 | 做法 |
|---|---|
| **开场宣读** | 压制在②规则宣读阶段由主持人明确说出。玩家是在**押注之后、博弈之前**知道的，而不是在被拦下的那一刻 |
| **建筑记忆** | 你进过一次的建筑，它的压制配置会在你自己的公示牌视图上多显示一行。**这是你的知识，不是系统的公告** |
| **改配置要留痕** | 作者修改压制后，去过的玩家再靠近时会看到"这栋楼变了"，但不告诉他变成了什么 |

### 5.4 为什么"绝缘区"是恐怖的，而不是无聊的

对普通编号，绝缘区意味着公平。

对回响者，绝缘区意味着**他赖以为生的东西被拿走了**——
而他之所以成为回响者，正因为他曾被逼到绝境。绝缘区把他重新推回那个位置。

这制造了一个漂亮的反转：**越强的玩家，越怕这类关卡。**
它天然地为高阶玩家提供了难度，而不需要任何数值堆砌。

### 5.5 被压制的发动依然会被看见

这一点在体验上至关重要：

> 当有人试图发动回响却被拦下时，**全场都会看到**。
>
> 你暴露了自己是回响者，却什么都没得到。

在压制不公示的前提下，这一条的分量还要更重：**第一个撞上压制的人，等于免费替全场做了实验。**
他用自己的身份暴露，换来了所有人都能用的一条情报。

这是一条极有价值的社交信息，也是压制模式的隐性代价。
回响者在绝缘区里最怕的不是没能力用，是**忍不住去用**。

## 6. 什么是坏关卡

### 6.1 四类必须被拦下的关卡

无论作者主观意图如何，以下四类关卡在体验上都是失败的：

| 类型 | 表现 | 为什么是坏的 |
|---|---|---|
| **死锁** | 出现所有编号都无合法行动的局面 | 玩家干坐着，游戏停在那里 |
| **必然屠杀** | 无论怎么玩都全员出局 | 决策毫无意义，玩家会正确地把它归因为"关卡在耍我" |
| **必然无人出局** | 无论怎么玩都不会死人 | 押注失去重量，整局没有恐惧 |
| **密令组合无解** | 密令池中存在无论如何都不可能达成的条目 | 拿到那条密令的人，从开局就已经输了 |

> **关键区分**：密令**互斥是特性，不可达是缺陷**。
> "我和他不可能同时完成"是好设计；"我一个人怎么做都完不成"是坏设计。

除此之外还有两类需要警惕但不必一律拦下的：

- **结局被锁死**（不同打法结果几乎相同）→ 玩家决策无意义，博弈坍缩。
- **开局即死**（首个出局集中在第一回合）→ 玩家还没参与就出局了。

**上线前应先用 AI 编号大量试跑，把这几类坏关卡在见到真人之前筛掉。**

### 6.2 四维评分

不使用单一的"好评 / 差评"，而是关卡结束后向玩家征集**四维打分**（可跳过）：

| 维度 | 问题 | 用途 |
|---|---|---|
| **公平** | 你输的时候，知道自己为什么输吗？ | **最重要的维度**，低分直接降权 |
| **张力** | 有没有让你手心出汗的时刻？ | 核心体验指标 |
| **清晰** | 开局时你看懂规则了吗？ | 检测规则过载 |
| **叙事** | 主持人的演出是否加分？ | 反馈给主持人调优 |

**造关者声望主要由「公平」与「张力」驱动，而不是游玩次数**——
这是刻意的，用来防止刷量型垃圾关卡挤占推荐位。

### 6.3 灰度与下架原则

| 阶段 | 原则 |
|---|---|
| **沙盒** | 只有作者与受邀编号能进，不消耗真实余命。作者可以随便试错 |
| **灰度** | 向少量自愿尝鲜的编号开放，真实结算但**余命波动上限减半**。风险由平台分担一半 |
| **正式** | 评分与数据达标后进入，开始正常抽成 |

下架不应该只看差评，而应看这几类信号：**中途退出率异常、致死率与标注严重不符、举报累计、确认存在漏洞利用**。
其中"确认存在漏洞利用"应当立即下架并冻结该关已产生的抽成——
**造关者从"设计了不公平的关卡"中获利，是这个生态最不能容忍的事。**

作者修改已上架的关卡时，应视同一次新的提交，重新走一遍准入。

## 7. 未决问题

1. **修正件上限 8 条是否过紧？**
   8 条能保证玩家读得完，但可能限制"复杂规则怪谈"类关卡的表达。
   是否应按日层分级放宽（试炼层 4 条 / 崩坏层 12 条）？需要用真实关卡验证。

2. **`隐秘` 可见性是否应该彻底取消？**
   目前限制为 2 条且不得致死。但即便如此，未公开的规则依然会伤害玩家对公平的感知——
   而公平是评分的第一维度。取消它会损失"规则怪谈"的惊悚感，保留它会带来长期的信任成本。
   **折中方案**：改为"存在已知、内容未知"——公示"本关有 2 条隐藏规则"，但不公示内容。需主创拍板。

3. **基础玩法模板是否永久封闭？**
   长期看，最优秀的造关者一定会想要新模板。
   是否设立"模板提案"通道（作者提交设计文档 → 官方实现），并给予提案者永久署名与分成？
   这会显著改变创作者生态的天花板。

4. **同一关卡是否允许多个权柄系混搭？**
   目前一个关卡归属单一权柄系，风格纯粹、玩家预期清晰。
   但"巳·蛇 + 酉·鸡"这类组合在叙事上极具吸引力。
   若开放混搭，如何避免关卡失去辨识度？倾向：允许一主一副，副系修正件不超过 2 条。

5. **密令池应该由作者全权决定，还是必须掺入官方密令？**
   全权决定给作者最大自由，但作者容易只写"猎杀型"密令，导致关卡同质化。
   倾向：强制要求密令池覆盖至少 3 种分类，或由官方按比例掺入。

6. **关卡是否需要"重玩价值"的设计要求？**
   一个搜证类关卡在玩家知道答案后就失效了，但它可能第一次体验极佳。
   平台是否应当区分"一次性关卡"与"可重复关卡"，并在推荐与抽成上区别对待？
