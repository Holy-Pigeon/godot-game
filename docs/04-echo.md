# 04 · 回响系统

> 状态：草案 v0.1 ｜ 关联：[00 高概念](00-overview.md)、[01 核心循环](01-core-loop.md)、[02 余命与记忆](02-economy-lifespan-memory.md)、[03 密令](03-mandate.md)、[05 十二权柄](05-zodiac-authority.md)、[07 规则引擎](07-level-pack-and-rule-engine.md)

**本文档是整个项目最核心的系统设计。** 它同时承担：超能力、长期目标、叙事驱动、翻盘机制、以及与 UGC 分类体系的接口。

---

## 1. 一句话定义

> **回响 = 当下的绝境，与你过去的伤口，产生了共振。**

它不是"你获得了能力"，而是"**你的过去回答了你**"。

这个定义不是文学修辞，它是三条硬性设计约束的来源：

| 定义中的词 | 导出的机制约束 |
|---|---|
| **绝境** | 只能在濒临失去时激活 → 天然是**翻盘机制**，不是滚雪球机制 |
| **过去的伤口** | 必须绑定**前史**，每人的回响独一无二 → 不可交易、不可购买、不可攻略 |
| **共振** | 需要"情境 × 前史"对上频率 → 天然**稀有**，但人人有机会 |

---

## 2. 三条不可违背的铁律

### 铁律 1：回响是逆转系统，不是成长系统

> **渴望只从"失去"中产生，绝不从"胜利"中产生。**

顺风的玩家永远攒不出回响，被逼到墙角的人才会觉醒。这条写死在数值里，它保证了：
老玩家不会因为玩得久就更强，而是**因为受过更具体的苦，才拥有更奇特的能力**。

### 铁律 2：回响是"规则例外权"，不是技能

如果回响是"我放火球 / 我加移速"，整个游戏会退化成动作游戏，
而所有 UGC 关卡（德州、投票、拍卖）会**全部崩溃**——它们是规则博弈，不是操作博弈。

> **回响 = 玩家私有的一张规则修正件，可以对当前关卡的规则开一个例外。**

**工程红利**：回响与关卡的[规则修正件](07-level-pack-and-rule-engine.md)走**同一套事件总线、同一套裁决管线**，
只是来源不同（作者 vs 玩家）。不需要写第二套系统。

### 铁律 3：回响跨轮回传递"信息与关系"，绝不传递"力量"

回响者带着记忆进入下一轮回，但那份记忆的价值必须**锚定在"人"，而不是"题"**：

> 上一轮，7 号在最后一刻把你推了出去。
> 而这一轮，7 号不记得这件事。

这个不对称提供的是**动机、猜疑与复仇**，不是数值优势。
（关卡是 UGC 无限产出的，记住某关解法本来也几乎没用。）

## 3. 前提：前史不是选的，是"被还给你的"

如果让玩家在建号时挑背景，所有人都会挑最强的那个，**整套分类系统当场作废**。

正确做法：

> **所有编号入场时都是失忆的。前史通过记忆碎片一片片被找回，
> 而系统根据你在前几个轮回里的实际行为，决定还给你哪一段过去。**

| 你的行为 | 系统还给你的过去 |
|---|---|
| 反复背叛他人 | "你曾被最亲的人背叛" |
| 屡次为救人而死 | "你曾眼睁睁看着某人死去" |
| 从不主动出击，只求苟活 | "你曾长期被困在一个出不去的地方" |
| 疯狂囤积余命 | "你曾拥有的一切被人夺走" |

每次拿到碎片时，给玩家 **2–3 种解读**去选：

> *「那天我恨他」 / 「那天我原谅了他」 / 「那天我什么都没想」*

**行为决定题目，玩家决定答案。** 既防了 min-max，又保留了玩家的作者权。

于是玩家路径是：

```
失忆的编号 → 行为被观测 → 记忆碎片(前史) → 执念成型 → 遇到共振情境 → 觉醒回响
```

> 真相轴的第一层不是世界的真相，**是你自己的真相**。而找回自己，正是觉醒的前置条件。
> 三条长期轴在这里合流。

## 4. 分类表一 · 经历（决定回响"是什么"）

经历不是一个标签，是**两层的乘法**。

### 4.1 创伤类型（八种 · 你身上发生了什么）

| 代号 | 创伤 | 内核 | 典型前史片段 |
|---|---|---|---|
| W1 | **背叛** | 信任被利用 | 被挚友出卖；被同伴推出去顶罪 |
| W2 | **无力** | 看得见，做不到 | 眼睁睁看着，伸手够不到 |
| W3 | **剥夺** | 本属于你的被夺走 | 成果被冒领；位置被顶替 |
| W4 | **欺瞒** | 你活在别人编的故事里 | 半生的真相是假的 |
| W5 | **弃绝** | 不被需要 | 被抛下；被判定为多余的那个 |
| W6 | **罪咎** | 你才是加害者 | 你活下来是因为别人没有 |
| W7 | **囚禁** | 无法离开 | 长期被困、被规训、动弹不得 |
| W8 | **湮没** | 无人记得你 | 你存在过，但没有留下痕迹 |

### 4.2 应对方式（四种 · 你当时怎么做的）

| 代号 | 应对 | 内核 |
|---|---|---|
| R1 | **复仇** | 我要让他也尝一次 |
| R2 | **补偿** | 我要把它还回去 |
| R3 | **逃避** | 我不要再靠近 |
| R4 | **支配** | 只要一切都在我手里，就不会重演 |

### 4.3 执念矩阵（8 × 4 = 32 种）

## 5. 分类表二 · 触发条件（决定回响"多强"）

> **条件越苛刻 → 回响越强。** 这是玩家提出的核心要求，也是本系统的平衡阀。

为了让引擎能判定，触发条件必须是**若干条款的合取（AND）**，每条来自一个类别。

### 5.1 触发条款类别

| 类别 | 说明 | 示例条款 | 苛刻权重 |
|---|---|---|---|
| **共鸣类** | 当前情境与前史节点匹配 | 「加害你的人，正处于你前史中那个人的位置」 | **必选 · 不计权** |
| **境况类** | 客观绝境 | 余命 < 10%／全场只剩你一人／你已进入出局判定 | ★ |
| **关系类** | 人际结构 | 加害者是你本轮回信任过的人／你的宿敌在场／你的守护对象已死 | ★★ |
| **时机类** | 窗口极窄 | 仅在死亡判定的最后一次结算／一轮回仅一次／仅在第 N 日 | ★★ |
| **代价类** | 主动付出 | 必须先主动放弃一条生路／已烧掉 ≥3 条记忆／自愿公开自己的密令 | ★★★ |
| **禁忌类** | 长期行为约束 | 本轮回你从未说谎／从未导致任何人出局／从未使用过任何道具 | ★★★★ |

**共鸣类是每条触发条件的必选项**，它锚定了"回响必须与角色过去的经历有关"这条要求。

### 5.2 为什么禁忌类最强

禁忌类约束的不是一个瞬间，而是你**几十小时的行为方式**。

想要顶级回响，你必须**活成某一种人**——这是本系统最珍贵的一条：
它把"数值强度"换算成了"角色扮演的自律"，而且**完全无法用付费或肝度绕过**。

> 一个只玩了 15 个轮回、但从头到尾没撒过一次谎的玩家，
> 可以拥有比玩了 200 轮回的老油条更强的回响。

### 5.3 苛刻度计算

```
苛刻度 = Σ(条款权重) × 条款数量修正
条款数量修正：2 条 ×1.0 ｜ 3 条 ×1.15 ｜ 4 条 ×1.3 ｜ 5 条及以上 ×1.5
```

（初值待实测标定，见 [02](02-economy-lifespan-memory.md) 的参数表约定。）

## 6. 分类表三 · 强度（用"能碰到规则的哪一层"分级）

强度**绝不能用数值定义**（"伤害+50%"之类），必须用**权限层级**定义，才能与规则引擎对齐。

| 阶 | 名称 | 能触及的层 | 举例 | 苛刻度门槛 |
|---|---|---|---|---|
| **0** | **既视感** | 无（纯感受） | 模糊直觉提示："你对这个房间有种说不出的熟悉" | 人人可得 |
| **1** | **微响** | **你自己的信息层** | 隐藏你的一次行动记录／偷看一条隐藏信息／记住一个本该被清除的名字 | ★–★★ |
| **2** | **回响** | **一次判定的结果** | 豁免一次出局／把损失转嫁一半／让某句已说出的话全场重播 | ★★★–★★★★ |
| **3** | **共鸣** | **本关的一条规则** | 3 回合内禁止任何人投票／让弃权视为同意／全场发言进入不可篡改记录 | ★★★★★+ |
| **4** | **权柄** | **对他人施加规则** | 生肖级。你开始成为"规则"本身 | 叙事级事件 |

### 6.1 三条自平衡的硬约束

| 约束 | 机制 | 效果 |
|---|---|---|
| **燃料** | 阶数越高，单次发动烧掉的**记忆碎片**越多（1 阶 1 条 → 3 阶 5 条以上） | 强者被迫遗忘自己是谁。**设定内最漂亮的诅咒** |
| **暴露** | 0–1 阶可隐蔽；**2 阶起全场可见并永久登记**；**3 阶起惊动生肖**，终焉之地会派人来"看看你" | 力量自动招来针对，形成天花板 |
| **窄化** | 越强的回响，触发条件越窄，一个轮回可能一次都对不上 | **它是保命底牌，不是常规手段** |

### 6.2 暴露机制：什么时候亮底牌

这是回响在**局内玩法**上最大的张力来源。

> 回响**未使用时不可见，一旦使用则全场永久可见**。

于是每个回响者都要面对同一个抉择：

- **亮早了** → 你成为全场公敌（"他有回响，先做掉他"）。
- **亮晚了** → 你可能已经死了。

这条把"特权"变成了**高风险资产**，比任何数值削弱都管用。
它也让"回响者"这个身份成为社交博弈的筹码：你可以**谎称**自己有回响（[巳·蛇](05-zodiac-authority.md)系玩家会很喜欢这一点）。

## 7. 合成公式：三张表如何变成一个回响

```
回响 = 系（执念决定）
     + 阶（触发苛刻度决定）
     + 具体效果（前史的细节决定）
```

### 7.1 完整实例走查

> **编号 043**，前史逐步找回：
> 他曾是某个团队的记录员，**同伴集体串供把事故推给他**（创伤 W1 背叛）。
> 他没有反击，只是**把所有证据都留了下来**（应对 R4 支配）。
>
> → 执念 = 背叛 × 支配 → 归 **戌·狗 · 忠诚**系？
> **不。** 前史细节（"留下证据"而非"缔结契约"）把他推向了 **辰·龙 · 改律**系。
> **这就是"前史细节决定具体效果"的含义**——矩阵给方向，细节给形状。
>
> **系统生成的触发条件：**
>
> | 类别 | 条款 | 权重 |
> |---|---|---|
> | 共鸣类 | 在场有人对你做出**公开的集体指认** | — |
> | 关系类 | 指认者中至少一人本轮回与你结过盟 | ★★ |
> | 时机类 | 在最终结算的最后一次发言 | ★★ |
> | 禁忌类 | **本轮回你从未主动指认过任何人** | ★★★★ |
>
> 苛刻度 = (2+2+4) × 1.15 ≈ **9.2 ★** → **3 阶 · 共鸣**
>
> **回响【留证】**：本关剩余全部回合，**所有人的发言都进入不可篡改的公开记录，且无人可以弃权。**

请注意这个能力：它**没有任何数值**，它只是把一条规则改了。
但在一场投票放逐关卡里，它足以**毁灭整个串供联盟**。
而且它只属于 043，因为只有他有这段过去。

## 8. 渴望值（执念的积累）

觉醒不是瞬间的，它需要"渴望"反复冲刷同一个伤口。

### 8.1 渴望值的产出源

| 事件 | 说明 | 归属创伤 |
|---|---|---|
| 余命跌破生死线 | 最基础的绝境 | 通用 |
| 被你**本局信任过**的人背叛 | 需要"信任"是可记录的社交状态 | W1 背叛 |
| 眼看着密令的守护对象死去 | [密令系统](03-mandate.md)在这里第二次发挥作用 | W2 无力 |
| 被同一个编号淘汰第二次 | **宿敌机制**，执念的经典来源 | W1 / W3 |
| 你的密令被公开处刑 | 社死也是一种绝境 | W8 湮没 |
| 你的提议被全场无视 | 弱信号，缓慢积累 | W5 弃绝 |
| 你导致了盟友出局 | 无论是否有意 | W6 罪咎 |
| 连续 N 局无法离开出局线 | 长期压抑 | W7 囚禁 |

### 8.2 三条硬规则

1. **不能用余命购买。**
2. **不能靠连胜积累。** 胜利不产生渴望。
3. **躺平送死不产生渴望。** 见下节。

### 8.3 反"自残刷执念"

玩家一定会尝试故意送死来刷渴望值。

> **对策：渴望值只在"你真实付出了努力后仍然失败"时结算。**

引擎可以评估：行动质量、是否有效抵抗、是否使用了可用资源、发言参与度、是否主动放弃优势位。
**放弃的人不会有渴望**——这在设定上也完全成立，一个自我放逐的人是不会燃烧的。

具体检测维度（初版）：

| 维度 | 判定 |
|---|---|
| 行动参与度 | 本局有效行动数 / 可行动次数 |
| 资源投入 | 是否押注了有意义比例的余命 |
| 抵抗性 | 出局前是否有过反制行为 |
| 一致性 | 行为是否与其公开承诺一致 |

四项均低于阈值 → 本局渴望值产出 **归零**，并记录"消极"标记。

## 9. 觉醒的三重合取（稀有性的来源）

觉醒需要三个条件**同时**成立，这就是"稀有但人人有机会"的机制解：

```
① 前史找回度达标   （真相轴进度，需要记忆碎片）
        ∧
② 情境与前史共振   （运气 + 主动创造）
        ∧
③ 渴望值突破阈值   （必须真的经历过绝境）
```

三重合取意味着：

- **不能靠肝**（②需要机遇，③需要真实失败）
- **不能靠钱**（①②③都不可购买）
- **但对所有人开放**（三条路径都没有门槛，只有时间与选择）

### 9.1 稀有度目标（起始值，待实测调整）

| 阶 | 目标覆盖率（活跃玩家） | 预期达成时间 |
|---|---|---|
| 0 · 既视感 | **100%** | 第 1 轮回 |
| 1 · 微响 | **约 35%** | 第 3–6 轮回 |
| 2 · 回响 | **约 8%** | 第 10–20 轮回 |
| 3 · 共鸣 | **约 0.5%** | 数十轮回 + 极端自律 |
| 4 · 权柄 | **全服个位数** | 叙事事件，需系统/官方认可 |

### 9.2 新人的第一次觉醒

**新手第一次濒死，正是最容易觉醒的时刻。**

设计要求：玩家的**首次濒死强制触发一次 1 阶觉醒演出**（可以是极弱的微响）。

> 这把新人最挫败的瞬间，直接改造成了最高光的入坑时刻。
> 见 [01 首次会话设计](01-core-loop.md#6-首次会话新玩家的前-60-分钟)。

## 10. 回响的进化与分化

回响不是拿到就定死的。跨轮回它会**生长**：

| 阶段 | 触发 | 变化 |
|---|---|---|
| **初生** | 首次觉醒 | 得到 1 条低阶回响，触发条件宽松、效果微弱 |
| **加深** | 同一执念被反复冲刷（同类渴望累积） | 效果强化，或触发条件收窄换取阶数提升 |
| **分化** | 出现第二种主导创伤 | 长出第二条回响，或原回响转向邻近权柄系 |
| **成型** | 单一权柄系内多条回响成体系 | 被终焉之地"注意"，进入生肖候选 |
| **晋升** | 通过认可流程 | 成为该系[生肖](05-zodiac-authority.md)，获得主持与造关资格 |

**玩家可以主动选择方向**：在"扩宽触发条件、降低强度"和"收窄条件、提升阶数"之间做取舍。
这是权柄轴上唯一的显式 Build 选择，其余全部由行为决定。

## 11. 与其他系统的接口

| 系统 | 接口 |
|---|---|
| [记忆碎片](02-economy-lifespan-memory.md) | **回响的燃料**。发动即烧记忆 → 与真相轴直接抢资源 |
| [密令](03-mandate.md) | 密令失败（尤其守护型）是渴望值的主要来源；回响可以扭转密令判定 |
| [十二权柄](05-zodiac-authority.md) | 回响归属某系 → 该系成型后可晋升生肖 |
| [规则引擎](07-level-pack-and-rule-engine.md) | 回响与规则修正件**共用触发器/效果/裁决管线**，只是来源不同 |
| [关卡包 · 压制](07-level-pack-and-rule-engine.md) | 关卡可封锁某类回响 / 让发动代价翻倍 / 设为绝缘区 |
| [死亡与轮回](06-death-and-recurrence.md) | 回响者可携带记忆跨轮回；首次濒死强制觉醒 |

### 11.1 关于压制（UGC 平衡阀）

回响会让 **UGC 关卡的平衡不可控**——作者不知道进来的十个人带着什么例外权。

> **解法：给关卡作者一个「压制」维度。**
> 关卡可声明"本关封锁交换类回响"／"本关内回响发动代价翻倍"／"本关是回响绝缘区"。

这不是打补丁，它本身就是一个极好的设计维度：

- **禁绝回响的关卡** → 让所有回响者恐惧，逼他们回到纯粹的人性博弈。
- **回响自由的关卡** → 超能力者的修罗场，观赏性极高。

**压制强度成为关卡的难度标签之一。**

## 12. 三道平衡闸门（针对"回响者带记忆"的风险）

| 闸门 | 机制 | 效果 |
|---|---|---|
| **闸门 1 · 特权即靶子** | 回响一旦使用即全场永久可见 | 特权变成高风险资产，比数值削弱更有效 |
| **闸门 2 · 价值锚定在"人"** | 记忆的价值是"谁背叛过我"，不是"这关怎么过" | 老玩家"更有故事"，而不是"更强" |
| **闸门 3 · 记忆残缺且失真** | 一轮回只能带走有限条，由玩家**主动挑选**（挑错自己负责），系统随机扭曲一小部分 | 无法完全信任自己的记忆，堵住"完美攻略" |

**非回响者不是全无所得**：他们有 **0 阶既视感**——模糊的直觉提示。
既是弱化版体验，也是"你是不是快觉醒了"的诱饵。

## 13. 可发现性：触发条件必须半透明

**全隐藏 = 玩家永远不知道自己在追什么，等于没有目标。**

> **设计要求：找回前史后，系统给出残缺的条件提示。给方向，不给答案。**

示例文案：

> *「你的回响似乎与『被众人指认』有关……
> 以及某种你尚未想起的克制。」*

| 玩家可见 | 玩家不可见 |
|---|---|
| 共鸣类条款（大意） | 精确的数值阈值 |
| 存在几条未知条款 | 禁忌类条款的具体内容（需自己领悟或靠记忆碎片解锁） |
| 当前渴望值的模糊刻度（"你的执念在加深"） | 精确进度条 |

禁忌类条款是**最后才揭示**的——很多玩家会在偶然满足它之后，才明白自己一直做对了什么。
这个"回过头才懂"的体验值得刻意保护。

## 14. 实装范围建议

32 种执念 × 5 阶的完整内容量非常大。建议分期：

| 里程碑 | 实装范围 |
|---|---|
| **M2** | 创伤 4 种（背叛/无力/剥夺/囚禁）× 应对 4 种 = **16 格**；阶 **0–1**；覆盖约 90% 玩家体验 |
| **M3** | 补齐 8 种创伤 = 32 格；开放阶 **2**；前史与记忆碎片系统完整化 |
| **M4** | 开放阶 **3**；回响分化与生肖晋升；阶 **4** 作为**手工设计的叙事内容**，不做程序化生成 |

**阶 3–4 永远保留手工设计。** 程序化生成的顶级能力必然崩坏平衡，也没有叙事重量。

## 15. 未决问题

1. **回响能否被剥夺？** 生肖是否有权在关卡内"没收"某人的回响作为惩罚？这会极大增加恐惧感，但也可能让玩家感到努力被抹杀。倾向：可以**临时压制**，不可永久剥夺。
2. **同一玩家能持有几条回响？** 目前设计允许分化出多条。上限设几条？多条回响会不会稀释"这是我的能力"的独特感？倾向：上限 3 条，且只有 1 条可在单局内装备。
3. **渴望值是否跨轮回累积？** 若跨轮回累积，长期玩家必然全员觉醒，稀有度目标失守；若不累积，则单轮回内的绝境密度要求过高。倾向：**部分累积 + 衰减**。
4. **前史的"解读"选择能否反悔？** 玩家可能在了解系统后后悔早期选择。提供一次性的"重述"机会（消耗大量记忆碎片）？还是不可逆以保证重量感？
5. **AI 编号是否拥有回响？** 若有，如何避免它们成为强度不可控的怪物；若无，真人玩家可以通过"谁没有回响"反推谁是 AI，破坏 [08](08-ugc-and-ai-host.md) 里"不告知谁是 AI"的设计。这是一个必须解决的冲突。
6. **共鸣判定的实现精度**：把"当前情境与前史节点匹配"变成可计算的谓词，需要一套情境特征提取。这套特征集的粒度直接决定了觉醒的手感是"命中注定"还是"莫名其妙"。这是 M2 最大的技术风险。
