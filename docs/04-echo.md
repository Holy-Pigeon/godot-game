# 04 · 回响系统

> 状态：核心规格 v0.3 ｜ 真源：回响定义、生命周期、生成与平衡

## 一句话定义

> **回响是前史伤口与当前情景共振后，暂时开放给玩家的一次规则例外权。**

它不是永久获得的技能，也不会自动执行效果。

## 不可违反的规则

1. **激活不等于发动。** 情景成立只将回响置为可用；发动永远由玩家在合法时机主动确认。
2. **只在当前轮回可用。** 新轮回开始时，激活状态、未用次数与未支付燃料全部清空，玩家重新成为普通编号。
3. **长期保留的是形状，不是力量。** 前史、执念、已形成的回响形状与公开档案可延续；可用回响不可延续。
4. **不发动没有成本。** 不烧记忆、不暴露、不改变判定、不消耗每关一次的发动次数。
5. **回响是逆转，不是滚雪球。** 渴望来自真实失去而非胜利；强度靠苛刻情景、燃料与暴露制衡。
6. **效果必须可判定。** 回响通过语义锚点接入模板，不能依赖主观感受或主持人解释。
7. **首次发现可以偶然，底层触发不能随机。** 系统始终按完整条件判定，但不会在第一次激活时直接公开条件清单；玩家通过跨轮回重复共振逐步还原触发路径。

“觉醒”仅是首次激活时的叙事演出名，不是永久能力状态。

## 触发路径的发现

玩家长期保留对回响形状的**理解进度**，但不保留激活状态或可用力量。每条回响按三次有效共振逐层揭示：

| 有效共振次数 | 玩家获得的信息 |
|---:|---|
| 第 1 次 · 觉醒 | 只知道刚才的经历唤醒了某种回响；呈现前史意象与效果预告，不显示条件清单 |
| 第 2 次 · 辨认 | 点明正在重演的前史结构，并揭示触发路径中的关键条件 |
| 第 3 次 · 掌握 | 公开完整触发路径、合法发动时机与代价；此后玩家可以主动布置局面争取再次激活 |

有效共振指完整激活条件真实成立；未满足条件的相似场面不累计。反馈可以保持叙事化，但玩家在掌握阶段必须能查看精确规则。跨轮回保留的是“我已经学会如何唤醒它”，不是已经唤醒的回响；新轮回仍须重新满足全部条件。

## 生命周期

| 状态 | 进入条件 | 玩家能做什么 | 退出条件 |
|---|---|---|---|
| 普通编号 | 新轮回开始 | 无回响发动入口 | 相关情景满足 |
| 本轮回已激活 | 激活条款全部满足 | 在合法时机发动，或始终放弃 | 新轮回开始 / 临时压制 |
| 已发动 | 主动确认并支付燃料 | 效果按模板结算 | 效果结束；本轮回激活状态仍可保留 |
| 已重置 | 新轮回开始 | 回到普通编号 | 再次满足激活条款 |

同一条回响每关最多发动一次；这是平台频次限制，不进入激活苛刻度计算。

## 回响形状

### 分类

回响形状 = **创伤 W × 应对 R × 前史细节**。W×R 给气质，前史细节决定具体效果；不再增加十二类等上层标签。

| 创伤 | 含义 |
|---|---|
| W1 背叛 | 信任被利用 |
| W2 无力 | 看得见却做不到 |
| W3 剥夺 | 本属于我的被夺走 |
| W4 欺瞒 | 活在别人编的故事里 |
| W5 弃绝 | 不被需要 |
| W6 罪咎 | 自己是加害者 |
| W7 囚禁 | 无法离开 |
| W8 湮没 | 无人记得 |

| 应对 | 含义 |
|---|---|
| R1 复仇 | 让对方也承受 |
| R2 补偿 | 把亏欠还回去 |
| R3 逃避 | 远离伤口 |
| R4 支配 | 把局面握在手里 |

前史必须是普通人能共情的伤口，名称必须是普通人说得出口的渴望，而不是机制名。例：`【真话】`、`【替】`、`【不是我】`。

### 形状成长

| 阶段 | 长期变化 |
|---|---|
| 初生 | 首次激活，确立低阶形状 |
| 加深 | 同类渴望积累；效果强化或条件收窄 |
| 分化 | 第二种主导创伤形成新形状或相邻分支 |
| 成型 | 同一执念方向形成稳定风格；最高可至四阶权柄 |

每个新轮回都要重新激活，即使形状已经成型。

**加深与分化的输入来自局后性格推断**：对局全量记录玩家的决策与发言，局后由小模型分析意图并产出带证据引用的执念倾向增量。推断只移动形状方向，不参与激活判定、不构成力量、对玩家不可见；初生阶段仍由首次激活确立。完整管线与隔离约束见 [13](13-record-and-inference.md)。

## 激活

### 条件

激活条件是若干可判定条款的 AND；共鸣类必选。

| 条款类别 | 用途 | 苛刻度 |
|---|---|---:|
| 共鸣类 | 当前情景重演前史结构；必须由模板情境谓词表达 | 必选，不计权 |
| 境况类 | 余命、人数、出局等客观绝境 | ★ |
| 关系类 | 信任、宿敌、守护、亏欠等已记录关系 | ★★ |
| 时机类 | 特定日、阶段或结算窗口 | ★★ |
| 代价类 | 已公开密令、已放弃生路等主动付出 | ★★★ |
| 禁忌类 | 本轮回始终未做某种行为 | ★★★★ |

```text
前史一句话 → 抽取伤口结构 → 用模板情境谓词写成共鸣条款
```

不得写“感到孤独”等不可判定条件。模板必须声明并实现情境谓词；缺少谓词时该关无法激活此回响，但不应让玩家为无效发动付费。

苛刻度初算：`Σ 条款权重 × 条款数量修正`；2/3/4/5+ 条款的修正系数依次为 1.0 / 1.15 / 1.3 / 1.5。数值仍待实测。

### 三重合取与渴望

一次激活要求同时满足：前史找回度、与前史共振的情境、渴望值阈值。三者时间常数不同——找回度是跨轮回累积的慢门，渴望值是局内事件驱动的快门，情境是瞬时门；完整判定式、碎片归属与渴望公式见 [14](14-fragments-and-yearning.md)。

渴望由真实努力后的失去产生：余命濒危、被信任者背叛、守护失败、密令受辱等。不能购买、不能由连胜获得、不能靠躺平送死刷取。反刷判定至少考察行动参与、资源投入、抵抗性与行为一致性。

新手首次濒死可强制播放 1 阶“觉醒”演出并激活一条弱微响；该回响仍只持续本轮回，使用仍由玩家选择。

## 强度、成本与暴露

| 阶 | 能触及的层 | 燃料起点 | 暴露 |
|---|---|---:|---|
| 0 既视感 | 纯提示 | 0 | 无 |
| 1 微响 | 自己的信息层 | 1 条记忆 | 可隐蔽 |
| 2 回响 | 一次判定结果 | 3 条记忆 | 全场可见并永久登记 |
| 3 共鸣 | 本关一条规则 | 5 条记忆 | 全场可见，惊动世界权威 |
| 4 权柄 | 对他人施加规则 | 叙事级 | 系统/官方事件 |

发动前不可见；发动越强，燃料、暴露和激活难度越高。压制可封锁动词族、提高发动成本或设置绝缘区；被压制的发动尝试依然可被全场看见。

## 语义接口

完整规格：

```text
玩家宣言 + 前史 + 执念格 + 激活条件 + 语义锚点（动词·对象·层级）
```

语义锚点由模板实现，而非逐条手配：例如 `转嫁·一次针对我的判定后果·L2` 在最后提案、契约、轮盘中分别落成对应的代价转移。L1/L2 锚点必须被所有上架模板实现；L3 未实现时可降为同系 L2 并按 L2 计费；完全无映射的模板不得上架。

### 已冻结的 L1/L2 锚点集

锚点是全体上架模板的强制义务，因此必须小而通用。当前冻结为四条：

| 锚点 | 含义 |
|---|---|
| `揭示·一次已锁定的选择·L1` | 读取某编号已锁定但尚未公开的一次选择 |
| `重播·我的一次公开表态·L1` | 把我此前的一次公开表态重新置入当前公共区 |
| `转嫁·一次针对我的判定后果·L2` | 把他人承担的一份代价移到我身上 |
| `转嫁·我的一次判定后果到指定编号·L2` | 把我承担的一份代价移到指定编号身上 |

新增锚点是平台级决策：它会给**所有**已上架模板追加实现义务，因此不随单条回响的需要扩张。回响的差异应通过激活条件与前史表达，而不是通过增加锚点。

### 情境谓词词表

激活条件只能引用平台维护的**封闭谓词词表**，不得使用模板专属词汇——否则该回响无法跨模板存活。模板通过绑定表把抽象谓词映射到自己的事件；未绑定的谓词按上文处理：该关无法激活对应回响，且不产生任何消耗。

与锚点不同，谓词绑定是**可选且逐条**的，因此扩充词表不会破坏已有模板，只会让新回响在未绑定的关卡里不可激活。词表与绑定的工程形态见 [15](15-t11-technical-design.md)。

模板是回响的两侧接口：

| 接口 | 模板义务 |
|---|---|
| 输出：语义锚点 | 实现封闭效果动词清单 |
| 输入：情境谓词 | 声明可客观判定的激活材料 |

## 与其他系统的边界

| 系统 | 边界 |
|---|---|
| 记忆 | 发动只能烧已拼回的碎片；已拼回部分永久保留，不构成可用力量，见 [14](14-fragments-and-yearning.md) |
| 密令 | 密令失败可产出渴望；回响可以改变密令相关判定 |
| 关卡 | 提供效果映射、情境谓词与压制；不直接触发玩家发动 |
| 主持人 | 与回响阶数无关；权柄不是主持资格 |
| AI 编号 | 是否拥有 0–1 阶形状仍待定，见 [09](09-open-questions.md) |
| 记录与推断 | 推断只影响形状漂移；条件与效果的可判定性不受影响，见 [13](13-record-and-inference.md) |

## 未决项

- 同一玩家一轮回最多可激活多少条形状（当前倾向 3）。
- 渴望跨轮回累积的比例与衰减。
- 共鸣谓词的标准粒度。
- 记忆消耗上限、回响剥夺与前史重述。
