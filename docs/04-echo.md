# 04 · 回响系统

> 状态：草案 v0.2 ｜ 关联：[00 高概念](00-overview.md)、[01 核心循环](01-core-loop.md)、[02 余命与记忆](02-economy-lifespan-memory.md)、[03 密令](03-mandate.md)、[05 无阵营与主持人](05-authority-and-ascension.md)、[07 关卡设计系统](07-level-design.md)、[11 MVP 回响与前史](11-mvp-echoes.md)
>
> **v0.2 变更**：回响不会在条件成立时自动发动。特定情景只负责**激活**回响，
> 激活后由玩家主动选择是否**发动**；激活只持续当前轮回，下轮回强制重置。

**本文档是整个项目最核心的系统设计。** 它同时承担：超能力、长期目标、叙事驱动、翻盘机制、以及与 UGC 分类体系的接口。

## 1. 一句话定义

> **回响 = 当下的绝境，与你过去的伤口，产生了共振。**

它不是"你获得了能力"，而是"**你的过去回答了你**"。
这份回答只会让能力在当下变得可用，**不会替玩家做决定**。

这个定义不是文学修辞，它是三条硬性设计约束的来源：

| 定义中的词 | 导出的机制约束 |
|---|---|
| **绝境** | 只能在濒临失去时激活 → 天然是**翻盘机制**，不是滚雪球机制 |
| **过去的伤口** | 必须绑定**前史**，每人的回响独一无二 → 不可交易、不可购买、不可攻略 |
| **共振** | 需要"情境 × 前史"对上频率 → 天然**稀有**，但人人有机会 |

---

### 1.1 回响的四段生命周期

| 阶段 | 发生什么 | 是否由玩家决定 |
|---|---|---|
| **普通编号** | 每次新轮回开始时都没有可用回响；前史与执念只决定你可能激活出什么 | 否 |
| **激活** | 本轮回内出现与前史共振的特定情景，回响进入可用状态，持续到本轮回结束 | 否，只是客观情景被识别 |
| **发动 / 使用** | 激活后，玩家在合法时机主动确认，支付燃料并让效果生效 | **是** |
| **重置** | 进入下一轮回时，已激活回响强制失效，玩家重新成为普通编号 | 否 |

> **硬规则：激活 ≠ 发动。**
> 回响一旦激活，**使用权持续到本轮回结束**，玩家可以一直不用，也可以在之后某个合法时机主动发动。
> **不发动就不烧记忆、不触发使用暴露、不消耗每关使用次数，也不改变任何判定。**
> **回响本身不跨轮回保留。**进入下一轮回后，无论上一轮回是否发动过，都必须重新遇到对应情景才能再次激活。

> **“觉醒”只是第一次激活回响时的叙事演出名称，不是一个永久能力状态。**

## 2. 三条不可违背的铁律

### 铁律 1：回响是逆转系统，不是成长系统

> **渴望只从"失去"中产生，绝不从"胜利"中产生。**

顺风的玩家永远激活不了回响，被逼到墙角的人才会在当前轮回获得使用它的可能。这条写死在数值里，它保证了：
老玩家不会因为玩得久就永久更强，他的过去只会决定**什么样的苦能让他在这一轮回里不再普通**。

### 铁律 2：回响是"规则例外权"，不是技能

如果回响是"我放火球 / 我加移速"，整个游戏会退化成动作游戏，
而所有 UGC 关卡（记账、投票、缔约、搜证）会**全部崩溃**——它们是规则博弈，不是操作博弈。

> **回响 = 玩家私有的一张规则修正件，可以对当前关卡的规则开一个例外。**

**设计红利**：回响与关卡的[规则修正件](07-level-design.md)是**同一种东西的两个来源**——
一个由关卡作者挂上去，一个从玩家的前史里长出来。
因此玩家天然看得懂自己的回响在做什么，也天然知道它能被关卡的压制挡住。

### 铁律 3：跨轮回只传递"信息与关系"，绝不传递"力量"

进入下一轮回时，回响的激活状态与未用次数全部清空，玩家再次成为普通编号。
若记忆最终被允许跨轮回保留（具体方案仍待定），它的价值也必须**锚定在"人"，而不是"题"**：

> 上一轮，7 号在最后一刻把你推了出去。
> 而这一轮，7 号不记得这件事。

这个不对称提供的是**动机、猜疑与复仇**，不是数值优势。
（关卡是 UGC 无限产出的，记住某关解法本来也几乎没用。）

## 3. 前提：前史不是选的，是"被还给你的"

如果让玩家在建号时挑背景，所有人都会挑最强的那个，**整套分类系统当场作废**。

正确做法：

> **所有编号入场时都是失忆的。前史通过记忆碎片一片片被找回，
> 而系统根据你在前几个轮回里的实际行为，决定还给你哪一段过去。**

| 你的行为 | 系统还给你的过去 |
|---|---|
| 反复背叛他人 | "你曾被最亲的人背叛" |
| 屡次为救人而死 | "你曾眼睁睁看着某人死去" |
| 从不主动出击，只求苟活 | "你曾长期被困在一个出不去的地方" |
| 疯狂囤积余命 | "你曾拥有的一切被人夺走" |

每次拿到碎片时，给玩家 **2–3 种解读**去选：

> *「那天我恨他」 / 「那天我原谅了他」 / 「那天我什么都没想」*

**行为决定题目，玩家决定答案。** 既防了 min-max，又保留了玩家的作者权。

于是玩家路径是：

```
失忆的编号 → 行为被观测 → 记忆碎片(前史) → 执念成型 → 遇到共振情境 → 本轮回激活回响
```

> 真相轴的第一层不是世界的真相，**是你自己的真相**。而找回自己，正是回响能在共振情境中激活的前置条件。
> 三条长期轴在这里合流。

## 4. 分类表一 · 经历（决定回响"是什么"）

经历不是一个标签，是**两层的乘法**。

### 4.1 创伤类型（八种 · 你身上发生了什么）

| 代号 | 创伤 | 内核 | 典型前史片段 |
|---|---|---|---|
| W1 | **背叛** | 信任被利用 | 每次出事，父母最后都说"要不是因为你" |
| W2 | **无力** | 看得见，做不到 | 隔着玻璃看着，喊了也没人听见 |
| W3 | **剥夺** | 本属于你的被夺走 | 他做的东西，署了别人的名字 |
| W4 | **欺瞒** | 你活在别人编的故事里 | 家里的事从来没人告诉他 |
| W5 | **弃绝** | 不被需要 | 他做什么都没人看，考好考砸都一样 |
| W6 | **罪咎** | 你才是加害者 | 弟弟替他顶了罪，弟弟的人生从此转了个弯 |
| W7 | **囚禁** | 无法离开 | 那间屋子他住了十九年，门一直是开着的 |
| W8 | **湮没** | 无人记得你 | 同学会上没人记得他坐在哪一排 |

> **写作口径（重要）：前史是平凡人生的因，不是奇观。**
>
> 该写"小时候家里所有事都瞒着他"，不该写"他曾亲手毁掉一座城"。理由有三条：
> **共情门槛**（玩家要说"我懂"，不是"设定挺酷"）、
> **可翻译性**（平凡的伤才有清晰结构，结构才能翻译成客观谓词，奇观只有情节）、
> **可量产**（普通人的伤是有限几十种，奇观每条都要单独编剧）。
>
> 终焉之地本身已经足够离奇了。**编号们的过去必须足够普通，这个对比才成立。**
> 示例见 [11 · MVP 四个回响与前史](11-mvp-echoes.md)。

### 4.1.1 回响锚在「渴望」上，不锚在机制上

回响的名字与定位，必须是**一个大多数人都有过的底层渴望**，
被终焉之地兑现成了畸形的形状——而不是一句机制描述。

| ❌ 机制描述 | ✅ 渴望 |
|---|---|
| 读取他人的隐藏行动 | **【真话】**——我想听一句真话 |
| 隐藏自己的行动记录 | **【余音】**——我说的话，能不能有人听见 |
| 把判定后果转到自己身上 | **【替】**——我欠着一个人，我想还 |
| 把判定后果转到他人身上 | **【不是我】**——别再算在我头上 |

**命名口径**：名字必须是**普通人说得出口的话**，不是术语，不是招式名。
一个合格的回响名同时做到三件事：**一眼看出它在干什么** / **念出来有分量** / **名字本身就是那个渴望**。

> 判据：把名字念给一个从没玩过这游戏的人听，他应该也懂那是什么感觉。

### 4.2 应对方式（四种 · 你当时怎么做的）

| 代号 | 应对 | 内核 |
|---|---|---|
| R1 | **复仇** | 我要让他也尝一次 |
| R2 | **补偿** | 我要把它还回去 |
| R3 | **逃避** | 我不要再靠近 |
| R4 | **支配** | 只要一切都在我手里，就不会重演 |

### 4.3 执念矩阵（8 × 4 = 32 格）

**执念 = 创伤 × 应对。这 32 格就是回响的全部分类。**

> **不设更高层的归类体系。**
> 早期版本把 32 格再映射到一套十二类的符号系统上，已废弃：
> 那一层既不影响判定，也不影响体验，只是给每条回响多贴了一个标签。
> **一条回响标注 `W6 × R2` 就够了**，它的形状由前史细节决定，不由标签决定。
>
> 更高层的分类（如果将来需要）留待想清楚再补，见 [09 Q-C9](09-open-questions.md)。

矩阵的作用只有一个：**给"这个人会长出什么样的回响"一个方向**。

| | R1 复仇<br>我要让他也尝一次 | R2 补偿<br>我要把它还回去 | R3 逃避<br>我不要再靠近 | R4 支配<br>都在我手里就不会重演 |
|---|---|---|---|---|
| **W1 背叛** | 以其人之道 | 替他还清 | 再不交心 | 让承诺无法违背 |
| **W2 无力** | 这次我先动手 | 替人承担 | 不再去看 | 我要更早知道 |
| **W3 剥夺** | 拿回来，连本带利 | 换一个等价的 | 不再拥有 | 一切都要过我的手 |
| **W4 欺瞒** | 用漏洞戳穿它 | 让规则说真话 | 从暗处自己取 | 那我也编一个 |
| **W5 弃绝** | 让他们不得不看我 | 我先对别人好 | 提前离开 | 让他们离不开我 |
| **W6 罪咎** | 恨那个让我活下来的局面 | 我来背，别让他背 | 不再靠近任何人 | 从头改掉这条规矩 |
| **W7 囚禁** | 砸开它 | 换一个人进去 | 找到门缝 | 那我来定门在哪 |
| **W8 湮没** | 抢一个位置 | 把位置让出去，好歹被记一笔 | 那就彻底消失 | 让世界不得不记住 |

**同一格的两个人，回响长得完全不一样**——格子给方向，[前史细节](11-mvp-echoes.md)给形状。

### 4.4 执念气质示例

| 执念 | 回响气质 | 对应样板 |
|---|---|---|
| W4 欺瞒 × R3 逃避 | 不当面要，从暗处自己取 | [【真话】](11-mvp-echoes.md) |
| W8 湮没 × R4 支配 | 我要让世界不得不记住 | [【余音】](11-mvp-echoes.md) |
| W6 罪咎 × R2 补偿 | 我来背，别让他背 | [【替】](11-mvp-echoes.md) |

| W3 剥夺 × R1 复仇 | 偷回来，连本带利 | — |
| W2 无力 × R4 支配 | 我要更早知道，我要重来一次 | — |
| W7 囚禁 × R3 逃避 | 从任何规则里溜走 | — |

## 5. 分类表二 · 激活条件（决定回响"多强"）

> **条件越苛刻 → 回响越强。** 这是玩家提出的核心要求，也是本系统的平衡阀。

为了能被无歧义地判定，激活条件必须是**若干条款的合取（AND）**，每条来自一个类别。
条件全部成立时，系统只将回响标记为**本轮回已激活**，不自动执行效果；该状态持续到本轮回结束。

### 5.1 激活条款类别

| 类别 | 说明 | 示例条款 | 苛刻权重 |
|---|---|---|---|
| **共鸣类** | 当前情境与前史节点匹配 | 「加害你的人，正处于你前史中那个人的位置」 | **必选 · 不计权** |
| **境况类** | 客观绝境 | 余命 < 10%／全场只剩你一人／你已进入出局判定 | ★ |
| **关系类** | 人际结构 | 加害者是你本轮回信任过的人／你的宿敌在场／你的守护对象已死 | ★★ |
| **时机类** | 窗口极窄 | 仅在死亡判定的最后一次结算／一轮回仅一次／仅在第 N 日 | ★★ |
| **代价类** | 主动付出 | 必须先主动放弃一条生路／已烧掉 ≥3 条记忆／自愿公开自己的密令 | ★★★ |
| **禁忌类** | 长期行为约束 | 本轮回你从未说谎／从未导致任何人出局／从未使用过任何道具 | ★★★★ |

**共鸣类是每条激活条件的必选项**，它锚定了"回响必须与角色过去的经历有关"这条要求。

### 5.1.1 共鸣类条款只能写在「情境谓词」之上

共鸣类是最容易写坏的一类——一不小心就会写成"当他感到孤独时"这种**无法判定**的句子。

> **规定：共鸣类条款必须是对「情境谓词」的判定，谓词取自模板声明的封闭清单。**

情境谓词是[语义锚点](#75-语义锚点一个回响如何在所有关卡里都成立)的镜像，两者构成回响的一对接口：

| 接口 | 方向 | 模板的义务 |
|---|---|---|
| **语义锚点** | 回响的**输出**——效果如何落到本关 | 实现 [07 §3.2](07-level-design.md) 的效果清单 |
| **情境谓词** | 回响的**输入**——激活条件拿什么来判定 | 声明并实现 [07 §3.2.2](07-level-design.md) 的谓词清单 |

**一个模板两边都实现了，才算完整。**

由此得到一条方法论上的先后顺序（[D-16](README.md)）：

> **回响先行，关卡后行。**
> 先有回响，才知道关卡需要暴露哪些谓词；反过来先做关卡，就只能在事后削足适履。

### 5.1.2 从前史到条款：三步翻译

激活条件不是用来替玩家按下技能的开关，而是**把一段私人记忆重写成当前局面的客观谓词**；
它只决定“这一轮回里，你还是不是普通人”，不决定你何时发动。

```
① 前史（一句人话）      「小时候家里所有事都瞒着他」
        ↓ 抽出结构
② 伤口的结构            「当面一套、背后一套，而我被蒙在鼓里」
        ↓ 用情境谓词表达
③ 共鸣类条款            表态矛盾(x, 针对我)
```

**第 ② 步是全部的功夫所在。** 跳过它直接从前史写条款，写出来的一定是不可判定的文学句子。
完整走查见 [11 · MVP 四个回响与前史](11-mvp-echoes.md)。

### 5.2 为什么禁忌类最强

禁忌类约束的不是一个瞬间，而是你**几十小时的行为方式**。

想要顶级回响，你必须**活成某一种人**——这是本系统最珍贵的一条：
它把"数值强度"换算成了"角色扮演的自律"，而且**完全无法用付费或肝度绕过**。

> 一个只玩了 15 个轮回、但从头到尾没撒过一次谎的玩家，
> 可以拥有比玩了 200 轮回的老油条更强的回响。

### 5.3 苛刻度计算

```
苛刻度 = Σ(条款权重) × 条款数量修正
条款数量修正：2 条 ×1.0 ｜ 3 条 ×1.15 ｜ 4 条 ×1.3 ｜ 5 条及以上 ×1.5
```

（初值待实测标定，见 [02](02-economy-lifespan-memory.md) 的参数表约定。）

## 6. 分类表三 · 强度（用"能碰到规则的哪一层"分级）

强度**绝不能用数值定义**（"伤害+50%"之类），必须用**权限层级**定义，才能与关卡规则的层级对齐。

| 阶 | 名称 | 能触及的层 | 举例 | 苛刻度门槛 |
|---|---|---|---|---|
| **0** | **既视感** | 无（纯感受） | 模糊直觉提示："你对这个房间有种说不出的熟悉" | 人人可得 |
| **1** | **微响** | **你自己的信息层** | 隐藏你的一次行动记录／偷看一条隐藏信息／记住一个本该被清除的名字 | ★–★★ |
| **2** | **回响** | **一次判定的结果** | 豁免一次出局／把损失转嫁一半／让某句已说出的话全场重播 | ★★★–★★★★ |
| **3** | **共鸣** | **本关的一条规则** | 3 回合内禁止任何人投票／让弃权视为同意／全场发言进入不可篡改记录 | ★★★★★+ |
| **4** | **权柄** | **对他人施加规则** | 主持人级。你开始成为"规则"本身 | 叙事级事件 |

### 6.1 四条自平衡的硬约束

| 约束 | 机制 | 效果 |
|---|---|---|
| **燃料** | 阶数越高，单次发动烧掉的**记忆碎片**越多（1 阶 1 条 → 3 阶 5 条以上） | 强者被迫遗忘自己是谁。**设定内最漂亮的诅咒** |
| **暴露** | 0–1 阶可隐蔽；**2 阶起全场可见并永久登记**；**3 阶起惊动权威**，终焉之地会派人来"看看你" | 力量自动招来针对，形成天花板 |
| **窄化** | 越强的回响，激活条件越窄，一个轮回可能一次都对不上 | **它是保命底牌，不是常规手段** |
| **频次** | **同一条回响，每关最多发动一次**。所有阶通用，1 阶也不例外 | 见下 |

#### 关于「频次」（[D-19](README.md)）

低阶回响是可隐蔽的，也就是**没有社交代价**——它唯一的成本只剩 1 条记忆碎片。
若允许一关之内反复发动，1 阶回响会从"底牌"退化成"常规操作"，
而整套回响设计建立在"**它是保命底牌，不是常规手段**"之上。

> **重要：频次是平台级约束，不是激活条款。**
> 它**不进入[苛刻度计算](#53-苛刻度计算)**——否则给 1 阶补一条"每关一次"的时机类条款（★★），
> 苛刻度会被推到 2 阶，把整套换算搞坏。
>
> 一句话：**苛刻度决定回响要在多窄的情景中才会激活，频次决定你一关能主动发动几次。两者互不干涉。**

### 6.2 暴露机制：什么时候亮底牌

这是回响在**局内玩法**上最大的张力来源。

> 回响**未使用时不可见，一旦使用则全场永久可见**。

于是每个回响者都要面对同一个抉择：

- **亮早了** → 你成为全场公敌（"他有回响，先做掉他"）。
- **亮晚了** → 你可能已经死了。

这条把"特权"变成了**高风险资产**，比任何数值削弱都管用。
它也让"回响者"这个身份成为社交博弈的筹码：**你可以谎称自己有回响**——没人能验证，直到你被迫亮出来为止。

## 7. 合成公式：三张表如何变成一个回响

```
回响 = 渴望（前史决定，也是它的名字）
     + 执念格 W×R（决定气质方向）
     + 阶（激活苛刻度决定）
     + 语义锚点（前史的细节决定具体效果）
```

### 7.1 完整实例走查

> **编号 043**，前史逐步找回：
> 他曾是某个团队的记录员，**同伴集体串供把事故推给他**（创伤 W1 背叛）。
> 他没有反击，只是**把所有证据都留了下来**（应对 R4 支配）。
>
> → 执念格 = **W1 背叛 × R4 支配**，方向是"让承诺无法违背"。
> **但他的回响不是契约类的。** 前史细节（"留下证据"而非"缔结契约"）
> 把他推向了完全不同的形状——**记录**。
> **这就是"前史细节决定具体效果"的含义**——格子给方向，细节给形状。
>
> **系统生成的激活条件：**
>
> | 类别 | 条款 | 权重 |
> |---|---|---|
> | 共鸣类 | 在场有人对你做出**公开的集体指认** | — |
> | 关系类 | 指认者中至少一人本轮回与你结过盟 | ★★ |
> | 时机类 | 在最终结算的最后一次发言 | ★★ |
> | 禁忌类 | **本轮回你从未主动指认过任何人** | ★★★★ |
>
> 苛刻度 = (2+2+4) × 1.15 ≈ **9.2 ★** → **3 阶 · 共鸣**
>
> **回响【留证】**：本关剩余全部回合，**所有人的发言都进入不可篡改的公开记录，且无人可以弃权。**

请注意这个能力：它**没有任何数值**，它只是把一条规则改了。
但在一场投票放逐关卡里，它足以**毁灭整个串供联盟**。
而且它只属于 043，因为只有他有这段过去。

## 7.5 语义锚点：一个回响如何在所有关卡里都成立

### 7.5.1 问题

回响的内核是**一句抽象的宣言**——"规则对我无效""代价该由别人来扛""我要看见本不该看见的"。
但关卡是具体的：暗账里有"夺"，投票放逐里有"投票"，契约谈判里有"签"。

> **同一句宣言，在不同关卡里必须落成不同的动作，但必须仍然能被这一句话解释。**

这是回响系统唯一的工程级难题。三条路：

| 做法 | 结果 |
|---|---|
| (a) **逐关手配**：每个回响 × 每个关卡各写一条具体效果 | 表达力最强。但 N×M 爆炸——作者做一张新关卡，要为全服每一条回响写适配。**UGC 生态下必死** |
| (b) **纯抽象**：回响只声明"我要对判定层做一次豁免"，交给模板自由解释 | 零配置，但味道全丢。「破万法」和「替人受过」打出来长得一模一样 |
| (c) **语义锚点** ✅ **采用（D-13）** | 回响声明的不是效果，是**语义**；模板负责把语义映射到自己的流程。**N×M 降为 N+M** |

### 7.5.2 回响的完整规格

```
回响 = 宣言（一句话，玩家看到的）
     + 语义锚点（动词 + 作用对象 + 层级，系统看到的）
     + 激活条件（共鸣类必选 + 其余若干）
     + 前史（它为什么长这样）
```

**语义锚点 = 动词 + 作用对象 + 层级**，三者都取自[封闭清单](07-level-design.md#32-效果四层分级)：

| 成分 | 取值来源 | 例 |
|---|---|---|
| 动词 | [07 §3.2](07-level-design.md) 的效果清单（揭示 / 隐藏 / 豁免 / 转嫁 / 改判 / 禁止行动 / 变更胜负条件……） | `豁免` |
| 作用对象 | 判定类型 + 归属（针对我的 / 针对指定编号的 / 全场的） | `一次针对我的出局判定` |
| 层级 | L1 信息 / L2 判定 / L3 规则，与回响阶数对齐 | `L2` |

> 关卡作者**永远不需要认识任何一条回响**。他只要用模板，模板已经实现了语义接口。
> 回响作者（官方 / 系统生成）也**永远不需要认识任何一张关卡**。

### 7.5.3 同一个锚点在不同模板里的落法

以锚点 `豁免 · 一次针对我的出局判定 · L2` 为例：

| 模板 | 这一关里它长什么样 |
|---|---|
| T-11 暗账 | 平账时你是账面最少的那个，**但你没有被销账** |
| T-02 投票放逐 | 你被票出去了，**但你还在场上**，且全场都看到了这件事 |
| T-10 契约谈判 | 你违约了，**但违约的自动扣除没有发生**——全场都看见了这件事 |
| T-06 俄罗斯轮盘 | 那一发是实弹，**但你没有倒下** |

四种表现完全不同，玩家的体验却是同一句话：**"我该死，但我没死。"**

### 7.5.4 降级规则：不允许"我的回响这一关什么都没发生"

这是 (c) 方案必须补上的一块，否则玩家会遇到最伤人的体验——**烧了记忆，什么也没发生**。

| 层级 | 规定 |
|---|---|
| **L1 信息 / L2 判定** | **模板必须实现全部语义动词才允许上架**。这是模板的准入门槛，不是可选项 |
| **L3 规则** | 允许模板不实现某些动词。未实现时，该回响在这一关**自动降级为同系的 L2 近似效果**，并按 L2 的燃料计费 |
| **完全无法映射** | 不允许存在。若审核中发现某锚点在某模板下无解，判定为**该模板不合格**，而不是该回响不合格 |

> **降级不是压制。** 压制是作者主动封锁回响（不公示，见 [D-11](README.md)）；
> 降级是模板能力不足，属于平台缺陷，必须在上架审核阶段就消灭掉，不能留到玩家面前。

### 7.5.5 三阶样板：【破万法】

> 用于内容制作与验证的**标准样板**。3 阶覆盖率目标仅 0.5%（见 §9.1），
> **它不代表新玩家可及的能力**，而是用来检验"语义锚点能不能承载规则层"。

| 项 | 内容 |
|---|---|
| **宣言** | **"你们的规矩，管不到我。"** |
| **执念格** | **W4 欺瞒 × R1 复仇** —— 用漏洞戳穿它 |
| **语义锚点** | `禁用 · 一条正在对我生效的关卡规则 · L3` |
| **阶** | 3 · 共鸣 |
| **燃料** | 5 条记忆碎片起 |
| **暴露** | 3 阶，全场可见 + 永久登记 + **惊动终焉之地的管理者** |

在不同模板里的落法：

| 模板 | 【破万法】发动后 |
|---|---|
| T-02 投票放逐 | 指定一条正在约束你的规则（如"弃权视为同意"）**对你失效至本关结束** |
| T-11 暗账 | 指定一条账目规则（如"匿必须扣 1 日"或"指认不实自罚"）对你失效 |
| T-10 契约谈判 | **你身上的一条契约条款失效**——但契约的其余部分仍然成立，且全场看得见你毁了哪一条 |

注意它**不是"我赢"**，而是"**我不受这一条约束**"。它拆掉的是一根柱子，不是整栋楼。
这也是判断一个 L3 回响是否设计合格的标准：**它必须仍然把你留在这场博弈里。**

## 8. 渴望值（执念的积累）

回响形状不是瞬间长成的，它需要"渴望"反复冲刷同一个伤口；
首次激活时播放的“觉醒”演出不改变这条长期积累规则。

### 8.1 渴望值的产出源

| 事件 | 说明 | 归属创伤 |
|---|---|---|
| 余命跌破生死线 | 最基础的绝境 | 通用 |
| 被你**本局信任过**的人背叛 | 需要"信任"是可记录的社交状态 | W1 背叛 |
| 眼看着密令的守护对象死去 | [密令系统](03-mandate.md)在这里第二次发挥作用 | W2 无力 |
| 被同一个编号淘汰第二次 | **宿敌机制**，执念的经典来源 | W1 / W3 |
| 你的密令被公开处刑 | 社死也是一种绝境 | W8 湮没 |
| 你的提议被全场无视 | 弱信号，缓慢积累 | W5 弃绝 |
| 你导致了盟友出局 | 无论是否有意 | W6 罪咎 |
| 连续 N 局无法离开出局线 | 长期压抑 | W7 囚禁 |

### 8.2 三条硬规则

1. **不能用余命购买。**
2. **不能靠连胜积累。** 胜利不产生渴望。
3. **躺平送死不产生渴望。** 见下节。

### 8.3 反"自残刷执念"

玩家一定会尝试故意送死来刷渴望值。

> **对策：渴望值只在"你真实付出了努力后仍然失败"时结算。**

可评估的维度包括：行动质量、是否有效抵抗、是否使用了可用资源、发言参与度、是否主动放弃优势位。
**放弃的人不会有渴望**——这在设定上也完全成立，一个自我放逐的人是不会燃烧的。

具体检测维度（初版）：

| 维度 | 判定 |
|---|---|
| 行动参与度 | 本局有效行动数 / 可行动次数 |
| 资源投入 | 是否押注了有意义比例的余命 |
| 抵抗性 | 出局前是否有过反制行为 |
| 一致性 | 行为是否与其公开承诺一致 |

四项均低于阈值 → 本局渴望值产出 **归零**，并记录"消极"标记。

## 9. 激活的三重合取（稀有性的来源）

每次轮回中，回响都需要三个条件**同时**成立才会激活，这就是"稀有但人人有机会"的机制解：

```
① 前史找回度达标   （真相轴进度，需要记忆碎片）
        ∧
② 情境与前史共振   （运气 + 主动创造）
        ∧
③ 渴望值突破阈值   （必须真的经历过绝境）
```

三重合取意味着：

- **不能靠肝**（②需要机遇，③需要真实失败）
- **不能靠钱**（①②③都不可购买）
- **但对所有人开放**（三条路径都没有门槛，只有时间与选择）
- **不是永久强者**（本轮回激活也会在下一轮回开始时清空）

### 9.1 稀有度目标（起始值，待实测调整）

| 阶 | 目标覆盖率（单次轮回内成功激活） | 首次形成该阶回响形状的预期时间 |
|---|---|---|
| 0 · 既视感 | **100%** | 第 1 轮回 |
| 1 · 微响 | **约 35%** | 第 3–6 轮回 |
| 2 · 回响 | **约 8%** | 第 10–20 轮回 |
| 3 · 共鸣 | **约 0.5%** | 数十轮回 + 极端自律 |
| 4 · 权柄 | **全服个位数** | 叙事事件，需系统/官方认可 |

### 9.2 新人的第一次激活

**新手第一次濒死，正是最容易激活回响的时刻。**

设计要求：玩家的**首次濒死强制播放一次 1 阶“觉醒”演出，并为本轮回激活一条极弱的微响**。
演出只告诉玩家“你这一轮回不再普通”，是否发动仍由玩家自主决定；下一轮回开始时依然清空。

> 这把新人最挫败的瞬间，直接改造成了最高光的入坑时刻。
> 见 [01 首次会话设计](01-core-loop.md#6-首次会话新玩家的前-60-分钟)。

## 10. 回响形状的进化与分化

跨轮回生长的是由前史与执念决定的**回响形状**，不是已激活的力量状态。
玩家会越来越清楚“自己在什么情景下会变成什么”，但每个新轮回仍然从普通人开始。

| 阶段 | 成形条件 | 变化 |
|---|---|---|
| **初生** | 首次激活（播放“觉醒”演出） | 确立 1 条低阶回响形状，激活条件宽松、效果微弱 |
| **加深** | 同一执念被反复冲刷（同类渴望累积） | 效果强化，或激活条件收窄换取阶数提升 |
| **分化** | 出现第二种主导创伤 | 长出第二条回响，或原回响转向相邻的执念格 |
| **成型** | 同一执念方向上多条回响成体系 | 稳定的个人风格；四阶·权柄是这条路的顶点 |

> **以上成长只保留“形状”：当前轮回的激活状态、可用次数与未支付的燃料不得带入下一轮回。**

**玩家可以主动选择方向**：在"扩宽激活条件、降低强度"和"收窄条件、提升阶数"之间做取舍。
这是权柄轴上唯一的显式 Build 选择，其余全部由行为决定。

> **回响与"能不能造关"完全无关。** 造关与主持是所有玩家的通用能力，只花余命，
> 不看阶数（见 [05 §5.1](05-authority-and-ascension.md)）。
> 回响影响的是**你会做出什么风格的关卡**，不是**你有没有资格做**。

## 11. 与其他系统的接口

| 系统 | 接口 |
|---|---|
| [记忆碎片](02-economy-lifespan-memory.md) | **回响的燃料**。发动即烧记忆 → 与真相轴直接抢资源 |
| [密令](03-mandate.md) | 密令失败（尤其守护型）是渴望值的主要来源；回响可以扭转密令判定 |
| [无阵营与主持人](05-authority-and-ascension.md) | 回响阶数与主持人身份**无关**；四阶·权柄只是回响的最高阶 |
| [关卡设计](07-level-design.md) | 回响与规则修正件**共用效果类型，不共用启动方式**：修正件由规则触发，回响由情景激活后供玩家主动发动 |
| [关卡 · 压制](07-level-design.md) | 关卡可封锁某类回响 / 让发动代价翻倍 / 设为绝缘区 |
| [死亡与轮回](06-death-and-recurrence.md) | 记忆怎样跨轮回仍待定；**回响激活状态不跨轮回**已锁定，新轮回开始即重置为普通编号 |

### 11.1 关于压制（UGC 平衡阀）

回响会让 **UGC 关卡的平衡不可控**——作者不知道进来的这些人带着什么例外权。

> **解法：给关卡作者一个「压制」维度。**
> 关卡可声明"本关封锁交换类回响"／"本关内回响发动代价翻倍"／"本关是回响绝缘区"。

这不是打补丁，它本身就是一个极好的设计维度：

- **禁绝回响的关卡** → 让所有回响者恐惧，逼他们回到纯粹的人性博弈。
- **回响自由的关卡** → 超能力者的修罗场，观赏性极高。

**压制强度成为关卡的难度维度之一——但它是一条隐藏难度。**
压制不在关卡入口公示（见 [D-11](README.md)），玩家只能靠亲身进场、打听或买情报得知。
对回响者来说，"这一关到底能不能用"本身就是一次押注。

## 12. 四道平衡闸门（针对"老玩家不能变成常驻强者"的风险）

| 闸门 | 机制 | 效果 |
|---|---|---|
| **闸门 1 · 强度清零** | 已激活的回响与未用次数在新轮回开始时全部清空 | 没有人能带着上轮回的例外权进入新局，老玩家更有故事而不是更强 |
| **闸门 2 · 特权即靶子** | 回响一旦使用即写入公开档案 | 当轮回的特权变成高风险资产，比数值削弱更有效 |
| **闸门 3 · 价值锚定在"人"** | 记忆的价值是"谁背叛过我"，不是"这关怎么过" | 老玩家"更有故事"，而不是"更强" |
| **闸门 4 · 记忆残缺且失真** | 一轮回只能带走有限条，由玩家**主动挑选**（挑错自己负责），系统随机扭曲一小部分 | 无法完全信任自己的记忆，堵住"完美攻略" |

**未激活者不是全无所得**：他们有 **0 阶既视感**——模糊的直觉提示。
既是弱化版体验，也是"你是不是快在这一轮回激活了"的诱饵。

## 13. 可发现性：激活条件必须半透明

**全隐藏 = 玩家永远不知道自己在追什么，等于没有目标。**

> **设计要求：找回前史后，系统给出残缺的条件提示。给方向，不给答案。**

示例文案：

> *「你的回响似乎与『被众人指认』有关……
> 以及某种你尚未想起的克制。」*

| 玩家可见 | 玩家不可见 |
|---|---|
| 共鸣类条款（大意） | 精确的数值阈值 |
| 存在几条未知条款 | 禁忌类条款的具体内容（需自己领悟或靠记忆碎片解锁） |
| 当前渴望值的模糊刻度（"你的执念在加深"） | 精确进度条 |

禁忌类条款是**最后才揭示**的——很多玩家会在偶然满足它之后，才明白自己一直做对了什么。
这个"回过头才懂"的体验值得刻意保护。

## 14. 实装范围建议

32 种执念 × 5 阶的完整内容量非常大。建议分期：

| 阶段 | 铺开范围 |
|---|---|
| **验证期 / 成型期** | **完全不做回响**。先把密令与余命验证清楚 |
| **主持期** | 创伤 4 种（背叛/无力/剥夺/囚禁）× 应对 4 种 = **16 格**；阶 **0–1**；覆盖约 90% 玩家体验 |
| **元游戏期** | 补齐 8 种创伤 = 32 格；开放阶 **2**；前史与记忆碎片完整化 |
| **开放期** | 开放阶 **3**；回响分化；阶 **4** 作为**手工设计的叙事内容**，不做程序化生成 |

**阶 3–4 永远保留手工设计。** 程序化生成的顶级能力必然崩坏平衡，也没有叙事重量。

## 15. 未决问题

1. **回响能否被剥夺？** 主持人是否有权在关卡内"没收"某人**本轮回已激活的回响**作为惩罚？倾向：可以**临时压制**，不能影响下轮回重新激活的资格。
2. **同一玩家一轮回能激活几条回响形状？** 目前设计允许分化出多条。上限设几条？多条回响会不会稀释"这是我的能力"的独特感？倾向：上限 3 条，但每条都必须在当轮回重新激活。
3. **渴望值是否跨轮回累积？** 若跨轮回累积，长期玩家会更容易激活高阶形状；若不累积，则单轮回内的绝境密度要求过高。倾向：**部分累积 + 衰减**。
4. **前史的"解读"选择能否反悔？** 玩家可能在了解系统后后悔早期选择。提供一次性的"重述"机会（消耗大量记忆碎片）？还是不可逆以保证重量感？
5. **AI 编号是否拥有回响？** 若有，如何避免它们成为强度不可控的怪物；若无，真人玩家可以通过"谁从没在轮回内激活过"反推谁是 AI，破坏 [08](08-host-and-ugc.md) 里"不告知谁是 AI"的设计。这是一个必须解决的冲突。
6. **"共鸣"到底以什么粒度判定？** 把"当前情境与前史节点匹配"说清楚，需要先在设计上定义"情境"包含哪些要素（谁做了什么、在什么位置、造成了什么后果……）。粒度太粗则激活显得莫名其妙，太细则几乎永远无法判定成功。**这是回响系统能否成立的设计命门。**
