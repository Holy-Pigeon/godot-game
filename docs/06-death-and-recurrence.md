# 06 · 死亡与轮回结算

> 状态：空白核心设计 ｜ 本文件是死亡相关事实的唯一来源。

以下问题均**未定案**；其他文档不得假设答案。

| 问题 | 需要决定什么 |
|---|---|
| 关卡内出局 | 离场、旁观，还是仍有行动/收益？ |
| 轮回结束 | 结算流程、可保留资源、失败与通关的区别？ |
| 重开 | 有无等待、经济或叙事代价？ |
| 复活 | 是否存在、代价是否公开？ |
| 遗留物 | 死者能否留下信息、资源或关系痕迹？ |
| 轮回痕迹 | 轮回次数在角色身上留下什么？ |

已锁定的例外：无论本文件最终如何设计，**回响的激活状态不跨轮回**；新轮回开始时玩家回到普通编号。
