# 13 · 对局记录与性格推断

> 状态：核心规格 v0.1 ｜ 真源：双流记录格式、局后推断管线与形状漂移
>
> 回响形状见 [04](04-echo.md)；T-11 需记录的事实见 [12](12-t11-last-proposal.md)。

## 一句话定义

> **对局按严格时序完整记录决策与发言；局后由小模型分析意图，产出执念倾向，只用于长线形状漂移。**

玩家永远看不到推断结果；系统也永远不用它做任何局内判定。

## 两条流

共用同一条单调递增的序号轴，消费者与保证完全不同。

| 流 | 内容 | 消费者 | 保证 |
|---|---|---|---|
| 规则事件流 | 阶段推进、顺序行动、转移申请与回应、持有状态、公开承诺、投票、否决来源、结算、承担值、失守 | 激活判定、结算、经济复算 | 纯判定，可重放 |
| 行为语料流 | 公开发言、私聊、语音转写、说话人与时点 | 局后性格推断 | 概率性，不参与判定 |

**规则事件流必须能独立复算整局。** 删掉行为语料流后，余命、承担值、奖励、失守与完美判定不得发生任何变化。

## 时序与对齐

两条流写入同一份追加日志，每条记录带：

`序号 · 时间戳 · 关卡轮次 · 协商轮 · 阶段编号 · 行动者 · 类型 · 载荷`

序号整局内单调递增且不复用。分析入口必须能按序号窗口取出一句话前后的规则事件——脱离上下文推不出意图：「我扛」在无人承担时说和在四枚已有主时说，含义相反。

## 记录范围

| 范围 | MVP 规定 |
|---|---|
| 公开发言 | 全部记录 |
| 私聊 | 全部记录，含收发双方与时点 |
| 语音 | 记录转写文本与置信度；不保留原始音频 |
| 决策 | 顺序行动、转移申请与回应、公开承诺、投票锁定 |
| 未提交痕迹 | MVP 不采集悬停、改票过程与草稿 |

转写失败或置信度过低的片段标记为缺失，不得由模型补全；按缺失处理，不按沉默处理。

**入场页须公示：全部发言（含私聊与语音）会被记录并用于系统内部分析。** 只公示记录事实，不公示推断用途，避免玩家针对推断表演。

## 推断管线

对局结束后执行一次，不在局内实时运行。

1. 从规则事件流抽取**结构化行为指标**：主动/被动承担率、转移申请次数与成功率、拒绝他人次数、言行差异次数、公开承诺次数与兑现率、否决参与次数、发言量与时点分布、参与灯点亮次数。
2. 结构化指标与对齐后的语料窗口一并交给小模型，要求输出**带证据引用的意图判断**。
3. 输出落到 `创伤 W1–W8 × 应对 R1–R4` 的带权候选分布，而非单一结论。
4. 作为本局**倾向增量**入库，附模型版本号与输入快照哈希。
5. 按跨局累计与衰减合成当前形状方向，喂给 [04](04-echo.md) 的形状成长。

三条约束：

- **结构化事实优先于语气。** 模型解释「为什么」，不判定「是什么」。[12](12-t11-last-proposal.md) 已锁定「系统只记录言行差异，不主观判断理由」；模型只负责回答「这次背叛是复仇、逃避还是支配」这类结构化指标分不出的问题。
- **证据强制引用。** 每条推断必须引用规则事件流的具体序号；无引用的整条丢弃。任何一次形状漂移都能被 GM 追溯到具体条目。
- **单局不改变形状。** 一局只产出倾向增量，形状按多局累计加权与衰减移动，对应 [04](04-echo.md) 的**加深**与**分化**；**初生不由推断决定**，仍按 04 由首次激活确立。系数与 [09](09-open-questions.md) C2 同源。

## 不可违反的隔离

1. **不进入任何局内判定。** 激活条件、效果结算、余命、记忆、承担值、完美判定一律只读规则事件流。
2. **不改变激活条件的可判定性。** [04](04-echo.md) 第 6 条全额生效；推断只影响玩家长出哪个方向的形状，不影响此刻某条回响能否激活。
3. **不构成力量。** 落在 04 第 3 条允许跨轮回保留的「形状」一侧。
4. **对所有玩家不可见**，包括本人。不进历史档案，不用于匹配或发令。
5. **模型不可用不影响对局。** 离线降级只暂停形状漂移，不阻塞结算或轮回推进。

玩家不会被告知「你是 W6 × R2」。自我认知只通过 [04](04-echo.md) 的三段式发现节奏发生：**从自己长出了什么样的回响，反过来认出自己是什么样的人。**

## T-11 行为到执念坐标的采样映射

推断的先验参考，不是硬编码规则。

| 反复出现的行为 | 主要指向 |
|---|---|
| 持续主动承担、替人多扛 | W6 罪咎 × R2 补偿 |
| 承诺认可后投反对并造成否决 | W4 欺瞒 或 W1 背叛 × R1 / R3 |
| 反复把灾痕申请转给曾拒绝自己的人 | W1 背叛 × R1 复仇 |
| 长期不选、少发言、回避交涉 | R3 逃避 |
| 主导分配、指挥方案、替别人安排承担 | R4 支配 |
| 反复提出方案却无人回应后转向沉默 | W8 湮没 |
| 转移申请反复被拒、无人愿意与我交换 | W5 弃绝 |
| 持有 2 枚仍拒绝他人接手以保承担奖 | W3 剥夺 × R4 支配 |

四条 MVP 回响各自对应的执念坐标：E-01 = W4×R3，E-02 = W8×R4，E-03 = W6×R2，E-04 = W1×R1。

## MVP 范围

| 项 | 规定 |
|---|---|
| 纳入 | 双流记录、统一序号轴、上下文对齐查询、公开与私聊文字、语音转写、局后一次性推断、带证据引用的倾向增量入库 |
| 纳入 | GM 可查看任意一局的两条流与该局倾向增量及其引用证据 |
| 暂不纳入 | 累计与衰减系数定案、未提交痕迹采集、实时推断、多模型交叉验证、原始音频留存 |

## 验证

1. 删除行为语料流后重放规则事件流，确认所有结算结果完全一致。
2. 取任意一句发言，确认能还原当时的轮次、阶段与场上分配。
3. GM 制造一次「承诺认可后投反对」，确认该事实同时出现在结构化指标与模型引用中。
4. 断开推断模型，确认对局正常结算并能进入下一轮回。
5. 同一输入重跑两次推断，确认差异只影响倾向增量权重，不影响任何已结算数值。
6. 确认玩家界面与历史档案中不出现执念坐标或推断文本。

## 未决项

累计与衰减系数、单局增量上限、模型升级后历史增量是否重算、转写置信度阈值、私聊留存期限，见 [09](09-open-questions.md)。
