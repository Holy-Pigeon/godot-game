# 《终焉之地》设计文档索引

> 状态：设计草案 v0.1
> **第一阶段只做游戏设计，不讨论任何技术实现。**

一款以"十日终焉"为气质原型的 **多人社交博弈 + UGC 关卡平台**。
玩家以失忆的**编号**身份被困在**终焉之地**，在**关卡**中用**余命**互相博弈，
在无数次**轮回**中找回自己的过去、觉醒**回响**，并最终有可能成为**生肖**——
关卡规则的化身，去折磨下一批人。

---

## 一分钟读懂

| 问题 | 答案 |
|---|---|
| 玩家在做什么 | 10 人一局的规则博弈（德州、放逐、拍卖……），每人持有**只有自己知道的密令** |
| 短期目标 | 活下来 + 完成密令 |
| 中期目标 | 打通一次**轮回**（10 个关卡 = 十日） |
| 长期目标 | 三轴并行：**生存**（余命）、**真相**（记忆碎片 / 找回前史）、**权柄**（觉醒回响 → 晋升生肖） |
| 唯一货币 | **余命**（单位：日） |
| 超能力 | **回响**——稀有，由绝境触发，且必须与你的**前史创伤**共振 |
| UGC 怎么做 | 不写规则条文，只**组合规则零件**：基础玩法模板 + 规则修正件 + 密令池 + 主持人人格 |
| 凑不齐 10 人怎么办 | **AI 编号补位**，这是世界观的一部分，不是妥协 |

## 设计阶段词汇

各文档在讨论"某个系统什么时候上"时，统一使用下列**设计阶段**标签。
它们描述的是**内容与系统的铺开顺序**，不涉及任何开发排期。

| 阶段 | 含义 |
|---|---|
| **验证期** | 只有编号 + 密令 + 余命。唯一目的是验证"密令能让平庸玩法变好玩" |
| **成型期** | 基础玩法模板与规则修正件成库，关卡开始有质感差异 |
| **主持期** | 主持人与 AI 编号登场，解决 10 人门槛 |
| **元游戏期** | 十日轮回、庇护所、前史与真相轴、回响深化 |
| **开放期** | 玩家创作关卡、晋升生肖、赛季与大终焉 |
