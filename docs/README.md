# 《终焉之地》设计文档索引

> 状态：设计草案 v0.2
> **第一阶段只做游戏设计，不讨论任何技术实现。**

一款以"十日终焉"为气质原型的 **多人社交博弈 + UGC 关卡平台**。
玩家以失忆的**编号**身份被困在**终焉之地**，在**关卡**中用**余命**互相博弈，
在无数次**轮回**中找回自己的过去，并在共振情景中激活只属于本轮回的**回响**。
同时，**任何玩家都可以自己造一个关卡并主持它**——成为规则的化身，去折磨下一批人。

> ⚠️ **当前唯一一块完全空白的核心设计：死亡怎么处理。**
> 见 [06](06-death-and-recurrence.md)，各文档中依赖它的地方一律标 〔待定〕。

## 一分钟读懂

| 问题 | 答案 |
|---|---|
| 玩家在做什么 | 在 2D 大世界里走到某栋建筑前进场，参加一局规则博弈（暗账、放逐、缔约……）。**开局人数由关卡设计者定义**，每人持有**只有自己知道的密令** |
| 短期目标 | 活下来 + 完成密令 |
| 中期目标 | 打通一次**轮回**（10 个关卡 = 十日） |
| 长期目标 | 三轴并行：**生存**（余命）、**真相**（记忆碎片 / 找回前史）、**权柄**（回响形状成型 → 每轮回重新激活 → 四阶权柄形状） |
| 唯一货币 | **余命**（单位：日） |
| 超能力 | **回响**——稀有，在与前史创伤共振的特定情景中**激活**，活跃至本轮回结束；是否发动由玩家主动选择，下轮回重置为普通编号 |
| UGC 怎么做 | 不写规则条文，只**组合规则零件**：基础玩法模板 + 规则修正件 + 密令池 + 主持人人格 |
| 谁能造关 | **所有人**，没有身份门槛。但要先在大世界里**买一块地**——地很贵，核心区还有限。唯一硬约束：**不能以编号身份进自己的关卡** |
| 死了会怎样 | **〔待定〕**，见 [06](06-death-and-recurrence.md) |
| 凑不齐关卡要求的人数怎么办 | **AI 编号补位**，这是世界观的一部分，不是妥协 |

## 已拍板的决策（不再讨论，如需推翻请走变更流程）

| # | 决策 | 出处 |
|---|---|---|
| D-01 | **形态**：在线多人为主，AI 编号补位保底 | [00](00-overview.md) |
| D-02 | **表现**：2D 像素 + 可走动的庇护所场景 | [01](01-core-loop.md) |
| D-03 | **主持人由玩家自己接入的外部模型扮演**，但没有接入的玩家也必须能正常游玩 | [08](08-host-and-ugc.md) |
| D-04 | **无阵营**：普通玩家只有编号，不存在"人类阵营"（保住猜疑链） | [05](05-authority-and-ascension.md) |
| D-05 | **主持人是职责不是敌人**：规则的化身，胜利条件是"收成"而非杀人 | [05](05-authority-and-ascension.md) |
| D-06 | **"日"是个人进度轴**，不是全服现实时钟（原条目后半句「死亡零冷却重开」**已撤回**，随死亡逻辑待定） | [01 §3.2](01-core-loop.md) |
| D-07 | **回响稀有但人人有机会**：激活情景越苛刻，回响越强，且必须与前史共振；**激活不等于发动**，是否使用永远由玩家选择；激活状态只持续当轮回，下轮回重置 | [04](04-echo.md) |
| D-08 | **创作者只做规则的组合**，不撰写自由规则条文；一切效果必须可被客观判定 | [07](07-level-design.md) |
| D-09 | **主持人不裁判胜负**：胜负永远由关卡规则本身判定 | [08](08-host-and-ugc.md) |
| D-10 | **关卡入口在大世界**：走到建筑前交互进场，门口公示牌**只有四项**（类型 / 难度·死亡率 / 人数 / 门票） | [07](07-level-design.md) |
| D-11 | **压制不公开**：连总体标签都不给，只在进场后宣读。玩家自行交流、贩卖这条情报是被鼓励的 | [07](07-level-design.md) |
| D-12 | **关卡人数由设计者定义**，在模板区间内自选（平台区间 **4–16**）；凑不齐由 AI 编号补位 | [07](07-level-design.md) |
| D-13 | **回响走"语义锚点"**：回响只声明动词 + 作用对象 + 层级，由模板负责映射成本关的具体动作。模板必须实现 L1/L2 全部语义才能上架 | [04 §7.5](04-echo.md) |
| D-14 | **GM 模式是设计验证的一等公民**：前史、执念格、回响阶数、渴望值、密令分配等全部可直接设定，不依赖真实对局累积 | [10](10-gm-and-validation.md) |
| D-15 | **模板的准入判据是"能不能让人露出本性"**：无最优解 / 可观测 / 价值取舍 / **随机性不得成为决策的借口**。首批十个模板据此收敛为六个，首发模板为 **T-11 暗账** | [07 §2.2](07-level-design.md) |
| D-16 | **回响先行，关卡后行**：先设计回响与前史，关卡负责提供其激活所需的**情境谓词**。共鸣类条款只能写在谓词清单之上；单关可偏科，**一个日层的关卡池必须整体覆盖该层的回响池** | [04 §5.1.1](04-echo.md)、[11](11-mvp-echoes.md) |
| D-17 | **前史是平凡人生的因，不是奇观**："小时候家里所有事都瞒着他"，而不是"他曾亲手毁掉一座城" | [04 §4.1](04-echo.md) |
| D-18 | **回响锚在「渴望」上，不锚在机制上**：名字必须是普通人说得出口的话（【真话】【替】【不是我】），一眼能看出作用，且名字本身就是那个渴望 | [04 §4.1.1](04-echo.md)、[11](11-mvp-echoes.md) |
| D-19 | **同一条回响每关最多发动一次**（所有阶通用）。这是平台级约束，**不进入苛刻度计算** | [04 §6.1](04-echo.md) |
| D-20 | **废弃十二生肖／十二权柄整套符号系统**。回响只标[执念格 W×R](04-echo.md)，修正件按**效果层级 L1–L4** 组织，压制按**语义动词族**封锁，「生肖」统一为「**主持人**」，其裁量由关卡的**裁量清单**限定 | [05](05-authority-and-ascension.md) |

## 设计阶段词汇

各文档在讨论"某个系统什么时候上"时，统一使用下列**设计阶段**标签。
它们描述的是**内容与系统的铺开顺序**，不涉及任何开发排期。

| 阶段 | 含义 |
|---|---|
| **验证期** | 只有编号 + 密令 + 余命。唯一目的是验证"密令能让平庸玩法变好玩" |
| **成型期** | 基础玩法模板与规则修正件成库，关卡开始有质感差异 |
| **主持期** | 主持人与 AI 编号登场，解决开局人数门槛 |
| **元游戏期** | 十日轮回、庇护所、前史与真相轴、回响深化 |
| **开放期** | 开放全体玩家造关与主持（无门槛）、赛季与大终焉 |

## 阅读建议

- **第一次读**：`00` → `01` → `04`，这三份决定了这个游戏是什么。
- **要做数值**：`02` → `04`。（`06` 是空的，且它卡着 `02` 的一部分数值）
- **要设计关卡**：`03` → `07` → `05`（`05 §5` 讲谁能造关、造关受什么约束）。
- **要验证设计**：`10` → `04`。
- **要做 MVP**：`11` → `07 §2.5` → `10`。**先看回响，再看关卡**，顺序不能反。
- **要谈这个项目**：只读 `00` 和本文件。
